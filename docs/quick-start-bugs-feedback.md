# Bugs and Feedback

### The Help Menu

In the upper left corner of the Picker Page, you should see the Help Menu next to the File Menu.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu.png')} alt="help-menu" style={{marginLeft: 0, zoom: '80%'}} />

When you click on the Help Menu, you should see a number of useful menu items, including items for suggesting Features, reporting Bugs or sending me a message.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu-items.png')} alt="help-menu-items" style={{marginLeft: 0, zoom: '80%'}} />

With each of these items, when you click on them, they will open a link in your web browser so you can fill out a form.

Suggest a Feature and Report a Bug will add items directly to my ticket tracking system, and Contact Me will send a message to my business email.

You can also use these links to get to those specific forms:

- **[Report a Bug](https://tally.so/r/ODx6Np)**
- **[Suggest a Feature](https://tally.so/r/D4RjLp)**
- **[Contact Me](https://tally.so/r/RG9N6l)**
