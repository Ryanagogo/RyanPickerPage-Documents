# Editor Basics

<img src={useBaseUrl('/img/quick-start/editor-basics/editor-default-open.png')} alt="editor-default-open" style={{marginLeft: '0px', zoom: '75%'}} />

### File Menu

<img src={useBaseUrl('/img/quick-start/editor-basics/file-menu.png')} alt="file-menu" style={{marginLeft: '0px', zoom: '75%'}} />

From the File Menu, you can create a new blank picker page, load and save pages, and get to Editor Settings.

### Help Menu

<img src={useBaseUrl('/img/quick-start/editor-basics/help-menu.png')} alt="help-menu" style={{marginLeft: '0px', zoom: '75%'}} />

From the Help Menu, you can find links to the YouTube videos, Documents, Support, and links so you can report Bugs and Request Features.

### New Picker

<img src={useBaseUrl('/img/quick-start/editor-basics/new-picker.png')} alt="new-picker" style={{marginLeft: '0px', zoom: '75%'}} />

The New Picker Button will open another Picker Page Editor, allowing you to open multiple picker pages at one time.

### Page Title

<img src={useBaseUrl('/img/quick-start/editor-basics/page-title.png')} alt="page-title" style={{marginLeft: '0px', zoom: '75%'}} />

The Page Title will display the title of the Picker Page you've loaded in.

### Current Rig

<img src={useBaseUrl('/img/quick-start/editor-basics/current-rig.png')} alt="current-rig" style={{marginLeft: '0px', zoom: '75%'}} />

From the Pulldown Menu, you can select from any rig in your level, what the current rig that will work with your picker page.  The name of the current rig will also be displayed under the page title.

### Bookmarks

<img src={useBaseUrl('/img/quick-start/editor-basics/book-marks.png')} alt="book-marks" style={{marginLeft: '0px', zoom: '75%'}} />

Since you can move the picker canvas around and zoom in or out, the bookmarks allow you to save the current canvas position and zoom, so you can come back to it later.

### Edit Mode Toggle

<img src={useBaseUrl('/img/quick-start/editor-basics/edit-mode-toggle-button.png')} alt="edit-mode-toggle-button" style={{marginLeft: '0px', zoom: '75%'}} />

Clicking the Edit Mode Toggle button will allow you to enter and exit Edit Mode.  Edit Mode is where you can edit, add and remove Picker Page Widgets.

### Canvas Area

<img src={useBaseUrl('/img/quick-start/editor-basics/canvas-area.png')} alt="canvas-area" style={{marginLeft: '0px', zoom: '75%'}} />

The Canvas Area is where you will find all the Picker Page Widgets

# Edit Mode

<img src={useBaseUrl('/img/quick-start/editor-basics/editor-edit-mode.png')} alt="editor-edit-mode" style={{marginLeft: '0px', zoom: '75%'}} />

Edit Mode is where you can edit, add and remove Picker Page Widgets.

### Editable Page Title

<img src={useBaseUrl('/img/quick-start/editor-basics/editable-page-title.png')} alt="editable-page-title" style={{marginLeft: '0px', zoom: '75%'}} />

This is where you can change the Page Title

### Toolbar Tools

<img src={useBaseUrl('/img/quick-start/editor-basics/toolbar-tools.png')} alt="toolbar-tools" style={{marginLeft: '0px', zoom: '75%'}} />

The Toolbar contain various tools to help you edit certain common widget attributes and to help with widget layout.

### Widget Attribute Editor Toggle

<img src={useBaseUrl('/img/quick-start/editor-basics/attribute-editor-toggle.png')} alt="attribute-editor-toggle" style={{marginLeft: '0px', zoom: '75%'}} />

The Attribute Editor allows you to edit various attributes or see information for a selected widget.

### Widget Outliner Toggle

<img src={useBaseUrl('/img/quick-start/editor-basics/outliner-toggle.png')} alt="outliner-toggle" style={{marginLeft: '0px', zoom: '75%'}} />

The outliner give you different views of the widgets in the Canvas Area, grouped by Layer or Type.

### Canvas Edit Area

<img src={useBaseUrl('/img/quick-start/editor-basics/canvas-edit-area.png')} alt="canvas-edit-area" style={{marginLeft: '0px', zoom: '75%'}} />

You can know you are in Edit Mode when you see the red border around the Canvas Area.  Right clicking in this area will give you popup menus so you can create or edit Picker Page Widgets.
