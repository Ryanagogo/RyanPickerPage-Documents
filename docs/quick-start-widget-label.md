# Label Widget

### Creating a new Label Widget

You must be in **Edit Mode** to create a new Label Widget

**Right click in an empty part of the picker Canvas** to bring up the popup menu, then click on the "Label" menu item

### From the Attribute Editor

To see the values in the Attribute Editor, you need to select one widget

##### Label Appearance

<img src={useBaseUrl('/img/quick-start/widget-label/label-appearance.png')} alt="label-appearance" style={{marginLeft: 0, zoom: '80%'}} />

- **Color**
  - Set the Color of the Button
- **Font**
  - Set the font color and Font size

##### Label Text

<img src={useBaseUrl('/img/quick-start/widget-label/label-text.png')} alt="label-text" style={{marginLeft: 0, zoom: '80%'}} />

- **Label**

  - Set the Text in the Label

- **Text Styles**

  - For longer text, you can use the following to help format the text

    - Justification

    - Word Wrap

    - Margin

    - Clip

##### Label Image

<img src={useBaseUrl('/img/quick-start/widget-label/label-image.png')} alt="label-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - Use any image asset in your project
- **Stretch Mode**
  - Different modes determine how the image will stretch to try an fill up the size of the widget
- **Scale**
  - Allows you to zoom the image in or out
- **Offset**
  - Allows you to offset the image up and down and side to side
- **Alpha**
  - Allow you to set the transparency of the image.  The more transparent, the you see the Widget Color
