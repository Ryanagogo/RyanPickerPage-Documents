# Starting the Picker Page Editor

### The Plugin

Make sure the **RyanPickerPage** plugin is enabled

<img src={useBaseUrl('/img/starting-the-picker-page-editor/enable-plugin.png')} alt="enable-plugin" style={{display: 'block', marginLeft: 0, marginRight: 'auto'}} />

### Opening the Editor

Go to the Tools Menu

<img src={useBaseUrl('/img/starting-the-picker-page-editor/find-tools-menu.png')} alt="find-tools-menu" style={{display: 'block', marginLeft: 0, marginRight: 'auto'}} />

Then look for **Ryan Tools -> Picker Page**

<img src={useBaseUrl('/img/starting-the-picker-page-editor/find-ryan-tools-picker-page.png')} alt="find-ryan-tools-picker-page" style={{display: 'block', marginLeft: 0, marginRight: 'auto'}} />

A blank Picker Page Editor Utility Widget should open

<img src={useBaseUrl('/img/starting-the-picker-page-editor/blank-picker-page-editor.png')} alt="blank-picker-page-editor" style={{display: 'block', marginLeft: 0, marginRight: 'auto'}} />
