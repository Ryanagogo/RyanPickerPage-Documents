# Starting the Picker Page Editor

### The Plugin

Make sure the **RyanPickerPage** plugin is enabled

<img src="..\static\img\starting-the-picker-page-editor\enable-plugin.png" alt="enable-plugin" />

### Opening the Editor

Go to the Tools Menu

<img src="..\static\img\starting-the-picker-page-editor\find-tools-menu.png" alt="find-tools-menu" style="margin-left: 0;" />

Then look for **Ryan Tools -> Picker Page**

<img src="..\static\img\starting-the-picker-page-editor\find-ryan-tools-picker-page.png" alt="find-ryan-tools-picker-page" style="margin-left: 0;" />

A blank Picker Page Editor Utility Widget should open

<img src="..\static\img\starting-the-picker-page-editor\blank-picker-page-editor.png" alt="blank-picker-page-editor" />
