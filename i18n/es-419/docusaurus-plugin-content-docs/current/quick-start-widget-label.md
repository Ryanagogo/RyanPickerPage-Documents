# Widget de etiqueta \{#label-widget}

### Crear un widget de etiqueta nuevo \{#creating-a-new-label-widget}

Debes estar en el **modo de edición** para crear un widget de etiqueta nuevo

**Haz clic derecho en una zona vacía del lienzo del picker** para abrir el menú emergente y luego haz clic en la opción "Etiqueta"

### Desde el editor de atributos \{#from-the-attribute-editor}

Para ver los valores en el editor de atributos, necesitas seleccionar un solo widget

##### Apariencia de la etiqueta \{#label-appearance}

<img src={useBaseUrl('/img/quick-start/widget-label/label-appearance.png')} alt="label-appearance" style={{marginLeft: 0, zoom: '80%'}} />

- **Color**
  - Establece el color del botón
- **Fuente**
  - Establece el color y el tamaño de la fuente

##### Texto de la etiqueta \{#label-text}

<img src={useBaseUrl('/img/quick-start/widget-label/label-text.png')} alt="label-text" style={{marginLeft: 0, zoom: '80%'}} />

- **Etiqueta**

  - Establece el texto de la etiqueta

- **Estilos de texto**

  - Para textos largos, puedes usar lo siguiente para dar formato al texto

    - Justification

    - Word Wrap

    - Margin

    - Clip

##### Imagen de la etiqueta \{#label-image}

<img src={useBaseUrl('/img/quick-start/widget-label/label-image.png')} alt="label-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - Usa cualquier asset de imagen de tu proyecto
- **Modo de ajuste**
  - Los distintos modos determinan cómo se estira la imagen para intentar llenar el tamaño del widget
- **Escala**
  - Permite acercar o alejar la imagen
- **Desplazamiento**
  - Permite mover la imagen hacia arriba y hacia abajo, y de lado a lado
- **Alfa**
  - Permite establecer la transparencia de la imagen. Mientras más transparente sea, más se verá el color del widget
