# バグとフィードバック \{#bugs-and-feedback}

### ヘルプメニュー \{#the-help-menu}

Picker Page の左上隅、ファイルメニューの隣にヘルプメニューがあります。

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu.png')} alt="help-menu" style={{marginLeft: 0, zoom: '80%'}} />

ヘルプメニューをクリックすると、機能の提案、バグの報告、私へのメッセージ送信など、便利なメニュー項目がいくつか表示されます。

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu-items.png')} alt="help-menu-items" style={{marginLeft: 0, zoom: '80%'}} />

これらの項目をクリックすると、Web ブラウザでリンクが開き、フォームに入力できます。

「機能を提案」と「バグを報告」は私のチケット管理システムに直接項目を追加し、「お問い合わせ」は私の業務用メールアドレスにメッセージを送信します。

次のリンクから各フォームに直接アクセスすることもできます。

- **[バグを報告](https://tally.so/r/ODx6Np)**
- **[機能を提案](https://tally.so/r/D4RjLp)**
- **[お問い合わせ](https://tally.so/r/RG9N6l)**
