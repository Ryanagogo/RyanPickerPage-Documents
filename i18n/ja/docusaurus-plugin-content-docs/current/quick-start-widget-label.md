# ラベルウィジェット \{#label-widget}

### 新しいラベルウィジェットを作成する \{#creating-a-new-label-widget}

新しいラベルウィジェットを作成するには、**編集モード**になっている必要があります

**ピッカーキャンバスの空いている場所を右クリック**してポップアップメニューを表示し、「ラベル」メニュー項目をクリックします

### 属性エディタから \{#from-the-attribute-editor}

属性エディタで値を表示するには、ウィジェットを 1 つだけ選択する必要があります

##### ラベルの外観 \{#label-appearance}

<img src={useBaseUrl('/img/quick-start/widget-label/label-appearance.png')} alt="label-appearance" style={{marginLeft: 0, zoom: '80%'}} />

- **色**
  - ボタンの色を設定します
- **フォント**
  - フォントの色とサイズを設定します

##### ラベルのテキスト \{#label-text}

<img src={useBaseUrl('/img/quick-start/widget-label/label-text.png')} alt="label-text" style={{marginLeft: 0, zoom: '80%'}} />

- **ラベル**

  - ラベルのテキストを設定します

- **テキストスタイル**

  - 長いテキストの場合は、次の設定で書式を整えられます

    - Justification

    - Word Wrap

    - Margin

    - Clip

##### ラベルの画像 \{#label-image}

<img src={useBaseUrl('/img/quick-start/widget-label/label-image.png')} alt="label-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - プロジェクト内の任意の画像アセットを使用できます
- **引き伸ばしモード**
  - ウィジェットのサイズを埋めるために画像をどのように引き伸ばすかを、モードごとに決めます
- **スケール**
  - 画像をズームイン/ズームアウトできます
- **オフセット**
  - 画像を上下左右にずらすことができます
- **アルファ**
  - 画像の透明度を設定できます。透明にするほど、ウィジェットの色が見えるようになります
