# ポーズのミラー \{#mirror-pose}

*ページの左右対称を一度教えれば、その後はいつでもレイアウトをミラーできます。*

[ミラーツール](./editing-tools#mirror) は、現在選択しているものを、選んだアンカーを基準に反転します。
一度きりの反転には便利ですが、どのウィジェット同士が対応しているかは知りません。
**ポーズのミラー** は **Pose Map** でこれを解決します。Pose Map は、どのウィジェットがどのウィジェットの左側の相方か、
中心線がどこか、全体のアンカーとなるウィジェットはどれかをページ単位で記録したものです。
一度マッピングしてしまえば、レイアウトのミラーは毎回ワンクリックで済み、選択の手間もかかりません。

## Pose Map \{#the-pose-map}

**Pose Map…** ダイアログ（ファイルメニュー）で作成します。各ページにはマップが 1 つだけあり、次の 3 種類の
エントリを持ちます。

- **アンカー** — ミラー軸（自身の中心）を定義する唯一のウィジェットです。通常は
  ページの中心線上にあるルート/骨盤のボタンです。アンカーが設定されるまでは何もミラーされず、
  ポーズボタンはトースト通知で警告します。
- **中央ウィジェット** — 背骨、頭など、中心線上にあるもの。自分自身に対してミラーされます
  （軸を基準にその場で反転）。
- **ペア** — 左右のウィジェットの組です。左太もも ↔ 右太もも、などです。

ダイアログのウィジェットのドロップダウンはアルファベット順で検索もできるため、大きなページのマッピングも
スクロールではなく入力による絞り込みで行えます。**Map をリセット** ボタン（確認あり）で
マップ全体を消去できます。マップはページファイル内に保存されるので、レイアウトと一緒に持ち運べます。

## 使い方 \{#using-it}

ツールバーのミラー行には、Mirror Horizontal/Vertical ボタンの後に **ポーズ** ボタンと方向のドロップダウンがあります。

**選択がある場合** — **ポーズ** をクリックすると、選択した各ウィジェットがマップ上の役割に従ってミラーされます。
左または右のウィジェットの位置と回転はアンカーの軸を基準に反転され、
その*相方*に書き込まれます（選択した側がソースで、こちらは動きません）。中央ウィジェットと
アンカーはその場で反転します。マップにない選択ウィジェットはトースト通知とともにスキップされ、
残りは処理されます。

**何も選択していない場合** — ドロップダウンで指定した方向（デフォルトは **左 → 右**、または
**右 → 左**）で、マップ全体がワンクリックでミラーされます。アンカーとすべての中央ウィジェットは
その場で反転し、各ペアはソース側をコピー先にコピーします。これは
「左腕ができたから、右腕にも反映して」というボタンです。

方向のドロップダウンは一時的なページコントロールで、ファイルには保存されません。

## 変更するもの・しないもの \{#what-it-changes--and-doesnt}

ポーズのミラーが動かすのは **ウィジェットのジオメトリ**、つまりキャンバス上の位置と回転です。ミラーツールと同様に、
ウィジェットの接続先には触れません。右太もものボタンは引き続き右太ももを操作し、
単に左側のボタンの位置を反転した場所に配置されるだけです。これがポイントです。
ターゲットの割り当ては一度だけ行い、その後はレイアウトの変化に合わせて左右を見た目の上で揃え続けられます。
