# 画像 \{#image}

*キャンバス上のアートワークです。キャラクターの肖像、ボディ図、背景などに使います。*

画像は優れたピッカーの視覚的な土台です。ボタンの背後にキャラクターのターンアラウンドや体のシルエットを置くと、
抽象的なボタンの並びが一目でわかるものに変わります。
[ラベル](./widget-label) と同様にライブモードでのクリック動作はなく、3 つのデフォルトグループのうち
最も奥にある **画像** [レイヤーグループ](./editing-tools#layer-groups) に最初から入っています。そのため、
後で自分でグループの順序を入れ替えない限り、追加したばかりの画像がインタラクティブなコントロールを覆うことはありません。

## 切り抜きのパン/ズーム \{#crop-panzoom}

画像編集ソフトであらかじめテクスチャを切り抜く代わりに、ページ上でフレーミングします。**Image Scale** で
元テクスチャにズームインし、**Image Offset** で表示範囲をパンします。1 枚の
キャラクターシートから、それぞれ異なる体の部位をフレーミングした多数の画像ウィジェットを作れます。同じ
2 つのコントロールは、ラベルの背景画像にもあります。

## 作成 \{#authoring}

- **テクスチャ**
- **引き伸ばしモード** — ウィジェットの矩形にテクスチャをどう合わせるか
- **Image Scale** / **Image Offset** — 切り抜き範囲
- **背景色** — テクスチャの背後にあり、**画像アルファ** のブレンド先にもなります
- **画像アルファ** — 背景色の上に重なるテクスチャの不透明度（0–1）
- 角の半径（ラベルと同様、デフォルトは直角）
- 共通の位置/サイズ/回転ブロック

## レンダリング \{#rendering}

画像とラベルは、単純なテクスチャブラシではなく、共有マテリアル（`M_RyanPickerRoundedImage`）の
動的インスタンスで描画されます。角丸、引き伸ばしモードによるフィット、切り抜き範囲はすべて
この 1 回のマテリアルパスで計算されます。そのため 2 つのタイプはピクセル単位で同じように動作し、
切り抜きによる追加コストもありません。
