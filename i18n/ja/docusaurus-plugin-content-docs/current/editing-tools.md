# 編集ツールとキャンバスツール \{#editing--canvas-tools}

このページの内容はすべて **編集モード** で行います。キャンバス自体はどちらのモードでもパン/ズームできるので、
作業しやすい倍率で組み立ててください。

## 選択 \{#selection}

- ウィジェットをクリックすると選択できます。Shift/Ctrl+クリックで選択を追加します。
- キャンバスの空いている場所をドラッグすると、矩形選択ができます。
- 選択したウィジェットには 8 つのリサイズハンドルと回転ハンドルが表示され、それぞれ専用のカーソルになります。

属性エディタは単一選択に対応しています。多数のウィジェットを一度に編集するには、下記のツールバーの
ツールを使います。

## 直接操作 \{#direct-manipulation}

ウィジェットをドラッグすると移動します。ハンドルをドラッグするとリサイズします（回転したウィジェットでも
正しくリサイズされます）。回転ハンドルをドラッグすると、ウィジェットが中心を軸に回転します。回転は
度単位で保存され、回転したウィジェットもライブモードで完全に機能します（回転したスライダーは
回転した軸に沿ってドラッグできます）。回転中に Shift を押すと 15° 刻みでスナップします。複数のウィジェットを
選択して回転すると、グループ全体が共通のピボット（最後に選択したウィジェットに固定）を中心に一体となって回転し、
同時に各ウィジェットもそれぞれの中心を軸に回転します。

ロックしたウィジェットはこれらの操作の対象外です。[ウィジェットのロック](./attribute-editor-and-outliner#widget-locking) を参照してください。

矢印キーで選択を少しずつ移動できます（Shift で大きなステップ。どちらの距離もページの Class
Defaults です）。ツールバーの **ナッジ** ツールは、数値欄で距離を設定できる画面上の矢印を追加し、
正確なステップを繰り返し適用できます。

## ツールバーのツール \{#toolbar-tools}

一度にアクティブになるツール行は 1 つだけで、ヘッダーから切り替えます。

| ツール | 選択に対する動作 |
|---|---|
| **画像** | 選択したすべてのウィジェットにテクスチャを割り当てます |
| **色** | 選択したすべてのウィジェットに背景色/フォントの色を適用します |
| **ラベル** | 選択全体のラベルテキストとフォントサイズを設定します |
| **サイズ** | 選択全体に正確な幅/高さを設定します |
| **ナッジ** | 前述の固定ステップの矢印 |
| **整列** | 左/右/上/下、水平/垂直の中央揃え、均等配置 |
| **ミラー** | 下記を参照 |

ツールバー（および属性エディタ）からの色の変更は、カラーピッカー内でドラッグしている間まとめられます。
マウスの動きごとではなく、色の編集 1 回につき 1 つのアンドゥステップになります。

## ミラー \{#mirror}

ページの片側をもう片側から作ります。**Mirror Horizontal** / **Mirror Vertical** は、選択した各ウィジェットの
位置を軸を基準に反転し、回転も反転させます。軸は **Mirror Mode** ドロップダウンで設定します。

| モード | 反転の基準 |
|---|---|
| 自身 | 各ウィジェット自身の中心。ウィジェットはその場で反転します |
| 最後に選択 (含む) | 最後に選択したウィジェットの中心。そのウィジェットも移動します |
| 最後に選択 (除外) | 最後に選択したウィジェットの中心。そのウィジェットは動きません |
| 表示中のキャンバス | 現在表示されている範囲の中心 |

ミラーは幾何学的な処理だけです。コントロール名の変更やスライダーのチャンネルの入れ替えは行いません。通常の
手順は、ミラーしてからターゲットを付け直すことです。左腕のウィジェットをミラーし、コピーのターゲットを
右側のコントロールに向け直します。ペアを記憶して繰り返し左右をミラーするには、
[ポーズのミラー](./mirror-pose) を参照してください。

## レイヤーグループ \{#layer-groups}

すべてのウィジェットはいずれか 1 つの **レイヤーグループ** に属し、描画順は各グループのメンバーを
グループごとに手前から奥へ並べたものです。3 つのグループ（**画像**、**ラベル**、**コントロール**）は
どのページにも最初から作成されており、削除できません（それ以外のグループを削除すると、そのメンバーは
タイプごとのデフォルトグループに戻されます）。この 3 つ以外にも、グループはいくつでも作成、名前変更、
並べ替え、ロックできます。ロックしたグループは、個々のウィジェットの
[ロック](./attribute-editor-and-outliner#widget-locking) と同様に、その中のすべてのウィジェットをロックします。

ウィジェットを右クリックすると、そのグループ内で **最前面に移動 / Step Up / Step Down / 最背面に送る** を実行できます。
ウィジェットのグループ間の移動、グループ自体の並べ替え、ロックは、すべて Outliner の
[レイヤー別ビュー](./attribute-editor-and-outliner#outliner-left) で行います。ドラッグ＆ドロップによる管理 UI の
詳細はそちらのページを参照してください。

## コピー、切り取り、貼り付け \{#copy-cut-paste}

どの選択でも Ctrl+C / Ctrl+X / Ctrl+V が使えます。貼り付けはカーソル位置に行われます。開いている別のページタブにも
貼り付けられ、「その場に貼り付け」を使えばページ間で移す際も正確な位置が保たれます。
貼り付けたウィジェットはできるだけ元の名前を保ち、重複する場合は数字の接尾辞が付きます。トグル
グループは [グループ全体として](./widget-toggle#toggle-groups) コピー＆貼り付けできます。

## ウィジェットのデフォルト \{#widget-defaults}

新しく追加したウィジェットの見た目は、階層的に決まります（後のものほど優先）。

1. **Class Defaults** — タイプごとの初期値（色、サイズ、フォントなど）。ページの Class Defaults パネルで
   ウィジェットタイプごとのカテゴリとして編集できます。
2. **Sticky Defaults** — 任意のウィジェットを右クリック → **Copy to Sticky Defaults** を選ぶと、それ以降に
   作成するそのタイプのウィジェットが同じ見た目になります。どのプロパティカテゴリ（色、フォント、角の半径、
   サイズ、回転、テキスト、画像）を引き継ぐかは [エディタ設定](./editor-settings) で選びます。

これらは Add Widget メニューから追加したウィジェットにのみ適用されます。貼り付けたウィジェットや読み込んだウィジェットは、
それぞれ自身のデータを保持します。
