# 保存・読み込みとファイル \{#saving-loading--files}

ページは、ディスク上の好きな場所にある 1 つの **JSON ファイル** に保存されます。ページは Unreal の
アセットではありません。`Content/` には置かれず、作成したプロジェクトも必要なく、
普通のテキストファイルと同じように共有したり、メールで送ったり、バージョン管理したりできます。

1 回の保存でページ全体が保存されます。すべてのウィジェットとその接続・スタイル、
[ブックマーク行](./bookmarks)、トグルグループ、[Pose Map](./mirror-pose) です。

## ファイルメニュー \{#the-file-menu}

| 項目 | |
|---|---|
| **保存** | ページの現在のファイルに書き戻します。一度も保存していないページでは「名前を付けて保存」と同じ動作です |
| **名前を付けて保存** | OS 標準の保存ダイアログ |
| **読み込み** | OS 標準のファイルを開くダイアログ |
| **最近使用したものを読み込み** | 最近使用したファイル（ダイアログなし） |
| **再読み込み** | 現在のファイルをディスクから読み直します |
| **Pose Map…** | [Pose Map ダイアログ](./mirror-pose#the-pose-map) |
| **Settings…** | [エディタ設定](./editor-settings) ダイアログ |

保存・読み込みダイアログは、前回使用したディレクトリで開きます。

## ヘルプメニュー \{#the-help-menu}

項目は完全にデータ駆動です。ページの Class Defaults パネルで編集する、ラベル/URL/ツールチップの
リストです。コードの変更や再コンパイルなしに項目の追加、削除、並べ替え、リンク先の変更ができ、
項目をクリックすると OS の既定のブラウザで URL が開きます。1 つだけデータ駆動ではなく固定の
項目があります。**バージョン情報** で、プラグインのバージョン、Unreal Engine のバージョン、
作者をシンプルな情報ダイアログで表示します。

## 古いファイルも読み込めます \{#old-files-keep-loading}

保存ファイルにはスキーマのバージョンがあります。古いファイルを読み込むと、間にあるすべての
スキーマ変更を通して自動的に移行されます。初期バージョンのプラグインで作ったページも現在の
バージョンで読み込め、保存し直すだけで現在のバージョンで書き出されます。移行できない
ファイル（またはお使いのものより*新しい*プラグインで作られたファイル）は、
中途半端に読み込まれることなく、わかりやすいエラーで拒否されます。

プライバシーについての注意: 選択ボタンの [Python スクリプト](./python-scripting) は、ファイル内に
Base64 エンコードで保存されます。エンコードであって暗号化ではありません。スクリプトを含むページファイルは、
スクリプトそのものと同じように扱ってください。

## セッション状態 \{#session-state}

プラグインは、ページファイルの隣に（ただし決してその中にではなく）、ファイルパスごとに前回の作業位置を
記憶します。キャンバスのパン/ズーム、アクティブな Control Rig、編集モードかライブモードかです。明日同じファイルを
読み込めば、キャンバスは前回の位置そのままです。この情報はファイルパスをキーとしてお使いのマシンに
保存されるため、ページを共有しても共有されるのはレイアウトだけで、受け取った側は自分のビュー状態を持ちます。
90 日間（設定変更可）使われなかったエントリは削除されます。

## プラグイン自身のファイルの保存場所 \{#where-the-plugin-keeps-its-own-files}

```
%APPDATA%\RyanTechAnimTools\RyanPicker\
├── settings.json              # 最近使用したファイル、前回のダイアログのディレクトリ、Outliner のビュー
├── editor_settings.json       # エディタ設定ダイアログの値
└── page_session_state.json    # ファイルごとのセッション状態（絶対パスがキー）
```

これらはユーザーごと・マシンごとのファイルです。削除すると便利な機能（最近使用したファイル、ビューの
復元、設定）は失われますが、ページのデータが失われることはありません。ページは保存したファイルの中にだけ存在します。
