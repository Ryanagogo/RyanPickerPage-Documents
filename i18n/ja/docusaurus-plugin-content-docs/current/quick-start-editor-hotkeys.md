# ホットキー \{#hotkeys}

ピッカーエディタが反応するすべてのキーボードショートカットとマウス操作です。

### フォーカスとモードのルール \{#focus-and-mode-rules}

- **キーボードショートカットは、キャンバスにフォーカスがあるときだけ機能します。** キャンバスはクリックするとすぐにフォーカスを得ます。サイドバーの入力欄や Outliner の一覧にフォーカスがあると、キー入力はそちらに送られます。
- ライブモードで機能するのは **F** のショートカットだけです。それ以外のキーボードショートカットはすべて編集モード専用です。
- 右ドラッグでのパンとマウスホイールでのズームは、編集モードとライブモードの両方で使えます。

### キーボード \{#keyboard}

| キー | 操作 | モード |
|---|---|---|
| **Delete** | 選択したウィジェットを削除 | 編集のみ |
| **F** | キャンバスのビューを現在の選択の中央に合わせる（ズームは変わりません） | 編集 + ライブ |
| **Alt + ボタンをクリック** | ボタンのクリックで選択されたオブジェクトにビューポートを合わせる |ライブのみ|
| **Alt + ボタンをドラッグ選択** | ボタンをドラッグ選択して選択されたオブジェクトにビューポートを合わせる |ライブのみ|
| **矢印キー** | 選択を少し移動（デフォルト 2 px） | 編集のみ |
| **Shift + 矢印キー** | 選択を大きなステップで移動（デフォルト 10 px） | 編集のみ |
| **Ctrl + X** | 選択したウィジェットを切り取り | 編集のみ |
| **Ctrl + C** | 選択したウィジェットをコピー | 編集のみ |
| **Ctrl + V** | マウスカーソルの位置に貼り付け | 編集のみ |
| **Ctrl + Z** | 元に戻す | 編集のみ |
| **Ctrl + Shift + Z** または **Ctrl + Y** | やり直し | 編集のみ |

キーボードによる 2 つの移動距離は、ページの Class Defaults パネルで設定します。これらは、独自の距離欄を持つツールバーの **ナッジ** ツールとは別のものです。

コピー / 切り取り / 貼り付けは、開いているページタブ間でも使えます。

**割り当てなし:** Ctrl+A（すべて選択）、Ctrl+S（保存）、Ctrl+D（複製）、Esc（選択解除）はありません。複製、整列、分布、ミラーは、右クリックメニューまたはツールバーからのみ使えます。

### マウス — ウィジェットの選択 \{#mouse---selecting-widgets}

選択の動作を変えるのは Ctrl と Shift だけです。

| 操作 | 結果 |
|---|---|
| ウィジェットをクリック | そのウィジェットだけを選択 |
| Ctrl + ウィジェットをクリック | そのウィジェットを選択に追加、または選択から除外 |
| Shift + ウィジェットをクリック | そのウィジェットを選択に追加 |
| キャンバスの空いている場所をクリック | 選択を解除 |
| キャンバスの空いている場所をドラッグ | 選択用の矩形を描く |
| Ctrl または Shift + 選択矩形をドラッグ | 矩形内のウィジェットを、現在の選択を置き換えるのではなく追加 |
| Outliner の行をクリック | そのウィジェットを選択（ロックしたウィジェットでも可） |
| Outliner の行をダブルクリック | 名前を変更 |

### マウス — 移動、リサイズ、回転（編集モード） \{#mouse---moving-resizing-rotating-edit-mode}

8 つのリサイズハンドルと移動ハンドルは、編集モードでのみ表示されます。

| 操作 | 結果 |
|---|---|
| 移動ハンドルをドラッグ | 選択したウィジェットを移動 |
| **Alt** + 移動ハンドルをドラッグ | 移動の代わりに回転 |
| **Alt + Shift** + 移動ハンドルをドラッグ | 15 度刻みでスナップしながら回転 |
| 辺または角のハンドルをドラッグ | リサイズ（回転したウィジェットでも正しく動作） |

回転を始めるには、移動ハンドルを押す前に Alt を押したままにします。スナップするには、ドラッグ中に Shift を押し続けます。

### マウス — キャンバスの移動 \{#mouse---navigating-the-canvas}

| 操作 | 結果 | モード |
|---|---|---|
| マウスホイール | カーソルに向かってズーム | 編集 + ライブ |
| 右ドラッグ | キャンバスをパン | 編集 + ライブ |
| 右クリック（ドラッグなし） | コンテキストメニューを開く | 編集のみ |
| サイドバーの境界をドラッグ | Outliner または属性エディタのパネルのサイズを変更 | 編集のみ |

### ブックマーク \{#bookmarks}

| 操作 | 結果 |
|---|---|
| ブックマークをクリック | 保存したビューを適用 |
| ブックマークを **Ctrl + Shift + クリック** | 現在のビューをそのブックマークに上書き保存 |
| ブックマークを右クリック | 名前の変更またはクリア |
