# 画像ウィジェット \{#image-widget}

### 新しい画像ウィジェットを作成する \{#creating-a-new-image-widget}

新しい画像ウィジェットを作成するには、**編集モード**になっている必要があります

**ピッカーキャンバスの空いている場所を右クリック**してポップアップメニューを表示し、「画像」メニュー項目をクリックします

### 属性エディタから \{#from-the-attribute-editor}

属性エディタで値を表示するには、ウィジェットを 1 つだけ選択する必要があります

##### 画像ウィジェットの外観 \{#image-widget-appearance}

<img src={useBaseUrl('/img/quick-start/widget-image/image-widget-appearance.png')} alt="image-widget-appearance" style={{marginLeft: 0, zoom: '80%'}} />

**色**

- ボタンの色を設定します

##### 画像ウィジェットの画像 \{#image-widget-image}

<img src={useBaseUrl('/img/quick-start/widget-image/image-widget-image.png')} alt="image-widget-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - プロジェクト内の任意の画像アセットを使用できます
- **引き伸ばしモード**
  - ウィジェットのサイズを埋めるために画像をどのように引き伸ばすかを、モードごとに決めます
- **スケール**
  - 画像をズームイン/ズームアウトできます
- **オフセット**
  - 画像を上下左右にずらすことができます
- **アルファ**
  - 画像の透明度を設定できます。透明にするほど、ウィジェットの色が見えるようになります
