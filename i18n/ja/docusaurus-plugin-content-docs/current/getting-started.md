# はじめよう \{#getting-started}

## ページを開く \{#opening-a-page}

**Tools → Ryan Picker Page** で、新しいエディタタブにページが開きます。ページヘッダーの **New Tab** ボタンで
さらにページを開けます。各タブは完全に独立しており、それぞれ独自のファイル、独自の Control Rig の選択、
独自のキャンバスビューを持ちます。ページの名前を変更すると（タイトルは編集モードで編集できます）タブ名も
変わるため、多数のピッカーを開いていても迷いません。

## 2 つのモード \{#two-modes}

ヘッダーの編集モードボタンで、ページ全体を次の 2 つのモード間で切り替えます。

**ライブモード** — アニメーション作業用のモードです。ウィジェットをクリックするとリグのコントロールやアクターが選択され、
スライダーをドラッグするとトランスフォームを操作できます。ウィジェットにカーソルを合わせると、何に接続されているかがツールチップで表示されます。
レイアウト自体は変更できません。

**完成したページはライブモードで使われ続けます。**
[編集ツールとキャンバスツール](./editing-tools) の内容はすべて、ここにたどり着くためのものです。

**編集モード** — 構築用のモードです。ウィジェットに移動・リサイズ・回転のハンドルが表示され、キャンバスの空いている場所を
右クリックすると **Add Widget** メニューが開き、折りたたみ可能な 2 つのサイドバーが現れます。左側が
[Outliner](./attribute-editor-and-outliner)、右側が
[属性エディタ](./attribute-editor-and-outliner) です。

## 最初のページを作る \{#build-your-first-page}

片脚だけの最小限のピッカーを、最初から最後まで作ってみましょう。

1. キャラクターとその Control Rig を含む Level Sequence を開き、ピッカーページを開きます。
   ヘッダーのリグドロップダウンには、フォーカスされているシーケンスから自動的に項目が入ります。リグを選んでください（リグが
   1 つしかない場合は自動で選択されます）。
2. **編集モード**に入ります。
3. ビューポートまたは Anim Outliner で太もものコントロールを選択します。キャンバスを右クリック →
   **Add Widget → 選択ボタン** を選びます。デフォルトでは、新しいボタンは現在の選択からターゲットリストを
   作成するため、このボタンはすでに太ももを操作します。
4. ふくらはぎと足についても繰り返します。
   [属性エディタ](./attribute-editor-and-outliner) のラベル欄で各ボタンに名前を付け、ドラッグして
   脚の形の列に並べます。
5. 3 つすべてを選択し、[整列ツール](./editing-tools) で列をまっすぐに揃えてみましょう。
6. 編集モードを終了します。ボタンをクリックすると、それぞれ対応するコントロールが選択されます。これが基本の流れで、あとはすべて
   仕上げの作業です。
7. **ファイル → 保存** で、ページを好きな場所の JSON ファイルに書き出します。詳しくは
   [保存・読み込みとファイル](./save-load-and-files) を参照してください。

## 元に戻す、やり直し、セーフティネット \{#undo-redo-and-safety-nets}

編集モードでのすべての変更（移動、リサイズ、追加、削除、貼り付け、色の編集）は、ページの
アンドゥスタックに記録されます（デフォルトで 30 ステップ。[エディタ設定](./editor-settings) を参照）。Ctrl+Z /
Ctrl+Y、またはヘッダーのボタンを使います。カラーピッカー内でのドラッグは、動きごとではなく 1 つのアンドゥステップに
まとめられるため、色の変更を元に戻すとドラッグ全体が元に戻ります。

[ブックマーク](./bookmarks) には独自の独立したアンドゥスタックがあります。レイアウトのアンドゥが保存済みのビューに
影響することはなく、その逆もありません。

## 前回の続きから再開する \{#picking-up-where-you-left-off}

保存されたファイルごとに、プラグインはキャンバスのパン/ズーム、アクティブだった Control Rig、
編集モードとライブモードのどちらだったかを記憶しており、次にそのファイルをこのマシンで読み込んだときに
すべて自動で復元されます。この情報はページファイルの外に保存されるため、ページをチームメンバーと共有しても
共有されるのはレイアウトであり、あなたの表示の癖ではありません。詳しくは
[保存・読み込みとファイル](./save-load-and-files#session-state) を参照してください。
