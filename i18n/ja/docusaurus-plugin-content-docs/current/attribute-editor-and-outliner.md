# 属性エディタと Outliner \{#attribute-editor--outliner}

編集モードの 2 つのサイドバーです。それぞれヘッダーに専用の切り替えボタンがあるので、片方だけ、両方、
またはどちらも表示しない、を選べます。

## Outliner（左） \{#outliner-left}

ページ上のすべての要素の一覧です。行をクリックするとウィジェットを選択、ダブルクリックで名前を変更、
右クリックで移動/削除ができます。一覧の上にあるボタンで 3 つのビューを切り替えます。

- **タイプ別** — 6 つのウィジェットタイプの見出しの下にまとめて表示します。普段使いのビューです。
- **レイヤー別** — [レイヤーグループ](./editing-tools#layer-groups) ごとに描画順で表示します。重なり順は
  ここで並べ替えます。ウィジェットを別のグループにドラッグするとそのグループに移動し、グループ内でドラッグすると
  順序が変わり、グループの見出し自体をドラッグするとグループの順序が変わります。各グループの見出しには
  専用のロック切り替えがあり、個別に折りたためます。
- **グループ別** — [トグルグループ](./widget-toggle#toggle-groups) を、名前付きの見出しの下にメンバーを入れ子にして
  表示します。グループ名の変更もここで行います。

ウィジェット名はページ内で一意です（大文字小文字は区別しません）。名前が重複する変更は、
黙って別名に変えられるのではなく、拒否されて元に戻ります。最後に使ったビューはセッションをまたいでグローバルに記憶されます。

## 属性エディタ（右） \{#attribute-editor-right}

現在選択しているウィジェットのプロパティを詳細パネルに表示します。編集できるのは **一度に 1 つの
ウィジェット** です。多数のウィジェットに同じ変更を一括で適用するには、代わりに
[ツールバーのツール](./editing-tools#toolbar-tools) を使ってください。

表示される項目はウィジェットのタイプによって異なり、各ウィジェットのページでそれぞれ説明しています。
共通ブロック（位置、サイズ、回転、角の半径、ウィジェット名）は常に表示されます。

知っておくべき動作が 2 つあります。

- **編集中の内容は、選択が変わる前に確定されます。** ある項目を編集している途中で
  別のウィジェットをクリックすると、保留中の値は実際に編集していたウィジェットに確定されます。
  新しく選択したウィジェットに値が紛れ込むことはありません。
- **2D スライダーの同一チャンネル警告** は、パネル内に色付きのバナーとして表示されます。
  [2D スライダー](./widget-2d-slider) を参照してください。

## 角の半径 \{#corner-radius}

ウィジェットの角丸は 3 段階のカスケードで決まり、より具体的な設定が優先されます。

1. **ウィジェット単位のオーバーライド** — 個々のウィジェットに設定する「override corner radius」フラグと
   独自の値。
2. **タイプ単位の Class Default** — 各ウィジェットタイプは、ページの Class Defaults パネルで独自の
   デフォルト値を設定できます。
3. **グローバルデフォルト** — ボタン/スライダー/トグルの各タイプは 10、ラベルと画像はデフォルトで
   直角（0）です。グローバルなフォールバック値は [エディタ設定](./editor-settings) で調整できます。

カスタマイズしていないウィジェットはカスケードにリアルタイムで従います。タイプのデフォルト値を上げると、
オーバーライドしていないそのタイプのウィジェットがすべて一緒に更新されます。

## ウィジェットのロック \{#widget-locking}

どのウィジェットもロックできます。属性エディタのチェックボックス、Outliner の行やグループ見出しにある
ロックアイコン、または右クリックメニューの **ロック**/**選択項目のロックを解除** を使います。

ロックが影響するのは編集モードだけです。ロックしたウィジェットは編集モードでは選択・移動・リサイズができず、
移動/リサイズのハンドルも完全に消えます。ライブモードと Outliner の一覧自体には影響しません。
ロックしたウィジェットもライブモードでクリックすれば通常どおり動作し、Outliner では引き続き表示したり
名前を変更したりできます。Outliner の見出しから [レイヤーグループ](./editing-tools#layer-groups) をロックすると、
そのメンバーもすべて同じようにロックされます。

ロックは、配置が完了していて、周囲で作業中にうっかり動かしたくないウィジェット向けの機能です。
背景の画像や、完成したボタンの列などが該当します。

## ライブモードのツールチップ \{#live-mode-tooltip}

ライブモードでは、ウィジェットにカーソルを合わせると、その接続内容（名前と、操作するコントロール/アクター）を
まとめたツールチップが表示されます。見慣れないページを編集モードに入らずに確認する、最も手早い方法です。
