# ブックマーク \{#bookmarks}

*キャンバス用の名前付きカメラ位置です。*

全身用のピッカーでは、顔、手、足といった領域の間を頻繁に行き来します。ブックマークを使えば、
その移動がワンクリックになります。ブックマークはキャンバスのパン/ズームのビューを保存し、ヘッダー行にある
そのボタンをクリックするとキャンバスがその位置へ移動します。

## ブックマーク行 \{#the-bookmark-row}

- **デフォルト** は常に存在し、スクロールする行の外側に常に表示されています。「ホーム」として
  使ってください。
- **ユーザースロット**（デフォルトで 4 つ、最大 8 つ。[エディタ設定](./editor-settings) を参照）は、その横の
  横スクロールする行に並び、位置順に番号が付けられ、名前を付けることもできます。

## ブックマークの操作 \{#working-with-bookmarks}

| 操作 | 方法 |
|---|---|
| ビューに移動する | ボタンをクリック |
| 現在のビューを保存する | ボタンを **Ctrl+Shift+クリック**、または右クリック → 設定 / 上書き。確認としてボタンが緑色に点滅します |
| スロットの名前を変更する | 右クリック → 名前を変更 |
| スロットを追加する | 右クリック → 前にブックマークを追加 / 後ろにブックマークを追加 |
| 並べ替える | 右クリック → 左へ移動 / 右へ移動。入れ替わった両方のボタンがオレンジ色に点滅します |
| 削除 / リセットする | 右クリック → 削除、または Reset to Identity |

ブックマークの編集には、レイアウトのアンドゥとは完全に独立した**独自の 30 ステップのアンドゥスタック**があります。
キャンバス上で Ctrl+Z を押してもブックマークの変更が取り消されることはなく、ブックマークのアンドゥが
レイアウトに影響することもありません。

ブックマークは他のすべての内容とともにページファイルに保存されます。ボタンの幅、フォント、パディング、
2 つの確認点滅色は、Class Defaults パネルでページごとに調整できます。
