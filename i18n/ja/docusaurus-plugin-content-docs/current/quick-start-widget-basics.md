# ウィジェットの基本 \{#widget-basics}

### ウィジェットを作成する \{#create-widgets}

- 新しいウィジェットを作成するには、編集モードになっている必要があります
- キャンバスの空いている場所を右クリックするとポップアップメニューが開き、さまざまな種類のピッカーウィジェットを作成する項目が表示されます
- 新しいウィジェットは、右クリックしたときのマウスポインターの位置に配置されます。
- ウィジェットを作成すると元に戻すスタックに項目が追加されるため、作成を元に戻したりやり直したりできます

### ウィジェットを削除する \{#delete-widgets}

- ウィジェットを削除するには、編集モードになっている必要があります
- 「Delete」キーを押すと、選択しているウィジェットをすべて削除できます
- 1 つのウィジェットだけを削除するには、そのウィジェットを右クリックしてウィジェットのポップアップメニューを表示します。メニューの一番下に、そのウィジェットを削除する項目があります。
- ウィジェットを削除すると元に戻すスタックに項目が追加されるため、削除を元に戻したりやり直したりできます。

### ウィジェットを選択する \{#select-widgets}

- ウィジェットはライブモードと編集モードのどちらでも選択できます
- ウィジェットはクリックするか、周囲をボックスで囲むと選択できます
- ライブモードでは、一部のウィジェットは選択できません:
  - ラベルウィジェット
  - 画像ウィジェット
- 編集モードでは、すべてのウィジェットを選択できます
  - Outliner では、ウィジェットをロックして選択できないようにできます。複数のウィジェットが重なっている場合に便利です。
- ウィジェットを選択した順序は記憶されます。この選択順序は、編集モードの一部の機能で使用されます

### ウィジェットをトランスフォームする \{#transform-widgets}

- ウィジェットをトランスフォームするには、編集モードになっている必要があります
- **移動**
  - 1 つ以上のウィジェットを選択した状態で、選択中のウィジェットのいずれかにマウスを合わせ、カーソルを移動カーソルに変えます。そのままクリックしてドラッグすると、選択中のすべてのウィジェットがマウスに合わせて移動します。
- **回転**
  - マウスがウィジェット上にあり移動カーソルが表示されているときに Alt キーを押し続けると、カーソルが回転カーソルに変わります。そのままクリックしてドラッグすると、選択中のすべてのウィジェットが最後に選択したウィジェットを中心になめらかに回転します。
  - Alt キーと Shift キーを同時に押し続けると、15 度刻みで回転します
- ウィジェットをトランスフォームすると元に戻すスタックに項目が追加されるため、トランスフォームを元に戻したりやり直したりできます。

### ウィジェットのサイズを変更する \{#resize-widgets}

- ウィジェットのサイズを変更するには、編集モードになっている必要があります
- ウィジェットの辺や角にマウスポインターを合わせると、カーソルが辺または角のサイズ変更カーソルに変わります。そのままクリックしてドラッグすると、ウィジェットのサイズを変更できます。
- サイズ変更は 1 つのウィジェットに対してのみ行えます
- ウィジェットのサイズを変更すると元に戻すスタックに項目が追加されるため、サイズ変更を元に戻したりやり直したりできます。

### 切り取り、コピー、貼り付け \{#cut-copy-and-paste}

- ウィジェットの切り取り、コピー、貼り付けを行うには、編集モードになっている必要があります
- 選択中のウィジェットは、標準のショートカット Ctrl + X、Ctrl + C、Ctrl + V で切り取り、コピー、貼り付けができます
- 1 つのウィジェットであれば、右クリックしてポップアップメニューを表示すると、「切り取り」と「コピー」の項目があります
- Ctrl + V を使うと、マウスの位置にウィジェットが貼り付けられます
- キャンバスの空いている場所を右クリックすると、ポップアップメニューに 2 つの貼り付けオプションがあります
  - **貼り付け**
    - マウスの位置にウィジェットを貼り付けます
  - **その場に貼り付け**
    - コピーまたは切り取りを行ったときと同じ位置にウィジェットを貼り付けます

### ウィジェットのポップアップメニュー \{#widget-popup-menu}

- ウィジェットのポップアップメニューを表示するには、編集モードになっている必要があります
- ウィジェットを右クリックすると、ポップアップメニューが開きます
  - 最初の項目にはウィジェットの名前と種類、切り取りとコピーのオプションが表示されます
  - 最後の項目はウィジェットを削除するためのものです
  - その他のメニュー項目は、クリックしたウィジェットの種類によって異なります

### 属性エディタ \{#attribute-editor}

- 属性エディタを表示するには、編集モードになっている必要があります
- 属性エディタに属性が表示されるのは、ウィジェットが 1 つだけ選択されている場合のみです。複数のウィジェットを選択していると何も表示されません。(この動作は今後のリリースで変更される予定です)
- 最初の項目にはウィジェットの名前と種類が表示され、ウィジェットをロックして選択できないようにすることもできます
  - その他の項目は、選択したウィジェットの種類によって異なります

### Outliner \{#outliner}

- Outliner を表示するには、編集モードになっている必要があります
- Outliner には Picker Page 内のすべてのウィジェットが表示され、表示レイヤー別、ウィジェットの種類別、またはグループ別 (トグルウィジェットのグループ用) にまとめて表示されます
- キャンバスでウィジェットを選択すると Outliner の該当項目も選択され、その逆も同様です。
- Outliner のウィジェット項目をダブルクリックすると、ウィジェットの名前を変更できます
- 表示レイヤーのビューには、ウィジェットをロックまたはロック解除するチェックボックスがあります。ロックされたウィジェットは編集モードで選択できません。複数のウィジェットが重なっている場合に便利です。
- Outliner でウィジェットを選択すると、「F」キーでビューをそのウィジェットにフォーカスできます。特定のウィジェットが見つけにくいときに便利です
