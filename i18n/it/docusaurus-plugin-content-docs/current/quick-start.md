# Avvio rapido \{#quick-start}

#### Caricare un Control Rig del Mannequin \{#load-in-a-mannequin-control-rig}

<img src={useBaseUrl('/img/quick-start/quick-start/load-mannequin.png')} alt="load-mannequin" style={{marginLeft: 0, zoom: '67%'}} />

**Apri la Picker Page: Tools -> Ryan Tools -> Picker Page**

<img src={useBaseUrl('/img/quick-start/quick-start/start-picker-page.png')} alt="start-picker-page" style={{marginLeft: '0px', zoom: '80%'}} />

Apri la Picker Page predefinita per l'Epic Mannequin

**Picker Page: File -> Carica predefinita -> Epic Mannequin**

<img src={useBaseUrl('/img/quick-start/quick-start/open-epic-mannequin-picker.png')} alt="open-epic-mannequin-picker" style={{marginLeft: 0, zoom: '80%'}} />

Fai clic su uno dei pulsanti della Picker Page

<img src={useBaseUrl('/img/quick-start/quick-start/pick-mannequin-picker-button.png')} alt="pick-mannequin-picker-button" style={{marginLeft: 0, zoom: '50%'}} />

Trascina un riquadro attorno a più pulsanti per selezionare molti controlli contemporaneamente

<img src={useBaseUrl('/img/quick-start/quick-start/multi-select-mannequin-buttons.png')} alt="multi-select-mannequin-buttons" style={{marginLeft: 0, zoom: '67%'}} /><img src={useBaseUrl('/img/quick-start/quick-start/multi-select-mannequin-controls.png')} alt="multi-select-mannequin-controls" style={{zoom: '67%'}} />

Creiamo ora il nostro pulsante del picker.

Per prima cosa, partiamo da un'area di lavoro della Picker Page vuota

**Picker Page: File -> Nuova Picker Page**

<img src={useBaseUrl('/img/quick-start/quick-start/new-blank-picker-page.png')} alt="new-blank-picker-page" style={{marginLeft: 0, zoom: '67%'}} />

Se compare il popup Modifiche non salvate, fai semplicemente clic su "Sì"

<img src={useBaseUrl('/img/quick-start/quick-start/unsaved-changes-popup.png')} alt="unsaved-changes-popup" style={{marginLeft: 0, zoom: '80%'}} />

#### Ora entra in modalità di modifica. Basta fare clic sul pulsante interruttore "Modalità di modifica". \{#now-go-into-edit-mode--just-click-the-edit-mode-toggle-button}

Il pulsante diventa blu e l'area di lavoro della Picker Page avrà un bordo rosso.

<img src={useBaseUrl('/img/quick-start/quick-start/go-into-edit-mode.png')} alt="go-into-edit-mode" style={{marginLeft: 0, zoom: '50%'}} />

Vai nel viewport e seleziona uno dei controlli del Mannequin

<img src={useBaseUrl('/img/quick-start/quick-start/select-control-on-mannequin.png')} alt="select-control-on-mannequin" style={{marginLeft: 0, zoom: '67%'}} />

Torna alla Picker Page e fai clic destro su un punto vuoto dell'area di lavoro.

Si aprirà un menu contestuale da cui puoi aggiungere un widget del picker.

Fai clic sulla prima voce, "Pulsante di selezione"

<img src={useBaseUrl('/img/quick-start/quick-start/create-selection-button.png')} alt="create-selection-button" style={{marginLeft: 0, zoom: '67%'}} /><img src={useBaseUrl('/img/quick-start/quick-start/new-selection-button.png')} alt="new-selection-button" style={{marginLeft: 0, zoom: '100%'}} />

Qualunque controllo del Control Rig tu abbia selezionato verrà aggiunto al widget Pulsante di selezione al momento della creazione.

#### Fai clic sul pulsante interruttore Modalità di modifica per uscire dalla modalità di modifica. \{#click-on-the-edit-mode-toggle-button-to-get-out-of-edit-mode}

Se fai clic sinistro su un punto vuoto dell'area di lavoro, il pulsante verrà deselezionato. Verrà deselezionato anche il controllo del Control Rig.

<img src={useBaseUrl('/img/quick-start/quick-start/deselect-button.png')} alt="deselect-button" style={{marginLeft: 0, zoom: ''}} />

Se fai clic sul pulsante o tracci un riquadro attorno a esso, il pulsante verrà selezionato di nuovo. Verrà selezionato di nuovo anche il controllo del Control Rig. (In modalità di modifica viene selezionato solo il widget; il Control Rig non viene toccato.)

<img src={useBaseUrl('/img/quick-start/quick-start/box-select-button.png')} alt="box-select-button" style={{marginLeft: 0, zoom: ''}} />

<img src={useBaseUrl('/img/quick-start/quick-start/test-select-selection-button.png')} alt="test-select-selection-button" style={{marginLeft: 0, zoom: '80%'}} />

**Nota:** se selezioni prima il controllo del Control Rig, verrà selezionato il widget.

#### Ora torna in modalità di modifica. \{#now-go-back-into-edit-mode}

Se porti il mouse su un bordo o un angolo, vedrai il puntatore di ridimensionamento.

Se porti il mouse al centro del widget, vedrai il puntatore di spostamento.

Facendo clic con il puntatore di ridimensionamento o di spostamento potrai ridimensionare o spostare il widget.

<img src={useBaseUrl('/img/quick-start/quick-start/resize-widget-mouse-pointer.png')} alt="resize-widget-mouse-pointer" style={{marginLeft: 0, zoom: ''}} /><img src={useBaseUrl('/img/quick-start/quick-start/translate-widget-mouse-pointer.png')} alt="translate-widget-mouse-pointer" />

**Con il widget selezionato, apriamo l'Editor degli attributi.**

Il piccolo "+" nell'angolo in alto a destra dell'area di lavoro

<img src={useBaseUrl('/img/quick-start/quick-start/open-attribute-editor.png')} alt="open-attribute-editor" style={{marginLeft: 0, zoom: '67%'}} />

Nel gruppo Aspetto puoi cambiare i colori del widget

<img src={useBaseUrl('/img/quick-start/quick-start/change-widget-color.png')} alt="change-widget-color" style={{marginLeft: 0, zoom: '80%'}} />

Nel gruppo Testo puoi cambiare il testo dell'etichetta del pulsante

<img src={useBaseUrl('/img/quick-start/quick-start/change-widget-text.png')} alt="change-widget-text" style={{marginLeft: 0, zoom: ''}} />

Quando hai finito di modificare gli attributi del pulsante, puoi chiudere l'Editor degli attributi e creare altri widget.

#### Grazie per aver letto l'avvio rapido! \{#thanks-for-reading-through-the-quick-start}
