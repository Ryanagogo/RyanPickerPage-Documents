# Bug e feedback \{#bugs-and-feedback}

### Il menu Aiuto \{#the-help-menu}

Nell'angolo in alto a sinistra della Picker Page dovresti vedere il menu Aiuto accanto al menu File.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu.png')} alt="help-menu" style={{marginLeft: 0, zoom: '80%'}} />

Facendo clic sul menu Aiuto vedrai diverse voci utili, tra cui quelle per suggerire funzionalità, segnalare bug o inviarmi un messaggio.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu-items.png')} alt="help-menu-items" style={{marginLeft: 0, zoom: '80%'}} />

Ognuna di queste voci, quando viene cliccata, apre un link nel browser web per consentirti di compilare un modulo.

Suggerisci una funzionalità e Segnala un bug aggiungono elementi direttamente al mio sistema di gestione dei ticket, mentre Contattami invia un messaggio al mio indirizzo e-mail di lavoro.

Puoi anche usare questi link per accedere direttamente ai moduli:

- **[Segnala un bug](https://tally.so/r/ODx6Np)**
- **[Suggerisci una funzionalità](https://tally.so/r/D4RjLp)**
- **[Contattami](https://tally.so/r/RG9N6l)**
