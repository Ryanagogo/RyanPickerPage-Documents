# Widget Image \{#image-widget}

### Créer un nouveau widget Image \{#creating-a-new-image-widget}

Vous devez être en **mode édition** pour créer un nouveau widget Image

**Faites un clic droit sur une zone vide du canevas du picker** pour afficher le menu contextuel, puis cliquez sur l'élément « Image »

### Depuis l'Éditeur d'attributs \{#from-the-attribute-editor}

Pour voir les valeurs dans l'Éditeur d'attributs, vous devez sélectionner un seul widget

**Couleur**

- Définit la couleur du bouton

##### Image du widget Image \{#image-widget-image}

<img src={useBaseUrl('/img/quick-start/widget-image/image-widget-image.png')} alt="image-widget-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - Utilisez n'importe quel asset image de votre projet
- **Mode d'étirement**
  - Les différents modes déterminent la façon dont l'image est étirée pour tenter de remplir la taille du widget
- **Échelle**
  - Permet de zoomer ou dézoomer l'image
- **Décalage**
  - Permet de décaler l'image vers le haut, vers le bas et sur les côtés
- **Alpha**
  - Permet de définir la transparence de l'image. Plus elle est transparente, plus la couleur du widget est visible
