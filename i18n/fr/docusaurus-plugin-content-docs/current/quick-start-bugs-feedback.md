# Bugs et retours \{#bugs-and-feedback}

### Le menu Aide \{#the-help-menu}

Dans le coin supérieur gauche de la Picker Page, vous devriez voir le menu Aide à côté du menu Fichier.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu.png')} alt="help-menu" style={{marginLeft: 0, zoom: '80%'}} />

En cliquant sur le menu Aide, vous verrez plusieurs éléments utiles, notamment pour suggérer des fonctionnalités, signaler des bugs ou m'envoyer un message.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu-items.png')} alt="help-menu-items" style={{marginLeft: 0, zoom: '80%'}} />

Chacun de ces éléments ouvre un lien dans votre navigateur web afin que vous puissiez remplir un formulaire.

Suggérer une fonctionnalité et Signaler un bug ajoutent directement des éléments à mon système de suivi de tickets, et Me contacter envoie un message à mon adresse e-mail professionnelle.

Vous pouvez aussi utiliser ces liens pour accéder directement à ces formulaires :

- **[Signaler un bug](https://tally.so/r/ODx6Np)**
- **[Suggérer une fonctionnalité](https://tally.so/r/D4RjLp)**
- **[Me contacter](https://tally.so/r/RG9N6l)**
