# Démarrage rapide \{#quick-start}

#### Charger un Control Rig de Mannequin \{#load-in-a-mannequin-control-rig}

<img src={useBaseUrl('/img/quick-start/quick-start/load-mannequin.png')} alt="load-mannequin" style={{marginLeft: 0, zoom: '67%'}} />

**Ouvrir la Picker Page : Tools -> Ryan Tools -> Picker Page**

<img src={useBaseUrl('/img/quick-start/quick-start/start-picker-page.png')} alt="start-picker-page" style={{marginLeft: '0px', zoom: '80%'}} />

Ouvrez la Picker Page prédéfinie pour l'Epic Mannequin

**Picker Page : Fichier -> Charger un modèle prédéfini -> Epic Mannequin**

<img src={useBaseUrl('/img/quick-start/quick-start/open-epic-mannequin-picker.png')} alt="open-epic-mannequin-picker" style={{marginLeft: 0, zoom: '80%'}} />

Cliquez sur l'un des boutons de la Picker Page

<img src={useBaseUrl('/img/quick-start/quick-start/pick-mannequin-picker-button.png')} alt="pick-mannequin-picker-button" style={{marginLeft: 0, zoom: '50%'}} />

Tracez un rectangle autour de plusieurs boutons pour sélectionner plusieurs contrôles à la fois

<img src={useBaseUrl('/img/quick-start/quick-start/multi-select-mannequin-buttons.png')} alt="multi-select-mannequin-buttons" style={{marginLeft: 0, zoom: '67%'}} /><img src={useBaseUrl('/img/quick-start/quick-start/multi-select-mannequin-controls.png')} alt="multi-select-mannequin-controls" style={{zoom: '67%'}} />

Créons maintenant notre propre bouton de picker.

Commençons d'abord avec un canevas de Picker Page vierge

**Picker Page : Fichier -> Nouvelle Picker Page**

<img src={useBaseUrl('/img/quick-start/quick-start/new-blank-picker-page.png')} alt="new-blank-picker-page" style={{marginLeft: 0, zoom: '67%'}} />

Si une fenêtre Modifications non enregistrées s'affiche, cliquez simplement sur « Oui »

<img src={useBaseUrl('/img/quick-start/quick-start/unsaved-changes-popup.png')} alt="unsaved-changes-popup" style={{marginLeft: 0, zoom: '80%'}} />

#### Passez maintenant en mode édition. Cliquez simplement sur le bouton bascule « Mode édition ». \{#now-go-into-edit-mode--just-click-the-edit-mode-toggle-button}

Le bouton devient bleu et le canevas de la Picker Page s'entoure d'une bordure rouge.

<img src={useBaseUrl('/img/quick-start/quick-start/go-into-edit-mode.png')} alt="go-into-edit-mode" style={{marginLeft: 0, zoom: '50%'}} />

Allez dans le viewport et sélectionnez l'un des contrôles du Mannequin

<img src={useBaseUrl('/img/quick-start/quick-start/select-control-on-mannequin.png')} alt="select-control-on-mannequin" style={{marginLeft: 0, zoom: '67%'}} />

Revenez à la Picker Page et faites un clic droit sur une zone vide du canevas.

Un menu contextuel s'affiche pour vous permettre d'ajouter un widget de picker.

Cliquez sur le premier élément, « Bouton de sélection »

<img src={useBaseUrl('/img/quick-start/quick-start/create-selection-button.png')} alt="create-selection-button" style={{marginLeft: 0, zoom: '67%'}} /><img src={useBaseUrl('/img/quick-start/quick-start/new-selection-button.png')} alt="new-selection-button" style={{marginLeft: 0, zoom: '100%'}} />

Le contrôle Control Rig que vous avez sélectionné, quel qu'il soit, est ajouté au widget Bouton de sélection lors de sa création.

#### Cliquez sur le bouton bascule Mode édition pour quitter le mode édition. \{#click-on-the-edit-mode-toggle-button-to-get-out-of-edit-mode}

Si vous faites un clic gauche sur une zone vide du canevas, le bouton est désélectionné. Cela désélectionne aussi le contrôle Control Rig.

<img src={useBaseUrl('/img/quick-start/quick-start/deselect-button.png')} alt="deselect-button" style={{marginLeft: 0, zoom: ''}} />

Si vous cliquez sur le bouton ou tracez un rectangle autour, le bouton est de nouveau sélectionné. Cela sélectionne aussi de nouveau le contrôle Control Rig. (En mode édition, seul le widget est sélectionné ; le Control Rig n'est pas affecté.)

<img src={useBaseUrl('/img/quick-start/quick-start/box-select-button.png')} alt="box-select-button" style={{marginLeft: 0, zoom: ''}} />

<img src={useBaseUrl('/img/quick-start/quick-start/test-select-selection-button.png')} alt="test-select-selection-button" style={{marginLeft: 0, zoom: '80%'}} />

**Remarque :** si vous sélectionnez d'abord le contrôle Control Rig, le widget est sélectionné.

#### Repassez maintenant en mode édition. \{#now-go-back-into-edit-mode}

Si vous placez la souris sur un bord ou un coin, le pointeur de redimensionnement apparaît.

Si vous placez la souris au milieu du widget, le pointeur de déplacement apparaît.

En cliquant avec le pointeur de redimensionnement ou de déplacement, vous pouvez redimensionner ou déplacer le widget.

<img src={useBaseUrl('/img/quick-start/quick-start/resize-widget-mouse-pointer.png')} alt="resize-widget-mouse-pointer" style={{marginLeft: 0, zoom: ''}} /><img src={useBaseUrl('/img/quick-start/quick-start/translate-widget-mouse-pointer.png')} alt="translate-widget-mouse-pointer" />

**Le widget étant sélectionné, ouvrons l'Éditeur d'attributs.**

Le petit « + » dans le coin supérieur droit du canevas

<img src={useBaseUrl('/img/quick-start/quick-start/open-attribute-editor.png')} alt="open-attribute-editor" style={{marginLeft: 0, zoom: '67%'}} />

Dans le groupe Apparence, vous pouvez modifier les couleurs du widget

<img src={useBaseUrl('/img/quick-start/quick-start/change-widget-color.png')} alt="change-widget-color" style={{marginLeft: 0, zoom: '80%'}} />

Dans le groupe Texte, vous pouvez modifier le texte de l'étiquette du bouton

<img src={useBaseUrl('/img/quick-start/quick-start/change-widget-text.png')} alt="change-widget-text" style={{marginLeft: 0, zoom: ''}} />

Lorsque vous avez fini de modifier les attributs du bouton, vous pouvez fermer l'Éditeur d'attributs et créer d'autres widgets.

#### Merci d'avoir suivi ce démarrage rapide ! \{#thanks-for-reading-through-the-quick-start}
