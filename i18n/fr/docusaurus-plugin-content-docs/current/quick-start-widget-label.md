# Widget Étiquette \{#label-widget}

### Créer un nouveau widget Étiquette \{#creating-a-new-label-widget}

Vous devez être en **mode édition** pour créer un nouveau widget Étiquette

**Faites un clic droit sur une zone vide du canevas du picker** pour afficher le menu contextuel, puis cliquez sur l'élément « Étiquette »

### Depuis l'Éditeur d'attributs \{#from-the-attribute-editor}

Pour voir les valeurs dans l'Éditeur d'attributs, vous devez sélectionner un seul widget

##### Apparence de l'étiquette \{#label-appearance}

<img src={useBaseUrl('/img/quick-start/widget-label/label-appearance.png')} alt="label-appearance" style={{marginLeft: 0, zoom: '80%'}} />

- **Couleur**
  - Définit la couleur du bouton
- **Police**
  - Définit la couleur et la taille de la police

##### Texte de l'étiquette \{#label-text}

<img src={useBaseUrl('/img/quick-start/widget-label/label-text.png')} alt="label-text" style={{marginLeft: 0, zoom: '80%'}} />

- **Étiquette**

  - Définit le texte de l'étiquette

- **Styles de texte**

  - Pour les textes plus longs, vous pouvez utiliser les options suivantes pour mettre en forme le texte

    - Justification

    - Word Wrap

    - Margin

    - Clip

##### Image de l'étiquette \{#label-image}

<img src={useBaseUrl('/img/quick-start/widget-label/label-image.png')} alt="label-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - Utilisez n'importe quel asset image de votre projet
- **Mode d'étirement**
  - Les différents modes déterminent la façon dont l'image est étirée pour tenter de remplir la taille du widget
- **Échelle**
  - Permet de zoomer ou dézoomer l'image
- **Décalage**
  - Permet de décaler l'image vers le haut, vers le bas et sur les côtés
- **Alpha**
  - Permet de définir la transparence de l'image. Plus elle est transparente, plus la couleur du widget est visible
