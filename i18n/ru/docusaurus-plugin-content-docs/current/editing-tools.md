# Инструменты редактирования и холста \{#editing--canvas-tools}

Всё, что описано на этой странице, происходит в **режиме редактирования**. Сам холст можно панорамировать и масштабировать в обоих
режимах — стройте раскладку при любом удобном вам увеличении.

## Выделение \{#selection}

- Щёлкните по виджету, чтобы выделить его; Shift/Ctrl+щелчок расширяет выделение.
- Протяните мышью по пустому месту холста, чтобы выделить рамкой.
- У выделенных виджетов отображаются восемь маркеров изменения размера и маркер вращения, у каждого свой курсор.

Редактор атрибутов работает с одиночным выделением; инструменты панели инструментов, описанные ниже, позволяют редактировать много
виджетов сразу.

## Прямое манипулирование \{#direct-manipulation}

Перетащите виджет, чтобы переместить его. Перетащите маркер, чтобы изменить размер — изменение размера корректно работает и у повёрнутых
виджетов. Перетащите маркер вращения, чтобы повернуть виджет вокруг его центра; вращение хранится в
градусах, и повёрнутые виджеты полностью работают в режиме Live (повёрнутый слайдер перетаскивается вдоль
своей повёрнутой оси). Удерживайте Shift при вращении, чтобы привязываться к шагу 15°. Вращение выделения из нескольких виджетов
поворачивает всю группу как единое целое вокруг общей опорной точки (привязанной к последнему выделенному
виджету), при этом каждый виджет также продолжает вращаться вокруг собственного центра.

Заблокированный виджет не участвует ни в чём из этого — см. [Блокировка виджетов](./attribute-editor-and-outliner#widget-locking).

Клавиши со стрелками сдвигают выделение (с Shift — на больший шаг; оба расстояния — это Class
Defaults страницы). Инструмент **Сдвиг** на панели инструментов добавляет экранные стрелки с собственным расстоянием,
задаваемым в числовом поле, для повторяющихся точных шагов.

## Инструменты панели инструментов \{#toolbar-tools}

Одновременно активна одна строка инструментов; она переключается в заголовке:

| Инструмент | Действует на выделение |
|---|---|
| **Изображение** | назначает текстуру каждому выделенному виджету |
| **Цвет** | применяет цвет фона/шрифта к каждому выделенному виджету |
| **Метка** | задаёт текст метки и размер шрифта для всего выделения |
| **Размер** | задаёт точные ширину/высоту для всего выделения |
| **Сдвиг** | стрелки с фиксированным шагом, как описано выше |
| **Выровнять** | по левому/правому/верхнему/нижнему краю, по горизонтальному/вертикальному центру и равномерное распределение |
| **Зеркало** | см. ниже |

Изменения цвета с панели инструментов (и в редакторе атрибутов) объединяются, пока вы перетаскиваете внутри
палитры цветов, — один шаг отмены на один сеанс выбора цвета, а не на каждое движение мыши.

## Зеркало \{#mirror}

Строит одну сторону страницы из другой: **Mirror Horizontal** / **Mirror Vertical** отражают
положение каждого выделенного виджета относительно оси и инвертируют его вращение. Ось задаётся
выпадающим списком **Mirror Mode**:

| Режим | Отражает относительно |
|---|---|
| Сам | центра каждого виджета — виджеты переворачиваются на месте |
| Последний выбранный (вкл.) | центра последнего выделенного виджета; он тоже перемещается |
| Последний выбранный (искл.) | центра последнего выделенного виджета; он остаётся на месте |
| Видимый холст | центра видимой в данный момент области |

Отражение чисто геометрическое — оно не переименовывает контролы и не меняет каналы слайдеров. Обычный
порядок работы — отразить, затем перенастроить цели: отразите виджеты левой руки, а затем направьте копии на
контролы правой стороны. Для повторяемого отражения «лево/право», которое запоминает пары, см.
[Отражение позы](./mirror-pose).

## Группы слоёв \{#layer-groups}

Каждый виджет принадлежит одной **группе слоёв**, а порядок отрисовки — это просто участники каждой группы,
группа за группой, от переднего плана к заднему. Три группы — **Изображения**, **Метки**, **Контролы** — создаются
на каждой странице и не могут быть удалены (при удалении любой другой группы её участники возвращаются в
группу по умолчанию для своего типа). Помимо этих трёх, можно создавать, переименовывать, переупорядочивать и блокировать
сколько угодно групп — заблокированная группа блокирует все свои виджеты, так же как
[блокировка](./attribute-editor-and-outliner#widget-locking) отдельного виджета.

Щёлкните правой кнопкой по виджету, чтобы выбрать **Переместить на передний план / Step Up / Step Down / Отправить на задний план** в пределах его группы. Перемещение
виджета между группами, изменение порядка самих групп и блокировка выполняются в
[виде «По слою»](./attribute-editor-and-outliner#outliner-left) в Outliner — полный интерфейс управления
перетаскиванием описан на той странице.

## Копирование, вырезание, вставка \{#copy-cut-paste}

Ctrl+C / Ctrl+X / Ctrl+V для любого выделения. Вставка выполняется в позицию курсора; можно вставлять в другую открытую вкладку
страницы, а «Вставить на месте» сохраняет точные позиции при переносе между страницами.
Вставленные виджеты по возможности сохраняют имена, а дубликаты получают числовой суффикс. Группы
переключателей можно копировать и вставлять [целиком](./widget-toggle#toggle-groups).

## Значения виджетов по умолчанию \{#widget-defaults}

Внешний вид только что добавленного виджета определяется послойно, от наименее к наиболее конкретному:

1. **Class Defaults** — начальные значения для каждого типа (цвета, размеры, шрифты…), редактируемые на
   панели Class Defaults страницы, по одной категории на тип виджета.
2. **Sticky Defaults** — щёлкните правой кнопкой по любому виджету → **Copy to Sticky Defaults**, и последующие
   виджеты этого типа будут создаваться по его образцу. Какие категории свойств переносятся (цвет, шрифт, радиус угла,
   размер, вращение, текст, изображение), выбирается в [Настройках редактора](./editor-settings).

Это относится только к виджетам из меню Add Widget — вставленные и загруженные виджеты сохраняют собственные
данные.
