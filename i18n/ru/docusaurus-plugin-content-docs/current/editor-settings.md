# Настройки редактора \{#editor-settings}

**Файл → Settings…** открывает диалог глобальных настроек плагина. Это настройки **для конкретного компьютера**,
которые применяются ко всем открываемым страницам, в отличие от Class Defaults страницы (сохраняются в
Blueprint страницы) и данных файла (сохраняются в файле страницы).

## Поведение новых виджетов \{#new-widget-behavior}

| Настройка | По умолчанию | |
|---|---|---|
| Seed New Widget Targets From Selection | вкл. | новые кнопки/слайдеры заполняют цели из текущего выделения — см. [Как назначаются цели](./control-rig-and-targets#how-targets-get-assigned) |
| Default Interactive Selection Mode | выкл. | новые кнопки выбора создаются в [интерактивном режиме выбора](./widget-select-button#interactive-selection-mode) |
| Размер нового виджета по умолчанию | 200 × 100 | с флажком **Override**: если он снят, действует значение из Class Defaults страницы; если установлен, его заменяет значение из этого диалога |
| Радиус скругления по умолчанию | 10 | тот же принцип флажка Override; глобальное резервное значение в [каскаде скругления](./attribute-editor-and-outliner#corner-radius) |

## Категории Sticky Defaults \{#sticky-defaults-categories}

Семь флажков — **Цвет, Шрифт, Радиус угла, Размер, Вращение, Текст, Изображение**, по умолчанию все
включены — определяют, какие группы свойств
[Copy to Sticky Defaults](./editing-tools#widget-defaults) действительно переносит на новые виджеты.
Например, отключите Размер и Вращение, чтобы sticky defaults были чисто косметическими.

## Страница и обслуживание \{#page--housekeeping}

| Настройка | По умолчанию | |
|---|---|---|
| Количество закладок по умолчанию | 4 | пользовательские слоты [закладок](./bookmarks) на новой странице (макс. 8) |
| Глубина стека отмены | 30 | шаги отмены/повтора основной страницы |
| Макс. возраст состояния сессии | 90 дней | более старые записи [состояния сессии](./save-load-and-files#session-state) удаляются; 0 отключает удаление |

## Принцип переопределения \{#the-override-pattern}

Для значений, которые также существуют в Class Defaults страницы (размер виджета, радиус скругления), этот диалог
намеренно уступает: Class Defaults Blueprint страницы имеют приоритет, пока вы не установите здесь
соответствующий флажок **Override**. Так настройки общего Blueprint страницы по умолчанию остаются нетронутыми,
но отдельный компьютер всё же может настоять на собственных значениях.
