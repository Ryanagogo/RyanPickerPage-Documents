# Начало работы \{#getting-started}

## Открытие страницы \{#opening-a-page}

**Tools → Ryan Picker Page** открывает страницу в новой вкладке редактора. Кнопка **New Tab** в
заголовке страницы открывает дополнительные — каждая вкладка полностью независима: у неё свой файл, свой выбранный
Control Rig и свой вид холста. Переименование страницы (её заголовок можно редактировать в режиме редактирования) переименовывает
и вкладку, так что даже целый ряд открытых пикеров остаётся удобным для навигации.

## Два режима \{#two-modes}

Кнопка режима редактирования в заголовке переключает всю страницу между:

**Режимом Live** — режимом анимации. Щелчок по виджетам выделяет контролы рига и акторы; перетаскивание
слайдеров управляет трансформациями; при наведении на виджет появляется подсказка о том, с чем он связан. Саму
раскладку изменить нельзя.

**Готовая страница проводит свою жизнь в режиме Live.** Всё, что описано в разделе
[Инструменты редактирования и холста](./editing-tools), нужно только для того, чтобы привести вас сюда.

**Режимом редактирования** — режимом построения. У виджетов появляются маркеры перемещения, изменения размера и поворота, щелчок правой кнопкой
по пустому месту холста открывает меню **Add Widget**, и появляются две сворачиваемые боковые панели:
[Outliner](./attribute-editor-and-outliner) слева и
[Редактор атрибутов](./attribute-editor-and-outliner) справа.

## Создание первой страницы \{#build-your-first-page}

Минимальный пикер для одной ноги от начала до конца:

1. Откройте Level Sequence с вашим персонажем и его Control Rig, затем откройте страницу пикера.
   Выпадающий список ригов в заголовке заполняется из активной последовательности — выберите свой риг (он
   выбирается автоматически, если он один).
2. Перейдите в **режим редактирования**.
3. Во вьюпорте или в Anim Outliner выделите контрол бедра. Щёлкните правой кнопкой по холсту →
   **Add Widget → Кнопка выбора**. По умолчанию новая кнопка заполняет свой список целей из
   текущего выделения, поэтому эта кнопка уже управляет бедром.
4. Повторите для голени и стопы. Задайте имя каждой кнопке в поле метки в
   [Редакторе атрибутов](./attribute-editor-and-outliner) и перетащите их, выстроив
   столбик в форме ноги.
5. Выделите все три и попробуйте [инструменты выравнивания](./editing-tools), чтобы выровнять столбик.
6. Выйдите из режима редактирования. Щёлкайте по кнопкам — каждая выделяет свой контрол. Это и есть основной цикл; всё остальное —
   доработка.
7. **Файл → Сохранить** записывает страницу в JSON-файл в любом удобном месте — см.
   [Сохранение, загрузка и файлы](./save-load-and-files).

## Отмена, повтор и страховка \{#undo-redo-and-safety-nets}

Каждое изменение в режиме редактирования — перемещения, изменения размера, добавления, удаления, вставки, правки цвета — попадает в
стек отмены страницы (по умолчанию 30 шагов; см. [Настройки редактора](./editor-settings)). Ctrl+Z /
Ctrl+Y или кнопки в заголовке. Перетаскивание в палитре цветов объединяется в один шаг отмены,
а не по шагу на каждое движение, поэтому отмена изменения цвета отменяет всё перетаскивание целиком.

У [закладок](./bookmarks) свой отдельный стек отмены — отмена изменений раскладки никогда не затрагивает
сохранённые виды, и наоборот.

## Продолжение с того места, где вы остановились \{#picking-up-where-you-left-off}

Для каждого сохранённого файла плагин запоминает панорамирование и масштаб холста, активный Control Rig и
то, в каком режиме вы находились — редактирования или Live. Всё это автоматически восстанавливается при следующей загрузке
этого файла на этом компьютере. Эти данные хранятся вне файла страницы, поэтому, делясь страницей с
коллегой, вы передаёте раскладку, а не свои привычки просмотра. См.
[Сохранение, загрузка и файлы](./save-load-and-files#session-state).
