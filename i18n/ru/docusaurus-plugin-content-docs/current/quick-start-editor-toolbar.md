# Панель инструментов \{#toolbar}

**В режиме редактирования** панель инструментов находится в заголовке редактора

<img src={useBaseUrl('/img/quick-start/editor-toolbar/editor-toolbar.png')} alt="editor-toolbar" style={{marginLeft: 0, zoom: ''}} />

Эти инструменты позволяют выполнять различные действия с одним или несколькими выделенными виджетами пикера.

### Как это работает: \{#the-way-it-works}

- Выделите виджеты
- Нажмите кнопку на панели инструментов, чтобы открыть инструмент
- Измените значение в поле или нажмите кнопку
- Изменение значения или нажатие кнопки применяется ко всем выделенным виджетам

### Изображение \{#image}

<img src={useBaseUrl('/img/quick-start/editor-toolbar/image-tool.png')} alt="image-tool" style={{marginLeft: 0, zoom: ''}} />

**Этот инструмент действует на виджеты меток и изображений — у обоих может быть изображение.**

- Выделите виджеты меток или изображений, затем щёлкните по выпадающему списку, чтобы найти нужное изображение или добавить изображение, выделенное в Content Browser. Все выделенные виджеты будут использовать это изображение

### Цвет \{#color}

<img src={useBaseUrl('/img/quick-start/editor-toolbar/color-tool.png')} alt="color-tool" style={{marginLeft: 0, zoom: ''}} />

**Этот инструмент действует на все виджеты с цветом фона, а также на виджеты с текстом.**

- Выделите виджеты, затем щёлкните по цвету фона или шрифта и выберите нужный цвет в палитре. Все выделенные виджеты получат эти цвета

### Метка \{#label}

<img src={useBaseUrl('/img/quick-start/editor-toolbar/label-tool.png')} alt="label-tool" style={{marginLeft: 0, zoom: ''}} />

**Этот инструмент действует на виджеты с текстом.**

- Выделите виджеты, затем измените текст в поле «Метка» или значение размера шрифта. Текст всех выделенных виджетов обновится

### Размер \{#size}

<img src={useBaseUrl('/img/quick-start/editor-toolbar/size-tool.png')} alt="size-tool" style={{marginLeft: 0, zoom: ''}} />

**Этот инструмент действует на все виджеты**

- Выделите виджеты, затем измените значения ширины или высоты. Ширина или высота всех выделенных виджетов изменится

### Сдвиг \{#nudge}

<img src={useBaseUrl('/img/quick-start/editor-toolbar/nudge-tool.png')} alt="nudge-tool" style={{marginLeft: 0, zoom: ''}} />

**Этот инструмент действует на все выделенные виджеты**

- Выделите виджеты, затем измените значение сдвига. При нажатии одной из кнопок со стрелками все выделенные виджеты сдвинутся на это значение.

### Выровнять \{#align}

<img src={useBaseUrl('/img/quick-start/editor-toolbar/align-tool.png')} alt="align-tool" style={{marginLeft: 0, zoom: ''}} />

**Этот инструмент действует на все выделенные виджеты**

- Выделите виджеты, затем нажмите одну из кнопок выравнивания или распределения. Края всех выделенных виджетов будут выровнены, либо виджеты будут перемещены так, чтобы распределиться равномерно.
- При выравнивании опорой служит последний выделенный виджет, поэтому все остальные выделенные виджеты выравниваются по нему.

### Зеркало \{#mirror}

<img src={useBaseUrl('/img/quick-start/editor-toolbar/mirror-tool.png')} alt="mirror-tool" style={{marginLeft: 0, zoom: ''}} />

#### Этот инструмент действует на все выделенные виджеты \{#this-tool-affects-all-selected-widgets}

- Выделите виджеты, затем нажмите одну из кнопок переворота или отражения. Все выделенные виджеты будут перемещены в отражённые позиции

#### Для переворота (Mirror Flip) можно задать поведение. \{#for-the-mirror-flip-you-can-set-the-flip-behavior}

- **Сам:** каждый выделенный виджет переворачивается относительно собственной оси
- **Последний выбранный (вкл.):** все выделенные виджеты переворачиваются вокруг последнего выделенного виджета. Последний выделенный также переворачивается относительно своей оси
- **Последний выбранный (искл.):** все выделенные виджеты переворачиваются вокруг последнего выделенного виджета. Последний выделенный виджет не затрагивается и не двигается.
- **Видимый холст:** все выделенные виджеты переворачиваются относительно оси видимого холста

#### Чтобы работало «Отражение позы», нужно создать Pose Map для отражения. \{#for-mirror-pose-to-work-pose-mirror-maps-need-to-be-created}

- **Pose Map для отражения:** позволяют задать опорный виджет отражения, а также центральные виджеты и пары виджетов «лево/право».
- **Несколько карт на странице:** карт может быть больше одной — например, одна для тела и одна для лица.
