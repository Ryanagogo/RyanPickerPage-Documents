# Ошибки и отзывы \{#bugs-and-feedback}

### Меню «Справка» \{#the-help-menu}

В левом верхнем углу Picker Page рядом с меню «Файл» находится меню «Справка».

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu.png')} alt="help-menu" style={{marginLeft: 0, zoom: '80%'}} />

Щёлкнув по меню «Справка», вы увидите ряд полезных пунктов, в том числе пункты для предложения функций, сообщения об ошибках или отправки мне сообщения.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu-items.png')} alt="help-menu-items" style={{marginLeft: 0, zoom: '80%'}} />

Каждый из этих пунктов при щелчке открывает ссылку в веб-браузере, чтобы вы могли заполнить форму.

«Предложить функцию» и «Сообщить об ошибке» добавляют записи прямо в мою систему отслеживания задач, а «Связаться со мной» отправляет сообщение на мой рабочий адрес электронной почты.

Вы также можете перейти к нужным формам по этим ссылкам:

- **[Сообщить об ошибке](https://tally.so/r/ODx6Np)**
- **[Предложить функцию](https://tally.so/r/D4RjLp)**
- **[Связаться со мной](https://tally.so/r/RG9N6l)**
