# Редактор атрибутов и Outliner \{#attribute-editor--outliner}

Две боковые панели режима редактирования. У каждой есть свой переключатель в заголовке, поэтому на экране можно держать одну, обе или
ни одной.

## Outliner (слева) \{#outliner-left}

Список всего, что есть на странице: щёлкните по строке, чтобы выделить виджет, дважды щёлкните, чтобы переименовать,
щёлкните правой кнопкой, чтобы переместить/удалить. Три вида, переключаемых кнопками над списком:

- **По типу** — сгруппировано под заголовками шести типов виджетов. Повседневный вид.
- **По слою** — сгруппировано по [группам слоёв](./editing-tools#layer-groups) в порядке отрисовки. Именно
  здесь меняется наложение: перетащите виджет в другую группу, чтобы переместить его туда, перетащите
  внутри группы, чтобы изменить порядок, или перетащите сам заголовок группы, чтобы переупорядочить группы. У каждого заголовка группы
  есть свой переключатель блокировки, и группы сворачиваются независимо.
- **По группе** — [группы переключателей](./widget-toggle#toggle-groups) с участниками, вложенными
  под заголовок каждой именованной группы; здесь же переименовываются группы.

Имена виджетов уникальны в пределах страницы (без учёта регистра) — конфликтующее переименование отклоняется и
откатывается, а не искажается незаметно. Последний использованный вид запоминается глобально между сессиями.

## Редактор атрибутов (справа) \{#attribute-editor-right}

Свойства выделенного виджета на панели сведений. Он редактирует **по одному виджету
за раз** — чтобы применить одно и то же изменение ко многим виджетам, используйте
[инструменты панели инструментов](./editing-tools#toolbar-tools).

Набор полей зависит от типа виджета; на странице каждого виджета описан его собственный набор.
Общий блок — положение, размер, вращение, радиус угла, имя виджета — присутствует всегда.

Два поведения, о которых стоит знать:

- **Незавершённые правки фиксируются перед сменой выделения.** Если вы редактируете поле и
  щёлкаете по другому виджету, ожидающее значение записывается в тот виджет, который вы на самом деле
  редактировали, — оно не может «утечь» во вновь выделенный.
- **Предупреждение 2D-слайдера об одинаковом канале** отображается цветным баннером прямо в панели — см.
  [2D-слайдер](./widget-2d-slider).

## Радиус угла \{#corner-radius}

Скругление виджета определяется трёхуровневым каскадом, где побеждает самый конкретный уровень:

1. **Переопределение для виджета** — флажок «override corner radius» и собственное значение у
   конкретного виджета.
2. **Class Default для типа** — каждый тип виджета может задать собственное значение по умолчанию на панели Class
   Defaults страницы.
3. **Глобальное значение по умолчанию** — 10 для типов кнопка/слайдер/переключатель; у меток и изображений по умолчанию
   прямые углы (0). Глобальное резервное значение настраивается в [Настройках редактора](./editor-settings).

Ненастроенные виджеты следуют каскаду в реальном времени — увеличьте значение по умолчанию для типа, и все виджеты
этого типа без переопределения обновятся вместе с ним.

## Блокировка виджетов \{#widget-locking}

Любой виджет можно заблокировать — собственным флажком в редакторе атрибутов, значком замка в его строке
или заголовке группы в Outliner либо командой **Заблокировать**/**Разблокировать выделение** в контекстном меню.

Блокировка действует только в режиме редактирования: заблокированный виджет нельзя там выделить, переместить или изменить в размере, а
его маркеры перемещения/изменения размера полностью исчезают. Режим Live и сам список Outliner не затрагиваются
— заблокированный виджет работает как обычно при щелчке в режиме Live, и его по-прежнему можно видеть и
переименовывать в Outliner. Блокировка [группы слоёв](./editing-tools#layer-groups) из её заголовка в Outliner
точно так же блокирует всех её участников.

Блокировка предназначена для виджетов, с размещением которых вы уже закончили и которые не хотите случайно сдвинуть,
работая рядом с ними, — например, фоновое изображение или готовый ряд кнопок.

## Подсказка в режиме Live \{#live-mode-tooltip}

В режиме Live при наведении на любой виджет появляется подсказка с кратким описанием его связей — как он называется и
какими контролами/акторами управляет. Это самый быстрый способ разобраться в незнакомой странице, не
входя в режим редактирования.
