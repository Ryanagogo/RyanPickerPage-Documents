# Закладки \{#bookmarks}

*Именованные положения камеры для холста.*

В пикере для всего тела вы постоянно перескакиваете между областями — лицом, кистями, стопами. Закладки
превращают каждый такой переход в один щелчок: закладка хранит вид холста (панорамирование и масштаб), а щелчок по её кнопке в
строке заголовка мгновенно переносит туда холст.

## Строка закладок \{#the-bookmark-row}

- **По умолчанию** существует всегда и всегда видна, вне прокручиваемой строки — считайте её
  «домашней».
- **Пользовательские слоты** — по умолчанию 4, максимум 8 (см. [Настройки редактора](./editor-settings)) — располагаются в
  горизонтально прокручиваемой строке рядом с ней, нумеруются по позиции и могут получать имена.

## Работа с закладками \{#working-with-bookmarks}

| Действие | Как |
|---|---|
| Перейти к виду | щёлкнуть по кнопке |
| Сохранить текущий вид | **Ctrl+Shift+щелчок** по кнопке или правый щелчок → Задать / перезаписать — кнопка мигнёт зелёным для подтверждения |
| Переименовать слот | правый щелчок → Переименовать |
| Добавить слот | правый щелчок → Добавить закладку перед / Добавить закладку после |
| Изменить порядок | правый щелчок → Сдвинуть влево / Сдвинуть вправо — обе поменявшиеся местами кнопки мигнут оранжевым |
| Удалить / сбросить | правый щелчок → Удалить или Reset to Identity |

У изменений закладок есть **собственный стек отмены на 30 шагов**, полностью независимый от отмены изменений раскладки —
Ctrl+Z на холсте никогда не «съест» изменение закладки, а отмена в закладках никогда не затрагивает
раскладку.

Закладки сохраняются в файле страницы вместе со всем остальным. Ширину кнопок, шрифт, внутренние отступы и
два цвета мигания-подтверждения можно настроить для каждой страницы на панели Class Defaults.
