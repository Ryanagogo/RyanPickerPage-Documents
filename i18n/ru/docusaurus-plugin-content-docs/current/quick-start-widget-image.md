# Виджет изображения \{#image-widget}

### Создание нового виджета изображения \{#creating-a-new-image-widget}

Чтобы создать новый виджет изображения, нужно находиться в **режиме редактирования**

**Щёлкните правой кнопкой по пустому месту холста пикера**, чтобы открыть контекстное меню, затем выберите пункт «Изображение»

### В редакторе атрибутов \{#from-the-attribute-editor}

Чтобы увидеть значения в редакторе атрибутов, нужно выделить ровно один виджет

##### Изображение виджета изображения \{#image-widget-image}

<img src={useBaseUrl('/img/quick-start/widget-image/image-widget-image.png')} alt="image-widget-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - Используйте любой ассет изображения из вашего проекта
- **Режим растяжения**
  - Разные режимы определяют, как изображение растягивается, чтобы заполнить размер виджета
- **Масштаб**
  - Позволяет увеличивать и уменьшать изображение
- **Смещение**
  - Позволяет сдвигать изображение вверх, вниз и в стороны
- **Альфа**
  - Задаёт прозрачность изображения. Чем оно прозрачнее, тем больше виден цвет виджета
