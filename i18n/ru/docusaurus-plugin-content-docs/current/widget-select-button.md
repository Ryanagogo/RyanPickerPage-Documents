# Кнопка выбора \{#select-button}

*Рабочая лошадка: кнопка, которая выделяет объекты.*

## В режиме Live \{#in-live-mode}

Щелчок по кнопке выбора выделяет назначенные ей контролы Control Rig и целевые акторы — во
вьюпорте, в риге и в Sequencer, где они привязаны, — а затем выполняет её
[скрипт на Python](./python-scripting), если он есть. Кнопка может содержать один контрол или целый
набор («выделить все пальцы») и свободно сочетать контролы рига и обычные акторы.

**Ctrl+щелчок** переключает, а не заменяет: если цели кнопки ещё не все выделены,
они добавляются к текущему выделению; если уже выделены — удаляются из него. Остальная
часть выделения в обоих случаях не затрагивается.

## Два варианта поведения при выделении \{#two-selection-behaviors}

Кнопка выбора работает в одном из двух режимов, которые переключаются флажком **Интерактивный режим выбора**
в редакторе атрибутов:

### Режим набора выделения (по умолчанию) \{#selection-set-mode-default}

Кнопка — это сохранённый набор выделения. Щелчок → её цели становятся выделением. Кнопка
не отслеживает, что вы выделяете в других местах.

### Интерактивный режим выбора \{#interactive-selection-mode}

Кнопка становится живым отражением выделения в редакторе — так ведут себя традиционные пикеры
для анимации:

- Страница несколько раз в секунду опрашивает текущее выделение во вьюпорте/риге и **подсвечивает
  кнопку**, когда все её цели входят в текущее выделение: выделите контрол во
  вьюпорте — и его кнопка на странице подсветится сама.
- Щелчок выделяет **с добавлением**: цели кнопки присоединяются к уже выделенному,
  а не заменяют его, поэтому щелчки по нескольким интерактивным кнопкам постепенно собирают выделение.
- Ctrl+щелчок удаляет цели кнопки из выделения, как описано выше.

Этот режим рассчитан на **один контрол (или один актор) на кнопку**. Включить его на кнопке
с несколькими целями можно, но появится предупреждение: кнопка с несколькими целями не может
однозначно отражать частичное выделение. Опрос выполняется, только пока вкладка страницы находится на
переднем плане и режим редактирования выключен, поэтому фоновые вкладки ничего не стоят.

Новые кнопки по умолчанию могут создаваться в любом из режимов — это задаётся в [Настройках редактора](./editor-settings).

## Создание \{#authoring}

Когда кнопка выделена в режиме редактирования, редактор атрибутов показывает:

- **Метку** (и показывать ли её), имя виджета, размер шрифта
- **Цвет фона** и **цвет шрифта**
- **Имена контролов** — разрешаются относительно текущего рига страницы; см.
  [Control Rig и целевые акторы](./control-rig-and-targets)
- **Целевые акторы** — разрешённая, понятная сводка по всем назначенным акторам
- Флажок **Интерактивный режим выбора**
- **Скрипт Python** — многострочный; выполняется после выделения при каждом щелчке
- Положение, размер, вращение, радиус угла — общие для всех виджетов

Новые кнопки заполняют список целей тем, что выделено в момент их создания (это
[настройка](./editor-settings), включённая по умолчанию), — самый быстрый цикл создания: *выделить во
вьюпорте, добавить кнопку, готово*.

## Скрипты \{#scripting}

Функции Blueprint находятся в `URyanPickerSelectButtonFunctionLibrary`
(категория `Ryan Picker Page|SelectControl`); общие функции трансформации/внешнего вида — в
[общей библиотеке виджетов](./blueprint-api).

| Функция | |
|---|---|
| `GetControlNames` | имена назначенных контролов рига |
| `GetTargetActorGUIDs` / `GetTargetActorBindingGUIDs` | назначенные акторы в обоих пространствах идентификаторов — см. [Spawnable-объекты Sequencer](./control-rig-and-targets#sequencer-spawnables) |
| `GetBackgroundColor` / `SetBackgroundColor` | |
| `GetFontColor` / `SetFontColor` | |
| `GetFontSize` / `SetFontSize` | |
| `GetPythonScript` / `SetPythonScript` | |
| `GetInteractiveSelectionMode` / `SetInteractiveSelectionMode` | сеттер предупреждает (но не блокирует) для кнопок с несколькими целями |

Подклассы Blueprint могут реализовывать события интерфейса `BI_RyanPickerSelectButton`:
`OnSelectButtonConstructed`, `OnSelectButtonClicked`, `OnControlRigControlsSelected`,
`OnTargetActorsSelected`, а также [три события жизненного цикла](./blueprint-api#event-hooks), общие для всех
типов виджетов. О том, как подкласс появляется в меню Add Widget, см.
[Пользовательские Blueprint-виджеты](./blueprint-api#custom-widget-blueprints).
