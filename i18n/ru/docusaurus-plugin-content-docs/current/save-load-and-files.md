# Сохранение, загрузка и файлы \{#saving-loading--files}

Страница сохраняется в один **JSON-файл** в любом выбранном вами месте на диске. Страницы не являются ассетами
Unreal: они не хранятся в `Content/`, не требуют проекта, в котором были созданы, и ими можно
делиться, отправлять их по почте или хранить в системе контроля версий, как любой текстовый файл.

Одно сохранение содержит всю страницу: каждый виджет со всеми связями и стилями,
[строку закладок](./bookmarks), группы переключателей и [Pose Map](./mirror-pose).

## Меню «Файл» \{#the-file-menu}

| Пункт | |
|---|---|
| **Сохранить** | записывает в текущий файл страницы; для ни разу не сохранённой страницы работает как «Сохранить как» |
| **Сохранить как** | системный диалог сохранения |
| **Загрузить** | системный диалог открытия |
| **Загрузить недавнее** | недавно использованные файлы, без диалога |
| **Перезагрузить** | заново читает текущий файл с диска |
| **Pose Map…** | [диалог Pose Map](./mirror-pose#the-pose-map) |
| **Settings…** | диалог [Настройки редактора](./editor-settings) |

Диалоги сохранения и загрузки снова открываются в последних использованных каталогах.

## Меню «Справка» \{#the-help-menu}

Пункты этого меню полностью задаются данными — это список элементов Метка/URL/Подсказка, редактируемый на панели Class
Defaults страницы. Добавляйте, удаляйте, переупорядочивайте или перенаправляйте пункты без изменения кода и перекомпиляции;
щелчок по пункту открывает его URL в браузере ОС по умолчанию. Один пункт не задаётся данными, а
фиксирован: **О программе** — он показывает версию плагина, версию Unreal Engine и
автора в простом информационном окне.

## Старые файлы по-прежнему загружаются \{#old-files-keep-loading}

Файлы сохранения имеют версию схемы. При загрузке более старого файла он автоматически проходит миграцию через все
промежуточные изменения схемы — страницы из ранних версий плагина загружаются в
текущую, а простое повторное сохранение записывает их в текущей версии. Файлы, которые невозможно
мигрировать (или которые созданы *более новой* версией плагина, чем ваша), отклоняются с понятной ошибкой,
а не загружаются наполовину.

Замечание о конфиденциальности: [скрипт на Python](./python-scripting) кнопки выбора хранится в файле
в кодировке Base64 — закодирован, а не зашифрован. Относитесь к файлам страниц со скриптами так же, как
к самим скриптам.

## Состояние сессии \{#session-state}

Рядом с файлом страницы — но никогда не внутри него — плагин запоминает для каждого пути к файлу, где вы
остановились: панорамирование/масштаб холста, активный Control Rig, режим редактирования или Live. Загрузите тот же файл
завтра — и холст окажется ровно там, где вы его оставили. Поскольку эти данные хранятся на вашем компьютере с привязкой к пути
файла, при передаче страницы передаётся только раскладка — у получателей будет своё состояние вида.
Записи, не использовавшиеся 90 дней (настраивается), удаляются.

## Где плагин хранит собственные файлы \{#where-the-plugin-keeps-its-own-files}

```
%APPDATA%\RyanTechAnimTools\RyanPicker\
├── settings.json              # недавние файлы, последние каталоги диалогов, вид Outliner
├── editor_settings.json       # значения диалога «Настройки редактора»
└── page_session_state.json    # состояние сессии для каждого файла, по абсолютному пути
```

Они хранятся отдельно для каждого пользователя и компьютера. Их удаление лишает удобств (недавние файлы, восстановление
видов, настройки), но никогда — данных страниц: страницы существуют только в сохранённых вами файлах.
