# Метка \{#label}

*Текст на холсте. Щелчки проходят сквозь неё.*

Метки служат для пояснений: заголовки разделов («ЛЕВАЯ РУКА»), заметки или изображения с подписями. В режиме Live у них
нет реакции на щелчок и нет назначенных целей — а значит, это единственный тип виджета
(наряду с [Изображением](./widget-image)), который можно свободно накладывать поверх других, не перехватывая щелчки
окружающих контролов.

Метка может вместо фиксированного текста показывать в реальном времени **имя текущего Control Rig** — поместите её в
угол страницы, и она всегда подскажет аниматору, каким ригом управляет эта вкладка.

## Создание \{#authoring}

- **Текст**, размер шрифта, цвет шрифта, **выравнивание**, **автоперенос**
- **Цвет фона** и, при желании, фоновое **изображение** с собственным режимом растяжения и
  [кадрированием (панорамирование/масштаб)](./widget-image#crop-panzoom)
- **Альфа изображения** — непрозрачность этого фонового изображения поверх цвета фона, 0–1
- Радиус угла: по умолчанию углы у меток прямые (радиус 0), но они участвуют в том же
  [каскаде скругления](./attribute-editor-and-outliner#corner-radius), что и все остальные типы
- Общий блок положения/размера/вращения

Метки отрисовывают фон тем же материалом со скруглёнными углами, что и
[Изображение](./widget-image#rendering), поэтому скругление и кадрирование изображения работают у них одинаково.

## Скрипты \{#scripting}

`URyanPickerLabelFunctionLibrary` (категория `Ryan Picker Page|Label`):

| Функция | |
|---|---|
| `GetText` / `SetText` | |
| `GetFontSize` / `SetFontSize` · `GetFontColor` / `SetFontColor` | |
| `GetTextJustification` / `SetTextJustification` · `GetAutoWrapText` / `SetAutoWrapText` | |
| `GetBackgroundColor` / `SetBackgroundColor` | |
| `GetImage` / `SetImage` · `GetStretchMode` / `SetStretchMode` | фоновое изображение |
| `GetImageScale` / `SetImageScale` · `GetImageOffset` / `SetImageOffset` | кадрирование (панорамирование/масштаб) |
| `GetImageAlpha` / `SetImageAlpha` | ограничено диапазоном 0–1 |

У меток нет интерфейса событийных хуков — щёлкать и тянуть нечего, — но все
[общие функции виджетов](./blueprint-api) (положение, размер, вращение, радиус угла, имя)
к ним применимы.
