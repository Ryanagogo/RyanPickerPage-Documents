# 1D-слайдер \{#1d-slider}

*Слайдер, связанный ровно с одним каналом трансформации.*

## В режиме Live \{#in-live-mode}

Перетаскивание слайдера записывает его значение в **один канал** — перемещения, вращения или масштаба по X, Y
или Z — каждого назначенного контрола Control Rig и целевого актора. Больше ничего не затрагивается:
слайдер считывает текущую трансформацию каждой цели, подменяет единственный принадлежащий ему канал и записывает
трансформацию обратно. Изменения значений проходят тем же путём применения, что и весь остальной плагин,
включая автоключ Sequencer, поэтому движения слайдера ставят ключи так же, как контролы, сдвинутые вручную.

Поскольку 1D-слайдер никогда не захватывает чужие каналы, несколько слайдеров могут управлять разными
каналами *одного и того же* контрола одновременно — «подъём» через Перемещение Y и «перекат» через Вращение Z на одном
контроле стопы не будут конфликтовать.

Щелчок правой кнопкой по слайдеру предлагает **Сбросить к начальному значению**, возвращая его к заданному
значению по умолчанию.

## Модель значений \{#value-model}

Важны три числа, и меняются только два из них:

- **Минимальное значение / Максимальное значение** — диапазон, на который отображается перетаскивание.
- **Current Value** — текущее значение; перетаскивание записывает его, и именно оно применяется к целям.
- **Начальное значение** — заданное автором значение по умолчанию, которое перетаскивание *никогда* не трогает. Оно меняется только
  намеренно в редакторе атрибутов, поэтому это всегда безопасное значение, к которому может вернуться
  «Сбросить к начальному значению».

Необязательный **Размер шага** привязывает перетаскивание к приращениям, а **Заблокировано** полностью отключает
перетаскивание (для опорного слайдера, который не хочется случайно задеть посреди шота).

## Создание \{#authoring}

Поля редактора атрибутов: метка/имя, минимальное/максимальное/текущее/начальное значения, **Активный Channel** (единственный
канал, которым управляет этот слайдер), **Ориентация** (по горизонтали/по вертикали), цвет полосы, цвет ручки,
толщина полосы, стиль утопленной ручки, блокировка, размер шага — плюс поля назначения целей,
общие с [кнопкой выбора](./widget-select-button), и общий блок
положения/размера/вращения/радиуса угла.

## Скрипты \{#scripting}

`URyanPicker1DSliderFunctionLibrary` (категория `Ryan Picker Page|1DSlider`):

| Функция | |
|---|---|
| `GetMinValue` / `SetMinValue` · `GetMaxValue` / `SetMaxValue` | диапазон |
| `GetCurrentValue` / `SetCurrentValue` | текущее значение |
| `GetInitialValue` / `SetInitialValue` | заданная точка сброса |
| `GetActiveChannel` / `SetActiveChannel` | `EPickerSliderChannel`: Translate/Rotate/Scale × X/Y/Z |
| `GetOrientation` / `SetOrientation` | |
| `GetBarColor` / `SetBarColor` · `GetHandleColor` / `SetHandleColor` | |
| `GetBarThickness` / `SetBarThickness` · `GetHandleIndented` / `SetHandleIndented` | |
| `GetLocked` / `SetLocked` · `GetStepSize` / `SetStepSize` | |
| `GetControlNames` · `GetTargetActorGUIDs` / `GetTargetActorBindingGUIDs` | цели |

Подклассы Blueprint могут реализовывать `BI_RyanPicker1DSlider`: `OnSliderConstructed`,
`OnSliderValueChanged(float)`, `OnSliderDragBegin`, `OnSliderDragEnd(bool bValueChanged)`, а также
[общие события жизненного цикла](./blueprint-api#event-hooks).
