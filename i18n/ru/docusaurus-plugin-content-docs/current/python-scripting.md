# Скрипты на Python \{#python-scripting}

*Привяжите Python редактора к щелчку — без подкласса Blueprint и без компиляции.*

[Кнопки выбора](./widget-select-button) содержат один необязательный скрипт на Python;
[переключатели](./widget-toggle) — по одному **на каждое состояние**. Скрипт выполняется в среде Python редактора
(стандартный модуль `unreal` и всё остальное, что предоставляет Python Editor Script Plugin)
при каждом щелчке по виджету в режиме Live.

## Порядок выполнения \{#execution-order}

Скрипт выполняется **после** того, как щелчок завершил выделение: контролы выделены, акторы
выделены, состояние переключателя уже изменено. Поэтому скрипт может считать, что цели виджета —
это текущее выделение, и работать с ними:

```python
import unreal

# Выполняется, когда цели кнопки уже выделены.
for actor in unreal.EditorLevelLibrary.get_selected_level_actors():
    unreal.log(f"picker clicked: {actor.get_actor_label()}")
```

У переключателя выполняется скрипт того состояния, *в которое* он только что перешёл, — переключатель IK/FK может выполнять
логику сопоставления/привязки при каждом переходе в каждом направлении.

## Создание и хранение \{#authoring-and-storage}

Редактируйте скрипт в поле **Скрипт Python** редактора атрибутов, выделив виджет в
режиме редактирования, или из Blueprint через `GetPythonScript` / `SetPythonScript` (кнопка выбора) и
`GetPythonScriptForState` / `SetPythonScriptForState` (переключатель).

В сохранённом файле страницы скрипт хранится в кодировке Base64 — это деталь передачи, а не защита.
В интерфейсе редактора, в Blueprint и в памяти это обычный текст, и он выполняется с полными правами Python
редактора. **Загружайте страницы только из доверенных источников** — по тому же стандарту, что и любой
скрипт редактора, — и при проверке относитесь к общим файлам страниц как к коду.
