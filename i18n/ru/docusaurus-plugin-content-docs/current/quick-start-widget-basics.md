# Основы работы с виджетами \{#widget-basics}

### Создание виджетов \{#create-widgets}

- Чтобы создавать новые виджеты, нужно находиться в режиме редактирования
- Щёлкните правой кнопкой по пустому месту холста, чтобы открыть контекстное меню с пунктами для создания разных типов виджетов пикера
- Новый виджет появляется там, где находился указатель мыши в момент щелчка правой кнопкой.
- При создании виджетов в стек отмены добавляется запись, поэтому создание можно отменить и повторить

### Удаление виджетов \{#delete-widgets}

- Чтобы удалять виджеты, нужно находиться в режиме редактирования
- Все выделенные виджеты можно удалить клавишей «Delete»
- Чтобы удалить один виджет, щёлкните по нему правой кнопкой, чтобы открыть контекстное меню виджета. Внизу меню есть пункт для удаления этого виджета.
- При удалении виджетов в стек отмены добавляется запись, поэтому удаление можно отменить и повторить.

### Выделение виджетов \{#select-widgets}

- Выделять виджеты можно и в режиме Live, и в режиме редактирования
- Виджеты выделяются щелчком или рамкой, нарисованной вокруг них
- В режиме Live некоторые виджеты выделить нельзя:
  - Виджеты меток
  - Виджеты изображений
- В режиме редактирования выделить можно все виджеты
  - В Outliner можно заблокировать виджеты, чтобы их нельзя было выделить. Это удобно, когда несколько виджетов лежат друг на друге.
- Порядок выделения виджетов запоминается. Некоторые функции режима редактирования используют этот порядок

### Трансформация виджетов \{#transform-widgets}

- Чтобы трансформировать виджеты, нужно находиться в режиме редактирования
- **Перемещение**
  - Выделив один или несколько виджетов, наведите мышь на один из выделенных виджетов, чтобы курсор сменился на курсор перемещения. Затем щёлкните и перетащите — все выделенные виджеты будут двигаться вместе с мышью.
- **Вращение**
  - Когда мышь находится над виджетом и отображается курсор перемещения, удерживайте клавишу Alt — курсор сменится на курсор вращения. Затем щёлкните и перетащите — все выделенные виджеты будут плавно вращаться вокруг последнего выделенного виджета.
  - Если удерживать одновременно Alt и Shift, вращение будет происходить шагами по 15 градусов
- При трансформации виджетов в стек отмены добавляется запись, поэтому трансформации можно отменить и повторить.

### Изменение размера виджетов \{#resize-widgets}

- Чтобы изменять размер виджетов, нужно находиться в режиме редактирования
- Если навести указатель мыши на край или угол виджета, курсор сменится на курсор изменения размера по краю или по углу. Затем щёлкните и перетащите, чтобы изменить размер виджета.
- Изменение размера работает только для одного виджета
- При изменении размера виджетов в стек отмены добавляется запись, поэтому изменение размера можно отменить и повторить.

### Вырезание, копирование и вставка \{#cut-copy-and-paste}

- Чтобы вырезать, копировать и вставлять виджеты, нужно находиться в режиме редактирования
- Для вырезания, копирования и вставки выделенных виджетов можно использовать стандартные сочетания Ctrl + X, Ctrl + C и Ctrl + V
- Для одного виджета можно щёлкнуть по нему правой кнопкой и открыть контекстное меню — там есть пункты «Вырезать» и «Копировать»
- Ctrl + V вставляет виджеты в позицию указателя мыши
- Если щёлкнуть правой кнопкой по пустому месту холста, в контекстном меню будут два варианта вставки
  - **Вставить**
    - Вставляет виджеты в позицию указателя мыши
  - **Вставить на месте**
    - Вставляет виджеты туда же, откуда они были скопированы или вырезаны

### Контекстное меню виджета \{#widget-popup-menu}

- Чтобы видеть контекстные меню виджетов, нужно находиться в режиме редактирования
- При щелчке правой кнопкой по виджету открывается контекстное меню
  - Первые пункты показывают имя и тип виджета, а также варианты вырезания и копирования
  - Последний пункт служит для удаления виджета
  - Остальные пункты зависят от типа виджета, по которому вы щёлкнули

### Редактор атрибутов \{#attribute-editor}

- Чтобы видеть редактор атрибутов, нужно находиться в режиме редактирования
- Редактор атрибутов показывает атрибуты, только когда выделен ровно один виджет. Если выделено несколько, ничего не отображается. (Это поведение изменится в одной из будущих версий)
- Первые пункты сообщают имя и тип виджета и позволяют заблокировать виджет, чтобы его нельзя было выделить
  - Остальные пункты зависят от типа выделенного виджета

### Outliner \{#outliner}

- Чтобы видеть Outliner, нужно находиться в режиме редактирования
- Outliner показывает все виджеты Picker Page, сгруппированные по слою отображения, по типу виджета или по группе (последнее относится к группам виджетов-переключателей)
- Если виджет выделен на холсте, его элемент в Outliner тоже выделен, и наоборот.
- Двойной щелчок по элементу виджета в Outliner позволяет переименовать виджет
- В режиме отображения по слоям есть флажки для блокировки и разблокировки виджетов. Заблокированные виджеты нельзя выделить в режиме редактирования. Это удобно, когда несколько виджетов лежат друг на друге.
- Выделив виджет в Outliner, можно нажать клавишу «F», чтобы сфокусировать вид на нём. Это помогает, если конкретный виджет трудно найти
