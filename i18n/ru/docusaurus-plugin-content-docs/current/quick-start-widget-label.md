# Виджет метки \{#label-widget}

### Создание нового виджета метки \{#creating-a-new-label-widget}

Чтобы создать новый виджет метки, нужно находиться в **режиме редактирования**

**Щёлкните правой кнопкой по пустому месту холста пикера**, чтобы открыть контекстное меню, затем выберите пункт «Метка»

### В редакторе атрибутов \{#from-the-attribute-editor}

Чтобы увидеть значения в редакторе атрибутов, нужно выделить ровно один виджет

##### Внешний вид метки \{#label-appearance}

<img src={useBaseUrl('/img/quick-start/widget-label/label-appearance.png')} alt="label-appearance" style={{marginLeft: 0, zoom: '80%'}} />

- **Цвет**
  - Задаёт цвет кнопки
- **Шрифт**
  - Задаёт цвет и размер шрифта

##### Текст метки \{#label-text}

<img src={useBaseUrl('/img/quick-start/widget-label/label-text.png')} alt="label-text" style={{marginLeft: 0, zoom: '80%'}} />

- **Метка**

  - Задаёт текст метки

- **Стили текста**

  - Для более длинного текста можно использовать следующие параметры форматирования

    - Justification

    - Word Wrap

    - Margin

    - Clip

##### Изображение метки \{#label-image}

<img src={useBaseUrl('/img/quick-start/widget-label/label-image.png')} alt="label-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - Используйте любой ассет изображения из вашего проекта
- **Режим растяжения**
  - Разные режимы определяют, как изображение растягивается, чтобы заполнить размер виджета
- **Масштаб**
  - Позволяет увеличивать и уменьшать изображение
- **Смещение**
  - Позволяет сдвигать изображение вверх, вниз и в стороны
- **Альфа**
  - Задаёт прозрачность изображения. Чем оно прозрачнее, тем больше виден цвет виджета
