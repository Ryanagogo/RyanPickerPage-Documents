# Горячие клавиши \{#hotkeys}

Все сочетания клавиш и жесты мыши, на которые реагирует редактор пикера.

### Правила фокуса и режимов \{#focus-and-mode-rules}

- **Сочетания клавиш работают, только когда фокус находится на холсте.** Холст получает фокус, как только вы по нему щёлкнете. Если фокус находится в поле боковой панели или в списке Outliner, нажатия клавиш уходят туда.
- В режиме Live работает только сочетание **F**. Все остальные сочетания клавиш работают только в режиме редактирования.
- Панорамирование перетаскиванием правой кнопкой и масштабирование колесом мыши работают как в режиме редактирования, так и в режиме Live.

### Клавиатура \{#keyboard}

| Клавиша | Действие | Режим |
|---|---|---|
| **Delete** | Удалить выделенные виджеты | Только редактирование |
| **F** | Центрировать вид холста на текущем выделении (масштаб не меняется) | Редактирование + Live |
| **Alt + щелчок по кнопке** | Центрировать вьюпорт на объектах, выделенных щелчком по кнопке |Только Live|
| **Alt + выделение кнопок рамкой** | Центрировать вьюпорт на объектах, выделенных рамкой по кнопкам |Только Live|
| **Клавиши со стрелками** | Сдвинуть выделение (по умолчанию 2 px) | Только редактирование |
| **Shift + клавиши со стрелками** | Сдвинуть выделение на больший шаг (по умолчанию 10 px) | Только редактирование |
| **Ctrl + X** | Вырезать выделенные виджеты | Только редактирование |
| **Ctrl + C** | Копировать выделенные виджеты | Только редактирование |
| **Ctrl + V** | Вставить в позиции курсора мыши | Только редактирование |
| **Ctrl + Z** | Отменить | Только редактирование |
| **Ctrl + Shift + Z** или **Ctrl + Y** | Повторить | Только редактирование |

Оба расстояния сдвига с клавиатуры задаются на панели Class Defaults страницы. Они не связаны с инструментом **Сдвиг** на панели инструментов, у которого есть собственное поле расстояния.

Копирование / вырезание / вставка работают между открытыми вкладками страниц.

**Не назначены:** нет Ctrl+A (выделить всё), Ctrl+S (сохранить), Ctrl+D (дублировать) и Esc (снять выделение). Дублирование, выравнивание, распределение и отражение доступны только в контекстном меню или на панели инструментов.

### Мышь — выделение виджетов \{#mouse---selecting-widgets}

Поведение выделения меняют только Ctrl и Shift.

| Жест | Действие |
|---|---|
| Щелчок по виджету | Выделить только этот виджет |
| Ctrl + щелчок по виджету | Добавить виджет к выделению или убрать его из выделения |
| Shift + щелчок по виджету | Добавить виджет к выделению |
| Щелчок по пустому месту холста | Снять выделение |
| Перетаскивание по пустому месту холста | Нарисовать рамку выделения |
| Ctrl или Shift + перетаскивание рамки выделения | Добавить попавшие в рамку виджеты к текущему выделению, а не заменить его |
| Щелчок по строке в Outliner | Выделяет этот виджет — работает даже для заблокированных виджетов |
| Двойной щелчок по строке в Outliner | Переименовать |

### Мышь — перемещение, изменение размера, вращение (режим редактирования) \{#mouse---moving-resizing-rotating-edit-mode}

Восемь маркеров изменения размера и маркер перемещения появляются только в режиме редактирования.

| Жест | Действие |
|---|---|
| Перетащить маркер перемещения | Переместить выделенные виджеты |
| **Alt** + перетащить маркер перемещения | Вращать вместо перемещения |
| **Alt + Shift** + перетащить маркер перемещения | Вращать с привязкой к шагу 15 градусов |
| Перетащить маркер края или угла | Изменить размер (корректно работает и для повёрнутых виджетов) |

Чтобы начать вращение, зажмите Alt перед нажатием на маркер перемещения. Удерживайте Shift во время перетаскивания для привязки.

### Мышь — навигация по холсту \{#mouse---navigating-the-canvas}

| Жест | Действие | Режим |
|---|---|---|
| Колесо мыши | Масштабировать к курсору | Редактирование + Live |
| Перетаскивание правой кнопкой | Панорамировать холст | Редактирование + Live |
| Щелчок правой кнопкой (без перетаскивания) | Открыть контекстное меню | Только редактирование |
| Перетащить разделитель боковой панели | Изменить размер панели Outliner или редактора атрибутов | Только редактирование |

### Закладки \{#bookmarks}

| Жест | Действие |
|---|---|
| Щелчок по закладке | Применить сохранённый вид |
| **Ctrl + Shift + щелчок** по закладке | Сохранить текущий вид в эту закладку (перезаписав её) |
| Щелчок правой кнопкой по закладке | Переименовать или очистить её |
