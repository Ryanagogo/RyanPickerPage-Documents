# 启动 Picker Page 编辑器 \{#starting-the-picker-page-editor}

### 插件 \{#the-plugin}

确保已启用 **RyanPickerPage** 插件

<img src={useBaseUrl('/img/quick-start/starting-the-picker-page-editor/enable-plugin.png')} alt="enable-plugin" style={{display: 'block', marginLeft: 0, marginRight: 'auto'}} />

### 打开编辑器 \{#opening-the-editor}

打开 Tools 菜单

<img src={useBaseUrl('/img/quick-start/starting-the-picker-page-editor/find-tools-menu.png')} alt="find-tools-menu" style={{display: 'block', marginLeft: 0, marginRight: 'auto'}} />

然后找到 **Ryan Tools -> Picker Page**

<img src={useBaseUrl('/img/quick-start/starting-the-picker-page-editor/find-ryan-tools-picker-page.png')} alt="find-ryan-tools-picker-page" style={{display: 'block', marginLeft: 0, marginRight: 'auto'}} />

此时应会打开一个空白的 Picker Page 编辑器（Editor Utility Widget）

<img src={useBaseUrl('/img/quick-start/starting-the-picker-page-editor/blank-picker-page-editor.png')} alt="blank-picker-page-editor" style={{display: 'block', marginLeft: 0, marginRight: 'auto'}} />
