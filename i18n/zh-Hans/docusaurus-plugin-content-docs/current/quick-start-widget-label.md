# 标签部件 \{#label-widget}

### 创建新的标签部件 \{#creating-a-new-label-widget}

必须处于**编辑模式**才能创建新的标签部件

**右键单击拾取器画布的空白处**以弹出菜单，然后单击“标签”菜单项

### 在属性编辑器中 \{#from-the-attribute-editor}

要在属性编辑器中查看数值，需要只选中一个部件

##### 标签外观 \{#label-appearance}

<img src={useBaseUrl('/img/quick-start/widget-label/label-appearance.png')} alt="label-appearance" style={{marginLeft: 0, zoom: '80%'}} />

- **颜色**
  - 设置按钮的颜色
- **字体**
  - 设置字体颜色和字体大小

##### 标签文本 \{#label-text}

<img src={useBaseUrl('/img/quick-start/widget-label/label-text.png')} alt="label-text" style={{marginLeft: 0, zoom: '80%'}} />

- **标签**

  - 设置标签中的文本

- **文本样式**

  - 对于较长的文本，可以使用以下选项来帮助排版

    - Justification

    - Word Wrap

    - Margin

    - Clip

##### 标签图像 \{#label-image}

<img src={useBaseUrl('/img/quick-start/widget-label/label-image.png')} alt="label-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - 可使用项目中的任意图像资产
- **拉伸模式**
  - 不同的模式决定图像如何拉伸以尽量填满部件的大小
- **缩放**
  - 可以放大或缩小图像
- **偏移**
  - 可以将图像上下、左右移动
- **Alpha**
  - 可以设置图像的透明度。越透明，就越能看到部件本身的颜色
