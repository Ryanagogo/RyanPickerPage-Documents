# 编辑与画布工具 \{#editing--canvas-tools}

本页的所有操作都在**编辑模式**下进行。画布本身在两种模式下都可以平移和缩放——
以你觉得舒适的任何缩放级别进行搭建。

## 选择 \{#selection}

- 单击部件即可选中；Shift/Ctrl+单击可扩展选择。
- 在画布空白处拖动可框选。
- 选中的部件会显示八个缩放手柄和一个旋转手柄，每个手柄都有自己的光标。

属性编辑器针对单个选择；如需一次编辑多个部件，请使用下面的工具栏
工具。

## 直接操作 \{#direct-manipulation}

拖动部件可移动它。拖动手柄可调整大小——对已旋转的部件同样能正确调整大小。
拖动旋转手柄可让部件绕其中心旋转；旋转以
角度存储，已旋转的部件在实时模式下仍完全可用（旋转后的滑块沿
旋转后的轴拖动）。旋转时按住 Shift 可按 15° 增量吸附。旋转多个部件的选择时，
整组会以一个共同的轴心（锚定在最后选中的部件上）整体刚性旋转，
同时每个部件也会绕自己的中心旋转。

被锁定的部件不受上述任何操作影响——请参阅 [部件锁定](./attribute-editor-and-outliner#widget-locking)。

方向键可微移选择（按 Shift 步长更大；两个距离都是页面的 Class
Defaults）。工具栏中的 **微移** 工具会添加屏幕箭头，其距离由单独的数值框设置，
用于重复、精确的步进。

## 工具栏工具 \{#toolbar-tools}

同一时间只有一行工具处于活动状态，可在标题栏中切换：

| 工具 | 对选择的作用 |
|---|---|
| **图像** | 为每个选中的部件指定纹理 |
| **颜色** | 将背景/字体颜色应用到每个选中的部件 |
| **标签** | 为整个选择设置标签文本和字体大小 |
| **大小** | 为整个选择设置精确的宽度/高度 |
| **微移** | 固定步长的箭头，如上所述 |
| **对齐** | 左/右/上/下、水平/垂直居中以及均匀分布 |
| **镜像** | 见下文 |

通过工具栏（以及属性编辑器）进行的颜色编辑，在取色器内拖动期间会合并——
每次颜色编辑只产生一个撤销步骤，而不是每次鼠标移动都产生一个。

## 镜像 \{#mirror}

根据页面的一侧搭建另一侧：**Mirror Horizontal** / **Mirror Vertical** 会将
每个选中部件的位置沿某条轴镜像，并将其旋转取反。轴由
**Mirror Mode** 下拉列表设置：

| 模式 | 镜像所依据的轴 |
|---|---|
| 自身 | 每个部件自己的中心——部件原地翻转 |
| 最后选中(含) | 最后选中部件的中心；它也会移动 |
| 最后选中(不含) | 最后选中部件的中心；它保持不动 |
| 可见画布 | 当前可见区域的中心 |

镜像只是几何操作——不会重命名控制点，也不会交换滑块通道。通常的
工作流程是先镜像再重新指定目标：镜像左臂的部件，然后把副本指向
右侧的控制点。如需可重复、并能记住配对关系的左右镜像，请参阅
[镜像姿势](./mirror-pose)。

## 图层组 \{#layer-groups}

每个部件都属于一个**图层组**，绘制顺序就是按组依次排列各组成员，
从前到后。三个组——**图像**、**标签**、**控制点**——会在
每个页面上预先创建且无法删除（删除其他任何组时，其成员会被重新分配回
各自类型的默认组）。除这三个组外，你可以创建、重命名、重新排序和锁定
任意数量的组——锁定的组会锁定其中的每个部件，与单个部件的
[锁定](./attribute-editor-and-outliner#widget-locking) 效果相同。

右键单击部件可在其所在组内执行 **移到最前 / Step Up / Step Down / 移到最后**。在组之间移动
部件、重新排列组本身以及锁定，都在 Outliner 的
[按图层视图](./attribute-editor-and-outliner#outliner-left) 中完成——完整的拖放管理界面
请参阅该页面。

## 复制、剪切、粘贴 \{#copy-cut-paste}

可对任何选择使用 Ctrl+C / Ctrl+X / Ctrl+V。粘贴内容会落在光标处；可以粘贴到另一个已打开的页面
标签页中，原位粘贴会在页面间传输时保留精确位置。
粘贴的部件会尽可能保留原名称，重名时会添加数字后缀。开关
组可以[作为整组](./widget-toggle#toggle-groups)复制和粘贴。

## 部件默认值 \{#widget-defaults}

新添加部件的外观是分层决定的，越靠后越具体：

1. **Class Defaults**——每种类型的初始值（颜色、大小、字体……），可在页面的
   Class Defaults 面板中编辑，每种部件类型一个类别。
2. **Sticky Defaults**——右键单击任意部件 → **Copy to Sticky Defaults**，之后
   新建的该类型部件就会与之一致。哪些属性类别会被沿用（颜色、字体、圆角半径、
   大小、旋转、文本、图像）在 [编辑器设置](./editor-settings) 中选择。

这些仅适用于通过 Add Widget 菜单添加的部件——粘贴和加载的部件会保留各自的
数据。
