# 属性编辑器与 Outliner \{#attribute-editor--outliner}

编辑模式下的两个侧边栏。每个侧边栏在标题栏中都有自己的开关，因此你可以让其中一个、两个都、
或者都不显示在屏幕上。

## Outliner（左侧） \{#outliner-left}

页面上所有内容的列表——单击某一行可选中该部件，双击可重命名，
右键单击可移动/删除。列表上方的按钮可在三种视图之间切换：

- **按类型**——按六种部件类型的标题分组。日常使用的视图。
- **按图层**——按 [图层组](./editing-tools#layer-groups) 分组，按绘制顺序排列。层叠顺序
  就在这里调整：把部件拖到另一个组中即可移动到该组，在组内拖动可重新排序，
  拖动组标题本身则可重新排列组的顺序。每个组标题
  都有自己的锁定开关，并可独立折叠。
- **按组**——[开关组](./widget-toggle#toggle-groups)，其成员嵌套在
  每个命名标题下；组的重命名也在这里进行。

部件名称在每个页面内唯一（不区分大小写）——发生冲突的重命名会被拒绝并
还原，而不会被悄悄改成别的名字。上次使用的视图会在各会话之间全局记住。

## 属性编辑器（右侧） \{#attribute-editor-right}

在详细信息面板中显示当前选中部件的属性。它**一次只编辑一个
部件**——如需将同一更改应用到多个部件，请改用
[工具栏工具](./editing-tools#toolbar-tools)。

显示哪些字段取决于部件的类型；每个部件页面都记录了各自的字段。
通用属性块——位置、大小、旋转、圆角半径、部件名称——始终存在。

有两个行为值得了解：

- **正在进行的编辑会在选择更改之前提交。** 如果你正在编辑某个字段时
  单击了另一个部件，待提交的值会提交到你实际正在编辑的部件上——
  不会串到新选中的部件上。
- **2D 滑块的同通道警告** 会以彩色横幅的形式直接显示在面板中——请参阅
  [2D 滑块](./widget-2d-slider)。

## 圆角半径 \{#corner-radius}

部件的圆角由一个三级级联决定，越具体的设置优先级越高：

1. **按部件覆盖**——在单个部件上设置“override corner radius”标志
   以及自定义值。
2. **按类型的 Class Default**——每种部件类型都可以在页面的 Class
   Defaults 面板中设置自己的默认值。
3. **全局默认值**——按钮/滑块/开关类型为 10；标签和图像默认为
   直角（0）。全局后备值可在 [编辑器设置](./editor-settings) 中调整。

未自定义的部件会实时跟随级联——提高某类型的默认值，该类型所有未覆盖的
部件都会随之更新。

## 部件锁定 \{#widget-locking}

任何部件都可以锁定——通过属性编辑器中的复选框、Outliner 中该部件所在行
或组标题上的锁定图标，或右键菜单中的 **锁定**/**解锁所选内容**。

锁定只影响编辑模式：被锁定的部件在编辑模式下无法被选中、移动或调整大小，
其移动/调整大小手柄也会完全消失。实时模式和 Outliner 列表本身不受影响
——被锁定的部件在实时模式下单击时仍然正常工作，你也仍然可以在 Outliner 中看到它并
重命名。从 Outliner 标题锁定一个 [图层组](./editing-tools#layer-groups)，
会以同样方式锁定其所有成员。

锁定适用于你已经摆放完毕、不希望在周围操作时被意外碰动的部件
——例如背景图像，或已经完成的一排按钮。

## 实时模式工具提示 \{#live-mode-tooltip}

在实时模式下，将鼠标悬停在任意部件上会显示一个工具提示，概括其连接情况——它叫什么名字，
以及它驱动哪些控制点/Actor。这是在不进入编辑模式的情况下检查一个陌生页面的最快方法。
