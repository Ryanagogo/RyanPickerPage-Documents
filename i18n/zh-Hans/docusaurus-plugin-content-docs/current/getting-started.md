# 入门 \{#getting-started}

## 打开页面 \{#opening-a-page}

**Tools → Ryan Picker Page** 会在新的编辑器标签页中打开一个页面。页面标题栏中的 **New Tab** 按钮可以
打开更多页面——每个标签页完全独立，拥有各自的文件、各自的 Control Rig 选择
以及各自的画布视图。重命名页面（标题可在编辑模式下编辑）会同时重命名
其标签页，因此即使打开了一排拾取器也依然便于切换。

## 两种模式 \{#two-modes}

标题栏中的编辑模式按钮可在以下两种模式之间切换整个页面：

**实时模式**——动画制作模式。单击部件会选中绑定控制点和 Actor；拖动
滑块会驱动变换；将鼠标悬停在部件上会显示工具提示，说明它连接到了什么。布局
本身无法改动。

**完成的页面大部分时间都在实时模式下使用。**
[编辑与画布工具](./editing-tools) 中的一切都是为了让你走到这一步。

**编辑模式**——搭建模式。部件上会出现移动/缩放/旋转手柄，右键单击
画布空白处会打开 **Add Widget** 菜单，同时会出现两个可折叠的侧边栏：左侧是
[Outliner](./attribute-editor-and-outliner)，右侧是
[属性编辑器](./attribute-editor-and-outliner)。

## 搭建你的第一个页面 \{#build-your-first-page}

一个最简单的单腿拾取器，从头到尾：

1. 打开包含你的角色及其 Control Rig 的 Level Sequence，然后打开一个拾取器页面。
   标题栏中的绑定下拉列表会根据当前聚焦的序列自动填充——选择你的绑定（如果
   只有一个，会自动选中）。
2. 进入**编辑模式**。
3. 在视口或 Anim Outliner 中选择大腿控制点。右键单击画布 →
   **Add Widget → 选择按钮**。默认情况下，新按钮会根据
   当前选择生成目标列表，因此这个按钮已经可以驱动大腿了。
4. 对小腿和脚重复上述操作。使用
   [属性编辑器](./attribute-editor-and-outliner) 中的标签字段为每个按钮命名，并将它们拖成
   腿形的一列。
5. 选中这三个按钮，试试 [对齐工具](./editing-tools) 把这一列排整齐。
6. 退出编辑模式。单击这些按钮——每个按钮都会选中对应的控制点。这就是基本流程；其他一切
   都只是精修。
7. **文件 → 保存** 会将页面写入你选择的任意位置的 JSON 文件——请参阅
   [保存、加载与文件](./save-load-and-files)。

## 撤销、重做与安全保障 \{#undo-redo-and-safety-nets}

编辑模式下的每一项更改——移动、缩放、添加、删除、粘贴、颜色编辑——都会进入
页面的撤销栈（默认 30 步；请参阅 [编辑器设置](./editor-settings)）。使用 Ctrl+Z /
Ctrl+Y，或标题栏中的按钮。在取色器内的拖动会合并为一个撤销步骤，
而不是每次移动一步，因此撤销一次颜色更改会撤销整个拖动过程。

[书签](./bookmarks) 拥有自己独立的撤销栈——布局撤销绝不会影响
你保存的视图，反之亦然。

## 从上次中断的地方继续 \{#picking-up-where-you-left-off}

对于每个已保存的文件，插件都会记住画布的平移/缩放、当前激活的 Control Rig，
以及你当时处于编辑模式还是实时模式——下次在这台计算机上加载该文件时，
这些都会自动恢复。这些信息存储在页面文件之外，因此与
团队成员共享页面时，共享的是布局，而不是你的查看习惯。请参阅
[保存、加载与文件](./save-load-and-files#session-state)。
