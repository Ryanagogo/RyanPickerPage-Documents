# 图像部件 \{#image-widget}

### 创建新的图像部件 \{#creating-a-new-image-widget}

必须处于**编辑模式**才能创建新的图像部件

**右键单击拾取器画布的空白处**以弹出菜单，然后单击“图像”菜单项

### 在属性编辑器中 \{#from-the-attribute-editor}

要在属性编辑器中查看数值，需要只选中一个部件

##### 图像部件图像 \{#image-widget-image}

<img src={useBaseUrl('/img/quick-start/widget-image/image-widget-image.png')} alt="image-widget-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - 可使用项目中的任意图像资产
- **拉伸模式**
  - 不同的模式决定图像如何拉伸以尽量填满部件的大小
- **缩放**
  - 可以放大或缩小图像
- **偏移**
  - 可以将图像上下、左右移动
- **Alpha**
  - 可以设置图像的透明度。越透明，就越能看到部件本身的颜色
