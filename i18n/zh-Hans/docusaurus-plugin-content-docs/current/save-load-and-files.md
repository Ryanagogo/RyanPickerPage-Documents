# 保存、加载与文件 \{#saving-loading--files}

页面保存为单个 **JSON 文件**，可以存放在磁盘上任何你选择的位置。页面不是 Unreal
资产：它们不位于 `Content/` 中，不需要创建它们时所在的项目，并且可以像任何文本文件一样
共享、通过邮件发送或进行版本控制。

一次保存就包含整个页面：每个部件及其所有连接和样式、
[书签行](./bookmarks)、开关组以及 [Pose Map](./mirror-pose)。

## “文件”菜单 \{#the-file-menu}

| 菜单项 | |
|---|---|
| **保存** | 写回页面当前的文件；对于从未保存过的页面，行为与“另存为”相同 |
| **另存为** | 系统原生的保存对话框 |
| **加载** | 系统原生的打开对话框 |
| **加载最近项** | 最近使用的文件，无需对话框 |
| **重新加载** | 从磁盘重新读取当前文件 |
| **Pose Map…** | [Pose Map 对话框](./mirror-pose#the-pose-map) |
| **Settings…** | [编辑器设置](./editor-settings) 对话框 |

保存和加载对话框会在你上次使用的目录中重新打开。

## “帮助”菜单 \{#the-help-menu}

其菜单项完全由数据驱动——是在页面的 Class Defaults 面板中编辑的“标签/URL/工具提示”项
列表。无需修改代码或重新编译，即可添加、删除、重新排序或更改菜单项的目标；
单击某一项会在操作系统的默认浏览器中打开其 URL。有一项是固定的，而非
数据驱动：**关于**，它会在一个简单的信息对话框中显示插件版本、Unreal Engine 版本以及
作者。

## 旧文件依然可以加载 \{#old-files-keep-loading}

保存文件带有架构版本。加载较旧的文件时，会自动依次迁移经过中间的每一次
架构变更——早期插件版本的页面可以在当前版本中加载，
只需重新保存即可以当前版本写入。无法迁移的文件
（或来自比你的版本*更新*的插件的文件）会被拒绝并给出清晰的错误，
而不会只加载一半。

关于隐私的一点说明：选择按钮的 [Python 脚本](./python-scripting) 在文件中以
Base64 编码存储——是编码，不是加密。请像对待脚本本身一样对待包含脚本的页面文件。

## 会话状态 \{#session-state}

插件会在页面文件旁边（但绝不在文件内部）按文件路径记住你上次
停在哪里：画布的平移/缩放、当前激活的 Control Rig、编辑模式还是实时模式。明天加载同一个文件，
画布仍然停在你离开时的位置。由于这些信息以文件路径为键存储在你的计算机上，
共享页面时只会共享布局——接收者拥有自己的视图状态。
90 天（可配置）未使用的条目会被清理。

## 插件自身文件的存放位置 \{#where-the-plugin-keeps-its-own-files}

```
%APPDATA%\RyanTechAnimTools\RyanPicker\
├── settings.json              # 最近的文件、上次对话框所用目录、Outliner 视图
├── editor_settings.json       # 编辑器设置对话框中的值
└── page_session_state.json    # 按文件保存的会话状态，以绝对路径为键
```

这些文件是按用户、按计算机保存的。删除它们会失去一些便利功能（最近的文件、恢复的
视图、设置），但绝不会丢失页面数据——页面只存在于你保存的文件中。
