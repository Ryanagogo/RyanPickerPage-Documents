# 镜像姿势 \{#mirror-pose}

*只需教会页面一次它自己的左右对称关系，此后即可随时镜像布局。*

[镜像工具](./editing-tools#mirror) 会以你选择的锚点为基准镜像当前选中的内容——
适合一次性的翻转，但它并不知道哪些部件彼此对应。
**镜像姿势** 通过 **Pose Map** 解决了这个问题：Pose Map 是页面级的记录，记载了
哪个部件是哪个部件的左侧搭档、中线在哪里，以及哪个部件
作为整体的锚点。映射完成后，每次镜像布局都只需单击一次，无需
任何繁琐的选择操作。

## Pose Map \{#the-pose-map}

在 **Pose Map…** 对话框（“文件”菜单）中编写。每个页面只有一个映射，其中包含三
类条目：

- **锚点**——定义镜像轴（即其中心）的唯一部件。通常是位于页面中线上的
  根/骨盆按钮。在设置锚点之前不会镜像任何内容——
  否则姿势按钮会弹出提示进行警告。
- **中间部件**——脊柱、头部等位于中线上的一切。它们会镜像到自身
  （沿轴原地翻转）。
- **配对**——左/右部件对：左大腿 ↔ 右大腿，依此类推。

对话框中的部件下拉列表按字母排序且可搜索，因此为大型页面建立映射
只需输入筛选，而不必滚动查找。**重置 Map** 按钮（需确认）会清除
整个映射。映射保存在页面文件中，因此会随布局一起携带。

## 使用方法 \{#using-it}

工具栏的镜像行中，在 Mirror Horizontal/Vertical 按钮之后有一个 **姿势** 按钮和一个方向下拉列表。

**有选择时**——单击 **姿势** 会根据每个选中部件在映射中的角色对其进行镜像：
左侧或右侧部件的位置和旋转会沿锚点的轴镜像，并写入其*搭档*
（被选中的一侧是源，本身不移动）；中间部件和
锚点则原地翻转。选中但不在映射中的部件会被跳过并弹出提示，
其余部件照常处理。

**未选择任何内容时**——整个映射一键镜像，方向由下拉列表决定
（默认 **左 → 右**，或 **右 → 左**）：锚点和每个中间部件
原地翻转，每个配对把源侧复制到目标侧。这就是
“左臂做完了，把右臂也印出来”的按钮。

方向下拉列表是页面上的临时控件——不会随文件保存。

## 会改变什么，不会改变什么 \{#what-it-changes--and-doesnt}

镜像姿势移动的是**部件几何**：画布上的位置和旋转。与镜像工具一样，
它不会改动部件所连接的对象——右大腿按钮仍然驱动右
大腿，只是被精确地放到左侧按钮所在位置的镜像处。这正是它的意义所在：
目标只需分配一次，之后在布局不断演进的过程中，两侧在视觉上始终保持同步。
