# 部件基础 \{#widget-basics}

### 创建部件 \{#create-widgets}

- 必须处于编辑模式才能创建新部件
- 右键单击画布的空白处可打开弹出菜单，其中包含用于创建各种类型拾取器部件的菜单项
- 新部件会放置在你右键单击时鼠标指针所在的位置。
- 创建部件时会向撤销栈添加一项，因此可以撤销和重做部件的创建

### 删除部件 \{#delete-widgets}

- 必须处于编辑模式才能删除部件
- 按下“Delete”键可删除所有选中的部件
- 要删除单个部件，可右键单击该部件弹出部件菜单，菜单底部有删除该部件的菜单项。
- 删除部件时会向撤销栈添加一项，因此可以撤销和重做删除操作。

### 选择部件 \{#select-widgets}

- 在实时模式和编辑模式下都可以选择部件
- 可以通过单击部件或在其周围框选来选择部件
- 在实时模式下，有些部件无法选择：
  - 标签部件
  - 图像部件
- 在编辑模式下，所有部件都可以选择
  - 在 Outliner 中可以锁定部件，使其无法被选中。当多个部件叠放在一起时，这很有用。
- 部件被选中的顺序会被记住。编辑模式中的某些功能会用到这个选择顺序

### 变换部件 \{#transform-widgets}

- 必须处于编辑模式才能变换部件
- **移动**
  - 选中一个或多个部件后，将鼠标移到某个选中的部件上，使光标变为移动光标。然后单击并拖动，所有选中的部件都会随鼠标移动。
- **旋转**
  - 当鼠标位于部件上且显示移动光标时，按住 Alt 键会将光标变为旋转光标。然后单击并拖动，所有选中的部件会围绕最后选中的部件平滑旋转。
  - 同时按住 Alt 和 Shift 键时，会以 15 度为步长旋转
- 变换部件时会向撤销栈添加一项，因此可以撤销和重做变换。

### 调整部件大小 \{#resize-widgets}

- 必须处于编辑模式才能调整部件大小
- 将鼠标指针移到部件的某条边或某个角上时，光标会变为边或角的调整大小光标。然后单击并拖动即可调整部件大小。
- 调整大小一次只能作用于一个部件
- 调整部件大小时会向撤销栈添加一项，因此可以撤销和重做大小调整。

### 剪切、复制和粘贴 \{#cut-copy-and-paste}

- 必须处于编辑模式才能剪切、复制和粘贴部件
- 可以使用标准快捷键 Ctrl + X、Ctrl + C 和 Ctrl + V 剪切、复制和粘贴选中的部件
- 对于单个部件，可以右键单击该部件弹出菜单，其中有“剪切”和“复制”菜单项
- 使用 Ctrl + V 会将部件粘贴到鼠标所在位置
- 右键单击画布的空白处，弹出菜单中有两个粘贴选项
  - **粘贴**
    - 将部件粘贴到鼠标所在位置
  - **原位粘贴**
    - 将部件粘贴到它们被复制或剪切时所在的位置

### 部件弹出菜单 \{#widget-popup-menu}

- 必须处于编辑模式才能看到部件弹出菜单
- 右键单击部件时会打开弹出菜单
  - 前几项显示部件的名称和类型，以及剪切和复制选项
  - 最后一项用于删除该部件
  - 其他菜单项取决于所单击部件的类型

### 属性编辑器 \{#attribute-editor}

- 必须处于编辑模式才能看到属性编辑器
- 只有在选中一个部件时，属性编辑器才会显示属性。如果选中了多个部件，则不会显示任何内容。(此行为将在未来版本中更改)
- 前几项显示部件的名称和类型，并可锁定部件使其无法被选中
  - 其他项取决于所选部件的类型

### Outliner \{#outliner}

- 必须处于编辑模式才能看到 Outliner
- Outliner 会显示 Picker Page 中的所有部件，并可按显示层、按部件类型或按组(专用于开关部件组)分组显示
- 如果在画布上选中了某个部件，Outliner 中对应的部件条目也会被选中，反之亦然。
- 双击 Outliner 中的部件条目可以重命名该部件
- 在显示层视图中有复选框，可用于锁定或解锁部件。锁定的部件在编辑模式下无法选中。当多个部件叠放在一起时，这很有用。
- 在 Outliner 中选中部件后，可以使用“F”快捷键将视图聚焦到该部件上。当你难以找到某个特定部件时，这很有用
