# 错误与反馈 \{#bugs-and-feedback}

### 帮助菜单 \{#the-help-menu}

在 Picker Page 的左上角，“文件”菜单旁边可以看到“帮助”菜单。

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu.png')} alt="help-menu" style={{marginLeft: 0, zoom: '80%'}} />

单击“帮助”菜单后，你会看到许多实用的菜单项，其中包括建议功能、报告错误以及给我发送消息的菜单项。

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu-items.png')} alt="help-menu-items" style={{marginLeft: 0, zoom: '80%'}} />

单击其中任意一项，都会在网页浏览器中打开一个链接，供你填写表单。

“建议功能”和“报告错误”会直接在我的工单跟踪系统中添加条目，“联系我”则会向我的工作邮箱发送消息。

你也可以通过以下链接直接访问相应的表单：

- **[报告错误](https://tally.so/r/ODx6Np)**
- **[建议功能](https://tally.so/r/D4RjLp)**
- **[联系我](https://tally.so/r/RG9N6l)**
