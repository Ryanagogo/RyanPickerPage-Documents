# 书签 \{#bookmarks}

*为画布命名的相机位置。*

在全身拾取器上，你会不停地在各个区域之间跳转——面部、手部、脚部。书签
让每次跳转都只需一次单击：书签会保存画布的平移/缩放视图，单击标题行中
对应的按钮，画布就会立即跳转到该位置。

## 书签行 \{#the-bookmark-row}

- **默认** 始终存在且始终可见，位于可滚动行之外——可以把它当作
  “主页”。
- **用户槽位**——默认 4 个，最多 8 个（请参阅 [编辑器设置](./editor-settings)）——位于它旁边
  可水平滚动的行中，按位置编号，并且可以命名。

## 使用书签 \{#working-with-bookmarks}

| 操作 | 方法 |
|---|---|
| 跳转到某个视图 | 单击按钮 |
| 保存当前视图 | **Ctrl+Shift+单击** 按钮，或右键单击 → 设置 / 覆盖——按钮会闪烁绿色以示确认 |
| 重命名槽位 | 右键单击 → 重命名 |
| 添加槽位 | 右键单击 → 在之前添加书签 / 在之后添加书签 |
| 重新排序 | 右键单击 → 左移 / 右移——交换位置的两个按钮都会闪烁橙色 |
| 删除 / 重置 | 右键单击 → 删除，或 Reset to Identity |

书签编辑拥有**自己独立的 30 步撤销栈**，与布局撤销完全独立——
在画布上按 Ctrl+Z 绝不会吞掉书签更改，书签撤销也绝不会影响
布局。

书签与其他所有内容一起保存在页面文件中。按钮宽度、字体、内边距以及
两种确认闪烁颜色都可以在 Class Defaults 面板中按页面调整。
