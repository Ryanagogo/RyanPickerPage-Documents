# 快捷键 \{#hotkeys}

拾取器编辑器响应的所有键盘快捷键和鼠标手势。

### 焦点与模式规则 \{#focus-and-mode-rules}

- **只有当画布拥有焦点时，键盘快捷键才会生效。** 单击画布后，画布会立即获得焦点。如果焦点在侧边栏的字段或 Outliner 列表上，按键会发送到那里。
- 在实时模式下只有 **F** 快捷键有效。其他所有键盘快捷键仅在编辑模式下可用。
- 右键拖动平移和鼠标滚轮缩放在编辑模式和实时模式下都可用。

### 键盘 \{#keyboard}

| 按键 | 操作 | 模式 |
|---|---|---|
| **Delete** | 删除选中的部件 | 仅编辑 |
| **F** | 将画布视图居中到当前选择（缩放保持不变） | 编辑 + 实时 |
| **Alt + 单击按钮** | 将视口居中到单击按钮时所选中的对象 |仅实时|
| **Alt + 拖动框选按钮** | 将视口居中到框选按钮时所选中的对象 |仅实时|
| **方向键** | 微移选择（默认 2 px） | 仅编辑 |
| **Shift + 方向键** | 以更大的步长微移选择（默认 10 px） | 仅编辑 |
| **Ctrl + X** | 剪切选中的部件 | 仅编辑 |
| **Ctrl + C** | 复制选中的部件 | 仅编辑 |
| **Ctrl + V** | 在鼠标光标处粘贴 | 仅编辑 |
| **Ctrl + Z** | 撤销 | 仅编辑 |
| **Ctrl + Shift + Z** 或 **Ctrl + Y** | 重做 | 仅编辑 |

两个键盘微移距离在页面的 Class Defaults 面板中设置。它们与工具栏中的 **微移** 工具相互独立，后者有自己的距离字段。

复制 / 剪切 / 粘贴可以在已打开的页面标签页之间使用。

**未绑定：** 没有 Ctrl+A（全选）、Ctrl+S（保存）、Ctrl+D（复制副本）或 Esc（取消选择）。复制副本、对齐、分布和镜像只能通过右键菜单或工具栏使用。

### 鼠标——选择部件 \{#mouse---selecting-widgets}

只有 Ctrl 和 Shift 会改变选择的方式。

| 手势 | 操作 |
|---|---|
| 单击部件 | 只选中该部件 |
| Ctrl + 单击部件 | 将该部件加入选择或从选择中移除 |
| Shift + 单击部件 | 将该部件加入选择 |
| 单击画布空白处 | 清除选择 |
| 在画布空白处拖动 | 绘制选择框 |
| Ctrl 或 Shift + 拖动选择框 | 将框内部件加入当前选择，而不是替换它 |
| 单击 Outliner 中的一行 | 选中该部件——即使是锁定的部件也可以 |
| 双击 Outliner 中的一行 | 重命名 |

### 鼠标——移动、调整大小、旋转（编辑模式） \{#mouse---moving-resizing-rotating-edit-mode}

八个缩放手柄和移动手柄只在编辑模式下出现。

| 手势 | 操作 |
|---|---|
| 拖动移动手柄 | 移动选中的部件 |
| **Alt** + 拖动移动手柄 | 旋转而不是移动 |
| **Alt + Shift** + 拖动移动手柄 | 以 15 度为步长吸附旋转 |
| 拖动边或角的手柄 | 调整大小（对已旋转的部件也能正确工作） |

在按下移动手柄之前按住 Alt 即可开始旋转。拖动过程中按住 Shift 即可吸附。

### 鼠标——在画布中导航 \{#mouse---navigating-the-canvas}

| 手势 | 操作 | 模式 |
|---|---|---|
| 鼠标滚轮 | 朝光标方向缩放 | 编辑 + 实时 |
| 右键拖动 | 平移画布 | 编辑 + 实时 |
| 右键单击（不拖动） | 打开上下文菜单 | 仅编辑 |
| 拖动侧边栏分隔条 | 调整 Outliner 或属性编辑器面板的大小 | 仅编辑 |

### 书签 \{#bookmarks}

| 手势 | 操作 |
|---|---|
| 单击书签 | 应用保存的视图 |
| **Ctrl + Shift + 单击** 书签 | 用当前视图覆盖该书签 |
| 右键单击书签 | 重命名或清除 |
