# 단축키 \{#hotkeys}

피커 에디터가 반응하는 모든 키보드 단축키와 마우스 동작입니다.

### 포커스 및 모드 규칙 \{#focus-and-mode-rules}

- **키보드 단축키는 캔버스에 포커스가 있을 때만 작동합니다.** 캔버스를 클릭하는 즉시 캔버스가 포커스를 받습니다. 사이드바 필드나 Outliner 목록에 포커스가 있으면 키 입력은 그쪽으로 갑니다.
- 라이브 모드에서는 **F** 단축키만 작동합니다. 나머지 키보드 단축키는 모두 편집 모드 전용입니다.
- 오른쪽 드래그로 팬하기와 마우스 휠로 줌하기는 편집 모드와 라이브 모드 모두에서 작동합니다.

### 키보드 \{#keyboard}

| 키 | 동작 | 모드 |
|---|---|---|
| **Delete** | 선택된 위젯 삭제 | 편집 전용 |
| **F** | 캔버스 뷰를 현재 선택의 가운데로 맞춤(줌은 그대로) | 편집 + 라이브 |
| **Alt + 버튼 클릭** | 버튼을 클릭할 때 선택된 오브젝트에 뷰포트를 맞춤 |라이브 전용|
| **Alt + 버튼 드래그 선택** | 버튼을 드래그해 선택할 때 선택된 오브젝트에 뷰포트를 맞춤 |라이브 전용|
| **화살표 키** | 선택을 조금씩 이동(기본 2 px) | 편집 전용 |
| **Shift + 화살표 키** | 선택을 더 큰 단계로 이동(기본 10 px) | 편집 전용 |
| **Ctrl + X** | 선택된 위젯 잘라내기 | 편집 전용 |
| **Ctrl + C** | 선택된 위젯 복사 | 편집 전용 |
| **Ctrl + V** | 마우스 커서 위치에 붙여넣기 | 편집 전용 |
| **Ctrl + Z** | 실행 취소 | 편집 전용 |
| **Ctrl + Shift + Z** 또는 **Ctrl + Y** | 다시 실행 | 편집 전용 |

키보드 이동 거리 두 가지는 페이지의 Class Defaults 패널에서 설정합니다. 자체 거리 필드가 있는 툴바의 **넛지** 도구와는 별개입니다.

복사 / 잘라내기 / 붙여넣기는 열려 있는 페이지 탭 사이에서도 작동합니다.

**할당되지 않음:** Ctrl+A(모두 선택), Ctrl+S(저장), Ctrl+D(복제), Esc(선택 해제)는 없습니다. 복제, 정렬, 분배, 미러는 마우스 오른쪽 클릭 메뉴나 툴바에서만 사용할 수 있습니다.

### 마우스 - 위젯 선택 \{#mouse---selecting-widgets}

선택 방식을 바꾸는 키는 Ctrl과 Shift뿐입니다.

| 동작 | 결과 |
|---|---|
| 위젯 클릭 | 그 위젯만 선택 |
| Ctrl + 위젯 클릭 | 그 위젯을 선택에 추가하거나 선택에서 제거 |
| Shift + 위젯 클릭 | 그 위젯을 선택에 추가 |
| 빈 캔버스 클릭 | 선택 해제 |
| 빈 캔버스에서 드래그 | 선택 사각형 그리기 |
| Ctrl 또는 Shift + 선택 사각형 드래그 | 사각형 안의 위젯을 현재 선택을 대체하지 않고 추가 |
| Outliner의 행 클릭 | 그 위젯 선택 — 잠긴 위젯에서도 작동 |
| Outliner의 행 더블클릭 | 이름 바꾸기 |

### 마우스 - 이동, 크기 조절, 회전(편집 모드) \{#mouse---moving-resizing-rotating-edit-mode}

크기 조절 핸들 8개와 이동 핸들은 편집 모드에서만 나타납니다.

| 동작 | 결과 |
|---|---|
| 이동 핸들 드래그 | 선택된 위젯 이동 |
| **Alt** + 이동 핸들 드래그 | 이동 대신 회전 |
| **Alt + Shift** + 이동 핸들 드래그 | 15도 단위로 스냅하며 회전 |
| 가장자리 또는 모서리 핸들 드래그 | 크기 조절(회전된 위젯에서도 올바르게 작동) |

회전을 시작하려면 이동 핸들을 누르기 전에 Alt를 누르고 있으세요. 스냅하려면 드래그하는 동안 Shift를 계속 누르고 있으세요.

### 마우스 - 캔버스 탐색 \{#mouse---navigating-the-canvas}

| 동작 | 결과 | 모드 |
|---|---|---|
| 마우스 휠 | 커서 쪽으로 줌 | 편집 + 라이브 |
| 오른쪽 드래그 | 캔버스 팬 | 편집 + 라이브 |
| 마우스 오른쪽 클릭(드래그 없이) | 컨텍스트 메뉴 열기 | 편집 전용 |
| 사이드바 구분선 드래그 | Outliner 또는 속성 편집기 패널 크기 조절 | 편집 전용 |

### 북마크 \{#bookmarks}

| 동작 | 결과 |
|---|---|
| 북마크 클릭 | 저장된 뷰 적용 |
| 북마크를 **Ctrl + Shift + 클릭** | 현재 뷰를 그 북마크에 덮어써서 저장 |
| 북마크를 마우스 오른쪽 클릭 | 이름 바꾸기 또는 지우기 |
