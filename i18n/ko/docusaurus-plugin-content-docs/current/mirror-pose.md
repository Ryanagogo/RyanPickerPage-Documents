# 포즈 미러 \{#mirror-pose}

*페이지에 좌우 대칭을 한 번만 알려 주면, 이후로는 언제든 레이아웃을 미러링할 수 있습니다.*

[미러 도구](./editing-tools#mirror)는 현재 선택된 항목을 선택한 앵커를 기준으로
반전합니다. 일회성 반전에는 좋지만, 어떤 위젯끼리 서로 대응하는지는
알지 못합니다. **포즈 미러**는 **Pose Map**으로 이를 해결합니다. Pose Map은 어떤 위젯이 어떤 위젯의 왼쪽 짝인지,
중심선이 어디인지, 전체를 고정하는 위젯이 무엇인지를 페이지 단위로 기록한 것입니다.
한 번 매핑해 두면 레이아웃 미러링은 매번 클릭 한 번이면 되며, 번거로운 선택 작업이
필요 없습니다.

## Pose Map \{#the-pose-map}

**Pose Map…** 대화 상자(파일 메뉴)에서 작성합니다. 각 페이지에는 맵이 정확히 하나 있으며, 세 가지
종류의 항목을 담습니다.

- **앵커** — 미러 축(자신의 중심)을 정의하는 단 하나의 위젯입니다. 보통
  페이지 중심선에 놓인 루트/골반 버튼입니다. 앵커가 설정되기 전에는 아무것도 미러링되지 않으며,
  그렇지 않으면 포즈 버튼이 토스트 알림으로 경고합니다.
- **가운데 위젯** — 척추, 머리 등 중심선 위의 모든 것. 자기 자신에 대해 미러링됩니다
  (축을 기준으로 제자리에서 반전).
- **쌍** — 왼쪽/오른쪽 위젯 짝: 왼쪽 허벅지 ↔ 오른쪽 허벅지 등.

대화 상자의 위젯 드롭다운은 알파벳순으로 정렬되어 있고 검색할 수 있으므로, 큰 페이지도
스크롤 대신 입력해서 걸러 가며 매핑할 수 있습니다. **Map 재설정** 버튼(확인 포함)은
맵 전체를 지웁니다. 맵은 페이지 파일 안에 저장되므로 레이아웃과 함께 이동합니다.

## 사용 방법 \{#using-it}

툴바의 미러 행에는 Mirror Horizontal/Vertical 버튼 다음에 **포즈** 버튼과 방향 드롭다운이 있습니다.

**선택이 있을 때** — **포즈**를 클릭하면 선택된 각 위젯이 맵에서의 역할에 따라 미러링됩니다.
왼쪽 또는 오른쪽 위젯의 위치와 회전은 앵커의 축을 기준으로 반전되어
그 *짝*에 기록됩니다(선택한 쪽이 원본이며 움직이지 않음). 가운데 위젯과
앵커는 제자리에서 반전됩니다. 맵에 없는 선택 위젯은 토스트 알림과 함께 건너뛰고
나머지는 처리됩니다.

**아무것도 선택하지 않았을 때** — 드롭다운이 가리키는 방향(기본값 **왼쪽 → 오른쪽**, 또는
**오른쪽 → 왼쪽**)으로 맵 전체가 클릭 한 번에 미러링됩니다. 앵커와 모든 가운데 위젯은
제자리에서 반전되고, 각 쌍은 원본 쪽을 대상 쪽으로 복사합니다. 이것이
"왼팔 끝났으니 오른팔에도 찍어 줘" 버튼입니다.

방향 드롭다운은 일시적인 페이지 컨트롤이며 파일에 저장되지 않습니다.

## 바뀌는 것과 바뀌지 않는 것 \{#what-it-changes--and-doesnt}

포즈 미러는 **위젯 지오메트리**, 즉 캔버스 위의 위치와 회전을 움직입니다. 미러 도구와 마찬가지로
위젯이 연결된 대상은 건드리지 않습니다. 오른쪽 허벅지 버튼은 계속 오른쪽 허벅지를
조작하며, 왼쪽 버튼이 있는 위치에 정확히 반전되어 놓일 뿐입니다. 바로 그것이 핵심입니다.
대상 지정은 한 번만 하고, 레이아웃이 발전하는 동안 양쪽을 시각적으로 맞춰 둘 수 있습니다.
