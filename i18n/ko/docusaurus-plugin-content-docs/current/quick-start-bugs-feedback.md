# 버그 및 피드백 \{#bugs-and-feedback}

### 도움말 메뉴 \{#the-help-menu}

Picker Page의 왼쪽 위 모서리, 파일 메뉴 옆에 도움말 메뉴가 있습니다.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu.png')} alt="help-menu" style={{marginLeft: 0, zoom: '80%'}} />

도움말 메뉴를 클릭하면 기능 제안, 버그 보고, 제게 메시지 보내기 등 유용한 메뉴 항목이 여러 개 표시됩니다.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu-items.png')} alt="help-menu-items" style={{marginLeft: 0, zoom: '80%'}} />

이 항목들을 클릭하면 웹 브라우저에서 링크가 열리며, 양식을 작성할 수 있습니다.

기능 제안과 버그 보고는 제 티켓 추적 시스템에 바로 항목을 추가하고, 문의하기는 제 업무용 이메일로 메시지를 보냅니다.

다음 링크를 사용해 각 양식으로 바로 이동할 수도 있습니다.
