# 편집 및 캔버스 도구 \{#editing--canvas-tools}

이 페이지의 모든 작업은 **편집 모드**에서 이루어집니다. 캔버스 자체는 두 모드 모두에서 팬과 줌이
가능하므로, 편한 배율로 작업하세요.

## 선택 \{#selection}

- 위젯을 클릭하면 선택됩니다. Shift/Ctrl+클릭은 선택을 확장합니다.
- 캔버스의 빈 곳을 드래그하면 사각형 선택 영역이 그려집니다.
- 선택된 위젯에는 크기 조절 핸들 8개와 회전 핸들 1개가 표시되며, 각각 전용 커서가 있습니다.

속성 편집기는 단일 선택을 따르며, 여러 위젯을 한꺼번에 편집하려면 아래의 툴바
도구를 사용합니다.

## 직접 조작 \{#direct-manipulation}

위젯을 드래그하면 이동합니다. 핸들을 드래그하면 크기가 조절되며, 회전된 위젯에서도 올바르게
동작합니다. 회전 핸들을 드래그하면 위젯이 중심을 기준으로 회전합니다. 회전은
도 단위로 저장되며, 회전된 위젯도 라이브 모드에서 완전히 동작합니다(회전된 슬라이더는
회전된 축을 따라 드래그됨). 회전하는 동안 Shift를 누르면 15° 단위로 스냅됩니다. 여러 위젯을 선택해 회전하면
그룹 전체가 공통 피벗(마지막으로 선택한 위젯에 고정)을 중심으로 한 덩어리처럼 회전하고,
동시에 각 위젯도 자기 중심을 기준으로 회전합니다.

잠긴 위젯은 이 모든 조작에서 제외됩니다. [위젯 잠금](./attribute-editor-and-outliner#widget-locking)을 참조하세요.

화살표 키로 선택을 조금씩 이동합니다(Shift는 더 큰 단계. 두 거리 모두 페이지의 Class
Defaults입니다). 툴바의 **넛지** 도구는 숫자 상자로 거리를 설정하는 화면 화살표를 추가해
정확한 단계를 반복 적용할 수 있게 합니다.

## 툴바 도구 \{#toolbar-tools}

한 번에 하나의 도구 행만 활성화되며, 헤더에서 전환합니다.

| 도구 | 선택에 대한 동작 |
|---|---|
| **이미지** | 선택된 모든 위젯에 텍스처를 지정합니다 |
| **색상** | 선택된 모든 위젯에 배경색/글꼴 색상을 적용합니다 |
| **라벨** | 선택 전체에 라벨 텍스트와 글꼴 크기를 설정합니다 |
| **크기** | 선택 전체에 정확한 너비/높이를 설정합니다 |
| **넛지** | 앞서 설명한 고정 단계 화살표 |
| **정렬** | 왼쪽/오른쪽/위/아래, 가로/세로 가운데, 균등 분배 |
| **미러** | 아래 참조 |

툴바(및 속성 편집기)에서의 색상 편집은 색상 선택기 안에서 드래그하는 동안 하나로
합쳐집니다. 마우스 움직임마다가 아니라 색상 편집 한 번당 실행 취소 단계 하나입니다.

## 미러 \{#mirror}

페이지의 한쪽을 다른 쪽으로부터 만듭니다. **Mirror Horizontal** / **Mirror Vertical**은
선택된 각 위젯의 위치를 축을 기준으로 반전하고 회전도 반대로 만듭니다. 축은
**Mirror Mode** 드롭다운으로 설정합니다.

| 모드 | 반전 기준 |
|---|---|
| 자신 | 각 위젯 자신의 중심 — 위젯이 제자리에서 반전됩니다 |
| 마지막 선택(포함) | 마지막으로 선택한 위젯의 중심. 그 위젯도 이동합니다 |
| 마지막 선택(제외) | 마지막으로 선택한 위젯의 중심. 그 위젯은 그대로 있습니다 |
| 보이는 캔버스 | 현재 보이는 영역의 중심 |

미러는 기하학적 처리일 뿐이며, 컨트롤 이름을 바꾸거나 슬라이더 채널을 맞바꾸지 않습니다. 일반적인
작업 흐름은 미러 후 대상 재지정입니다. 왼팔의 위젯을 미러링한 다음, 복사본이 오른쪽
컨트롤을 가리키도록 합니다. 짝을 기억하는 반복 가능한 좌우 미러링은
[포즈 미러](./mirror-pose)를 참조하세요.

## 레이어 그룹 \{#layer-groups}

모든 위젯은 하나의 **레이어 그룹**에 속하며, 그리기 순서는 각 그룹의 멤버를
그룹별로 앞에서 뒤로 나열한 것입니다. 세 그룹(**이미지**, **라벨**, **컨트롤**)은 모든 페이지에
기본으로 만들어지며 삭제할 수 없습니다(그 밖의 그룹을 삭제하면 멤버가 자기 유형의
기본 그룹으로 다시 배정됨). 이 세 그룹 외에도 그룹을 원하는 만큼 만들고, 이름을 바꾸고, 순서를 바꾸고, 잠글 수 있습니다.
잠긴 그룹은 개별 위젯의 [잠금](./attribute-editor-and-outliner#widget-locking)과 마찬가지로
그 안의 모든 위젯을 잠급니다.

위젯을 마우스 오른쪽 버튼으로 클릭하면 해당 그룹 안에서 **맨 앞으로 가져오기 / Step Up / Step Down / 맨 뒤로 보내기**를 실행할 수 있습니다.
위젯을 그룹 간에 옮기기, 그룹 자체의 순서 바꾸기, 잠금은 모두 Outliner의
[레이어별 보기](./attribute-editor-and-outliner#outliner-left)에서 합니다. 드래그 앤 드롭 관리 UI의
전체 설명은 해당 페이지를 참조하세요.

## 복사, 잘라내기, 붙여넣기 \{#copy-cut-paste}

어떤 선택이든 Ctrl+C / Ctrl+X / Ctrl+V를 사용할 수 있습니다. 붙여넣은 항목은 커서 위치에 놓입니다. 열려 있는 다른 페이지 탭에
붙여넣을 수도 있으며, 제자리에 붙여넣기를 사용하면 페이지 간 전송 시에도 정확한 위치가 유지됩니다.
붙여넣은 위젯은 가능하면 이름을 유지하고, 중복되면 숫자 접미사가 붙습니다. 토글
그룹은 [그룹 전체로](./widget-toggle#toggle-groups) 복사하고 붙여넣을 수 있습니다.

## 위젯 기본값 \{#widget-defaults}

새로 추가한 위젯의 모양은 계층적으로 결정되며, 뒤에 오는 것이 더 구체적입니다.

1. **Class Defaults** — 유형별 시작 값(색상, 크기, 글꼴 등)으로, 페이지의 Class Defaults 패널에서
   위젯 유형별 카테고리로 편집할 수 있습니다.
2. **Sticky Defaults** — 아무 위젯이나 마우스 오른쪽 버튼으로 클릭 → **Copy to Sticky Defaults**를 선택하면, 이후에
   만드는 해당 유형의 위젯이 그와 같은 모양으로 생성됩니다. 어떤 속성 카테고리(색상, 글꼴, 모서리 반경,
   크기, 회전, 텍스트, 이미지)를 이어받을지는 [에디터 설정](./editor-settings)에서 선택합니다.

이는 Add Widget 메뉴로 추가한 위젯에만 적용되며, 붙여넣거나 불러온 위젯은 자체
데이터를 유지합니다.
