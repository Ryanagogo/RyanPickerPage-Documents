# 라벨 위젯 \{#label-widget}

### 새 라벨 위젯 만들기 \{#creating-a-new-label-widget}

새 라벨 위젯을 만들려면 **편집 모드**여야 합니다

**피커 캔버스의 빈 곳을 마우스 오른쪽 버튼으로 클릭**해 팝업 메뉴를 연 다음 "라벨" 메뉴 항목을 클릭합니다

### 속성 편집기에서 \{#from-the-attribute-editor}

속성 편집기에서 값을 보려면 위젯을 하나만 선택해야 합니다

##### 라벨 모양 \{#label-appearance}

<img src={useBaseUrl('/img/quick-start/widget-label/label-appearance.png')} alt="label-appearance" style={{marginLeft: 0, zoom: '80%'}} />

- **색상**
  - 버튼의 색상을 설정합니다
- **글꼴**
  - 글꼴 색상과 글꼴 크기를 설정합니다

##### 라벨 텍스트 \{#label-text}

<img src={useBaseUrl('/img/quick-start/widget-label/label-text.png')} alt="label-text" style={{marginLeft: 0, zoom: '80%'}} />

- **라벨**

  - 라벨의 텍스트를 설정합니다

- **텍스트 스타일**

  - 긴 텍스트는 다음 설정으로 서식을 지정할 수 있습니다

    - Justification

    - Word Wrap

    - Margin

    - Clip

##### 라벨 이미지 \{#label-image}

<img src={useBaseUrl('/img/quick-start/widget-label/label-image.png')} alt="label-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - 프로젝트의 어떤 이미지 에셋이든 사용할 수 있습니다
- **스트레치 모드**
  - 위젯 크기를 채우기 위해 이미지를 어떻게 늘릴지 모드별로 결정합니다
- **스케일**
  - 이미지를 확대하거나 축소할 수 있습니다
- **오프셋**
  - 이미지를 위아래와 좌우로 이동할 수 있습니다
- **알파**
  - 이미지의 투명도를 설정할 수 있습니다. 투명할수록 위젯 색상이 더 많이 보입니다
