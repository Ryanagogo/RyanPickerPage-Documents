# 저장, 불러오기 및 파일 \{#saving-loading--files}

페이지는 디스크에서 원하는 위치의 **JSON 파일** 하나로 저장됩니다. 페이지는 Unreal
에셋이 아닙니다. `Content/`에 있지 않고, 만들어진 프로젝트가 필요하지 않으며,
일반 텍스트 파일처럼 공유하거나 이메일로 보내거나 버전 관리할 수 있습니다.

한 번 저장하면 페이지 전체가 담깁니다. 모든 위젯과 그 연결 및 스타일,
[북마크 행](./bookmarks), 토글 그룹, [Pose Map](./mirror-pose)이 포함됩니다.

## 파일 메뉴 \{#the-file-menu}

| 항목 | |
|---|---|
| **저장** | 페이지의 현재 파일에 다시 기록합니다. 한 번도 저장하지 않은 페이지에서는 다른 이름으로 저장처럼 동작합니다 |
| **다른 이름으로 저장** | 기본 저장 대화 상자 |
| **불러오기** | 기본 열기 대화 상자 |
| **최근 항목 불러오기** | 최근에 사용한 파일, 대화 상자 없음 |
| **다시 불러오기** | 현재 파일을 디스크에서 다시 읽습니다 |
| **Pose Map…** | [Pose Map 대화 상자](./mirror-pose#the-pose-map) |
| **Settings…** | [에디터 설정](./editor-settings) 대화 상자 |

저장 및 불러오기 대화 상자는 마지막으로 사용한 디렉터리에서 다시 열립니다.

## 도움말 메뉴 \{#the-help-menu}

항목은 전적으로 데이터 기반입니다. 페이지의 Class Defaults 패널에서 편집하는 라벨/URL/툴팁 항목
목록입니다. 코드 변경이나 재컴파일 없이 항목을 추가, 삭제, 재정렬하거나 대상을 바꿀 수 있으며,
항목을 클릭하면 OS 기본 브라우저에서 해당 URL이 열립니다. 항목 하나는 데이터 기반이 아니라
고정되어 있습니다. **정보** 항목으로, 플러그인 버전, Unreal Engine 버전,
작성자를 간단한 정보 대화 상자에 표시합니다.

## 오래된 파일도 계속 불러올 수 있습니다 \{#old-files-keep-loading}

저장 파일에는 스키마 버전이 있습니다. 오래된 파일을 불러오면 그 사이의 모든 스키마 변경을
자동으로 거쳐 마이그레이션됩니다. 초기 플러그인 버전에서 만든 페이지도 현재 버전에서
불러올 수 있으며, 다시 저장하기만 하면 현재 버전으로 기록됩니다. 마이그레이션할 수 없는
파일(또는 사용 중인 것보다 *더 새로운* 플러그인에서 만든 파일)은 반쯤 불러오는 대신
명확한 오류와 함께 거부됩니다.

개인 정보 관련 참고: 선택 버튼의 [Python 스크립트](./python-scripting)는 파일에
Base64로 인코딩되어 저장됩니다. 인코딩일 뿐 암호화가 아닙니다. 스크립트가 들어 있는 페이지 파일은
스크립트 자체처럼 다루세요.

## 세션 상태 \{#session-state}

플러그인은 페이지 파일 옆에(절대 그 안이 아니라) 파일 경로별로 마지막 작업 상태를
기억합니다. 캔버스 팬/줌, 활성 Control Rig, 편집 모드인지 라이브 모드인지입니다. 내일 같은 파일을
불러오면 캔버스가 정확히 떠났던 자리에 있습니다. 이 정보는 파일 경로를 키로 하여 사용자의 컴퓨터에
저장되므로, 페이지를 공유하면 레이아웃만 공유되고 받는 사람은 자신의 뷰 상태를 갖게 됩니다.
90일(구성 가능) 동안 사용되지 않은 항목은 정리됩니다.

## 플러그인이 자체 파일을 보관하는 위치 \{#where-the-plugin-keeps-its-own-files}

```
%APPDATA%\RyanTechAnimTools\RyanPicker\
├── settings.json              # 최근 파일, 마지막 대화 상자 디렉터리, 아웃라이너 보기
├── editor_settings.json       # 에디터 설정 대화 상자의 값
└── page_session_state.json    # 파일별 세션 상태, 절대 경로를 키로 사용
```

이 파일들은 사용자별, 컴퓨터별입니다. 삭제하면 편의 기능(최근 파일, 복원되는
뷰, 설정)은 사라지지만 페이지 데이터는 절대 사라지지 않습니다. 페이지는 저장한 파일 안에만 존재합니다.
