# 위젯 기본 \{#widget-basics}

### 위젯 만들기 \{#create-widgets}

- 새 위젯을 만들려면 편집 모드여야 합니다
- 캔버스의 빈 곳을 마우스 오른쪽 버튼으로 클릭하면 다양한 종류의 피커 위젯을 만드는 항목이 들어 있는 팝업 메뉴가 열립니다
- 새 위젯은 마우스 오른쪽 버튼을 클릭했을 때 마우스 포인터가 있던 위치에 배치됩니다.
- 위젯을 만들면 실행 취소 스택에 항목이 추가되므로 생성을 실행 취소하거나 다시 실행할 수 있습니다

### 위젯 삭제하기 \{#delete-widgets}

- 위젯을 삭제하려면 편집 모드여야 합니다
- "Delete" 키를 누르면 선택한 위젯을 모두 삭제할 수 있습니다
- 위젯 하나만 삭제하려면 해당 위젯을 마우스 오른쪽 버튼으로 클릭해 위젯 팝업 메뉴를 엽니다. 메뉴 맨 아래에 해당 위젯을 삭제하는 항목이 있습니다.
- 위젯을 삭제하면 실행 취소 스택에 항목이 추가되므로 삭제를 실행 취소하거나 다시 실행할 수 있습니다.

### 위젯 선택하기 \{#select-widgets}

- 위젯은 라이브 모드와 편집 모드 모두에서 선택할 수 있습니다
- 위젯을 클릭하거나 주위에 박스를 그려 선택할 수 있습니다
- 라이브 모드에서는 일부 위젯을 선택할 수 없습니다:
  - 라벨 위젯
  - 이미지 위젯
- 편집 모드에서는 모든 위젯을 선택할 수 있습니다
  - Outliner에서 위젯을 잠가 선택되지 않게 할 수 있습니다. 여러 위젯이 겹쳐 있을 때 유용합니다.
- 위젯을 선택한 순서가 기억됩니다. 이 선택 순서는 편집 모드의 일부 기능에서 사용됩니다

### 위젯 트랜스폼하기 \{#transform-widgets}

- 위젯을 트랜스폼하려면 편집 모드여야 합니다
- **이동**
  - 위젯을 하나 이상 선택한 상태에서 선택한 위젯 중 하나에 마우스를 올려 커서가 이동 커서로 바뀌게 합니다. 그런 다음 클릭하고 드래그하면 선택한 모든 위젯이 마우스를 따라 움직입니다.
- **회전**
  - 마우스가 위젯 위에 있고 커서가 이동 커서일 때 Alt 키를 누르고 있으면 커서가 회전 커서로 바뀝니다. 그런 다음 클릭하고 드래그하면 선택한 모든 위젯이 마지막으로 선택한 위젯을 중심으로 부드럽게 회전합니다.
  - Alt 키와 Shift 키를 함께 누르고 있으면 15도 단위로 회전합니다
- 위젯을 트랜스폼하면 실행 취소 스택에 항목이 추가되므로 트랜스폼을 실행 취소하거나 다시 실행할 수 있습니다.

### 위젯 크기 조절하기 \{#resize-widgets}

- 위젯 크기를 조절하려면 편집 모드여야 합니다
- 위젯의 가장자리나 모서리에 마우스 포인터를 올리면 커서가 가장자리 또는 모서리 크기 조절 커서로 바뀝니다. 그런 다음 클릭하고 드래그하면 위젯 크기를 조절할 수 있습니다.
- 크기 조절은 위젯 하나에만 적용됩니다
- 위젯 크기를 조절하면 실행 취소 스택에 항목이 추가되므로 크기 조절을 실행 취소하거나 다시 실행할 수 있습니다.

### 잘라내기, 복사, 붙여넣기 \{#cut-copy-and-paste}

- 위젯을 잘라내고, 복사하고, 붙여넣으려면 편집 모드여야 합니다
- 표준 단축키 Ctrl + X, Ctrl + C, Ctrl + V로 선택한 위젯을 잘라내고, 복사하고, 붙여넣을 수 있습니다
- 위젯 하나라면 마우스 오른쪽 버튼으로 클릭해 팝업 메뉴를 열면 잘라내기와 복사 메뉴 항목이 있습니다
- Ctrl + V를 사용하면 마우스 위치에 위젯이 붙여넣어집니다
- 캔버스의 빈 곳을 마우스 오른쪽 버튼으로 클릭하면 팝업 메뉴에 붙여넣기 옵션이 두 가지 있습니다
  - **붙여넣기**
    - 마우스 위치에 위젯을 붙여넣습니다
  - **제자리에 붙여넣기**
    - 복사하거나 잘라낸 위치와 같은 곳에 위젯을 붙여넣습니다

### 위젯 팝업 메뉴 \{#widget-popup-menu}

- 위젯 팝업 메뉴를 보려면 편집 모드여야 합니다
- 위젯을 마우스 오른쪽 버튼으로 클릭하면 팝업 메뉴가 열립니다
  - 처음 항목들은 위젯 이름과 종류, 그리고 잘라내기와 복사 옵션을 보여 줍니다
  - 마지막 항목은 위젯을 삭제하는 항목입니다
  - 나머지 메뉴 항목은 클릭한 위젯의 종류에 따라 다릅니다

### 속성 편집기 \{#attribute-editor}

- 속성 편집기를 보려면 편집 모드여야 합니다
- 속성 편집기는 위젯이 하나만 선택되었을 때만 속성을 표시합니다. 여러 위젯을 선택하면 아무것도 표시되지 않습니다. (이 동작은 향후 릴리스에서 변경될 예정입니다)
- 처음 항목들은 위젯의 이름과 종류를 알려 주며, 위젯을 잠가 선택되지 않게 하는 기능도 있습니다
  - 나머지 항목은 선택한 위젯의 종류에 따라 다릅니다

### Outliner \{#outliner}

- Outliner를 보려면 편집 모드여야 합니다
- Outliner는 Picker Page의 모든 위젯을 보여 주며, 표시 레이어별, 위젯 종류별 또는 그룹별(토글 위젯 그룹 전용)로 묶어 표시합니다
- 캔버스에서 위젯을 선택하면 Outliner의 해당 위젯 항목도 선택되며, 그 반대도 마찬가지입니다.
- Outliner에서 위젯 항목을 더블클릭하면 위젯 이름을 바꿀 수 있습니다
- 표시 레이어 뷰에는 위젯을 잠그거나 잠금 해제하는 체크박스가 있습니다. 잠긴 위젯은 편집 모드에서 선택할 수 없습니다. 여러 위젯이 겹쳐 있을 때 유용합니다.
- Outliner에서 위젯을 선택하면 "F" 단축키로 뷰를 해당 위젯에 포커스할 수 있습니다. 특정 위젯을 찾기 어려울 때 유용합니다
