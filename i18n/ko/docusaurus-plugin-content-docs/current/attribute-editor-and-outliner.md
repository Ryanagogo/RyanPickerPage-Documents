# 속성 편집기 및 Outliner \{#attribute-editor--outliner}

편집 모드의 사이드바 두 개입니다. 각각 헤더에 전용 토글이 있으므로 하나만, 둘 다, 또는
둘 다 숨긴 채로 화면을 구성할 수 있습니다.

## Outliner(왼쪽) \{#outliner-left}

페이지에 있는 모든 것의 목록입니다. 행을 클릭하면 위젯이 선택되고, 더블클릭하면 이름을 바꾸며,
마우스 오른쪽 버튼으로 클릭하면 이동/삭제할 수 있습니다. 목록 위의 버튼으로 세 가지 보기를 전환합니다.

- **유형별** — 여섯 가지 위젯 유형 헤더 아래에 묶어서 표시합니다. 평소에 쓰는 보기입니다.
- **레이어별** — [레이어 그룹](./editing-tools#layer-groups)별로 그리기 순서대로 표시합니다. 쌓임 순서는
  여기서 바꿉니다. 위젯을 다른 그룹으로 드래그하면 그 그룹으로 옮겨지고, 그룹 안에서 드래그하면
  순서가 바뀌며, 그룹 헤더 자체를 드래그하면 그룹 순서가 바뀝니다. 각 그룹 헤더에는
  자체 잠금 토글이 있고 독립적으로 접힙니다.
- **그룹별** — [토글 그룹](./widget-toggle#toggle-groups)을 이름 있는 헤더 아래에 멤버를 중첩해
  표시합니다. 그룹 이름 변경도 여기서 합니다.

위젯 이름은 페이지 내에서 고유합니다(대소문자 구분 없음). 이름이 겹치는 변경은
몰래 다른 이름으로 바뀌는 대신 거부되고 원래대로 되돌아갑니다. 마지막으로 사용한 보기는 세션 간에 전역으로 기억됩니다.

## 속성 편집기(오른쪽) \{#attribute-editor-right}

현재 선택된 위젯의 속성을 디테일 패널에 표시합니다. **한 번에 위젯 하나**만
편집합니다. 여러 위젯에 같은 변경을 일괄 적용하려면 대신
[툴바 도구](./editing-tools#toolbar-tools)를 사용하세요.

표시되는 필드는 위젯 유형에 따라 다르며, 각 위젯 페이지에서 해당 필드를 설명합니다.
공통 블록(위치, 크기, 회전, 모서리 반경, 위젯 이름)은 항상 표시됩니다.

알아 두면 좋은 동작 두 가지:

- **진행 중인 편집은 선택이 바뀌기 전에 확정됩니다.** 필드를 편집하는 도중에
  다른 위젯을 클릭하면, 보류 중인 값은 실제로 편집하던 위젯에 확정됩니다.
  새로 선택한 위젯으로 값이 새어 나가지 않습니다.
- **2D 슬라이더의 같은 채널 경고**는 패널 안에 색상 배너로 표시됩니다.
  [2D 슬라이더](./widget-2d-slider)를 참조하세요.

## 모서리 반경 \{#corner-radius}

위젯의 모서리 둥글기는 3단계 캐스케이드로 결정되며, 가장 구체적인 설정이 우선합니다.

1. **위젯별 재정의** — 개별 위젯에 설정하는 "override corner radius" 플래그와
   사용자 지정 값.
2. **유형별 Class Default** — 각 위젯 유형은 페이지의 Class Defaults 패널에서 자체
   기본값을 설정할 수 있습니다.
3. **전역 기본값** — 버튼/슬라이더/토글 유형은 10, 라벨과 이미지는 기본적으로
   각진 모서리(0)입니다. 전역 대체값은 [에디터 설정](./editor-settings)에서 조정할 수 있습니다.

사용자 지정하지 않은 위젯은 캐스케이드를 실시간으로 따릅니다. 유형 기본값을 올리면
재정의하지 않은 해당 유형의 모든 위젯이 함께 업데이트됩니다.

## 위젯 잠금 \{#widget-locking}

어떤 위젯이든 잠글 수 있습니다. 속성 편집기의 체크박스, Outliner의 행이나 그룹 헤더에 있는
잠금 아이콘, 또는 마우스 오른쪽 클릭 메뉴의 **잠금**/**선택 항목 잠금 해제**를 사용합니다.

잠금은 편집 모드에만 영향을 줍니다. 잠긴 위젯은 편집 모드에서 선택, 이동, 크기 조절을 할 수 없고,
이동/크기 조절 핸들도 완전히 사라집니다. 라이브 모드와 Outliner 목록 자체에는 영향이 없습니다.
잠긴 위젯도 라이브 모드에서 클릭하면 정상적으로 동작하며, Outliner에서는 계속 보이고
이름을 바꿀 수 있습니다. Outliner 헤더에서 [레이어 그룹](./editing-tools#layer-groups)을 잠그면
그 멤버도 모두 같은 방식으로 잠깁니다.

잠금은 배치를 끝내서 주변에서 작업하다 실수로 움직이고 싶지 않은 위젯을 위한 기능입니다.
예를 들어 배경 이미지나 완성된 버튼 줄 같은 것입니다.

## 라이브 모드 툴팁 \{#live-mode-tooltip}

라이브 모드에서 위젯 위에 마우스를 올리면 연결 내용을 요약한 툴팁이 표시됩니다. 위젯의 이름과
조작하는 컨트롤/액터를 보여 주므로, 낯선 페이지를 편집 모드에 들어가지 않고 살펴보는 가장 빠른 방법입니다.
