# 북마크 \{#bookmarks}

*캔버스용 이름 있는 카메라 위치입니다.*

전신 피커에서는 얼굴, 손, 발 같은 영역 사이를 끊임없이 오가게 됩니다. 북마크를 사용하면
매번의 이동이 클릭 한 번으로 끝납니다. 북마크는 캔버스의 팬/줌 뷰를 저장하며, 헤더 행에 있는
북마크 버튼을 클릭하면 캔버스가 즉시 그 위치로 이동합니다.

## 북마크 행 \{#the-bookmark-row}

- **기본값**은 항상 존재하며 스크롤되는 행 바깥에 항상 표시됩니다. "홈"으로
  생각하면 됩니다.
- **사용자 슬롯**(기본 4개, 최대 8개, [에디터 설정](./editor-settings) 참조)은 그 옆의
  가로 스크롤 행에 위치하며, 위치 순서대로 번호가 매겨지고 이름을 지정할 수 있습니다.

## 북마크 사용하기 \{#working-with-bookmarks}

| 작업 | 방법 |
|---|---|
| 뷰로 이동 | 버튼 클릭 |
| 현재 뷰 저장 | 버튼을 **Ctrl+Shift+클릭**하거나 마우스 오른쪽 클릭 → 설정 / 덮어쓰기. 확인 표시로 버튼이 녹색으로 깜박입니다 |
| 슬롯 이름 바꾸기 | 마우스 오른쪽 클릭 → 이름 바꾸기 |
| 슬롯 추가 | 마우스 오른쪽 클릭 → 앞에 북마크 추가 / 뒤에 북마크 추가 |
| 순서 변경 | 마우스 오른쪽 클릭 → 왼쪽으로 이동 / 오른쪽으로 이동. 자리를 바꾼 두 버튼이 주황색으로 깜박입니다 |
| 삭제 / 재설정 | 마우스 오른쪽 클릭 → 삭제 또는 Reset to Identity |

북마크 편집에는 레이아웃 실행 취소와 완전히 독립된 **자체 30단계 실행 취소 스택**이 있습니다.
캔버스에서 Ctrl+Z를 눌러도 북마크 변경이 취소되는 일은 없으며, 북마크 실행 취소가
레이아웃을 건드리는 일도 없습니다.

북마크는 다른 모든 내용과 함께 페이지 파일에 저장됩니다. 버튼 너비, 글꼴, 안쪽 여백,
두 가지 확인 깜박임 색상은 Class Defaults 패널에서 페이지별로 조정할 수 있습니다.
