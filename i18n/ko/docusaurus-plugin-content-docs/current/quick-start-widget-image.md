# 이미지 위젯 \{#image-widget}

### 새 이미지 위젯 만들기 \{#creating-a-new-image-widget}

새 이미지 위젯을 만들려면 **편집 모드**여야 합니다

**피커 캔버스의 빈 곳을 마우스 오른쪽 버튼으로 클릭**해 팝업 메뉴를 연 다음 "이미지" 메뉴 항목을 클릭합니다

### 속성 편집기에서 \{#from-the-attribute-editor}

속성 편집기에서 값을 보려면 위젯을 하나만 선택해야 합니다

##### 이미지 위젯 이미지 \{#image-widget-image}

<img src={useBaseUrl('/img/quick-start/widget-image/image-widget-image.png')} alt="image-widget-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - 프로젝트의 어떤 이미지 에셋이든 사용할 수 있습니다
- **스트레치 모드**
  - 위젯 크기를 채우기 위해 이미지를 어떻게 늘릴지 모드별로 결정합니다
- **스케일**
  - 이미지를 확대하거나 축소할 수 있습니다
- **오프셋**
  - 이미지를 위아래와 좌우로 이동할 수 있습니다
- **알파**
  - 이미지의 투명도를 설정할 수 있습니다. 투명할수록 위젯 색상이 더 많이 보입니다
