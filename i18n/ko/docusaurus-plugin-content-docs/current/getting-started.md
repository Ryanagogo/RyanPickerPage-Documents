# 시작하기 \{#getting-started}

## 페이지 열기 \{#opening-a-page}

**Tools → Ryan Picker Page**를 선택하면 새 에디터 탭에 페이지가 열립니다. 페이지 헤더의 **New Tab** 버튼으로
더 많은 페이지를 열 수 있습니다. 각 탭은 완전히 독립적이며 자체 파일, 자체 Control Rig 선택,
자체 캔버스 뷰를 가집니다. 페이지 이름을 바꾸면(제목은 편집 모드에서 편집 가능) 탭 이름도
바뀌므로 피커를 여러 개 열어 두어도 쉽게 찾아갈 수 있습니다.

## 두 가지 모드 \{#two-modes}

헤더의 편집 모드 버튼은 페이지 전체를 다음 두 모드 사이에서 전환합니다.

**라이브 모드** — 애니메이션 작업 모드입니다. 위젯을 클릭하면 리그 컨트롤과 액터가 선택되고, 슬라이더를
드래그하면 트랜스폼이 조작됩니다. 위젯 위에 마우스를 올리면 무엇에 연결되어 있는지 툴팁으로 표시됩니다. 레이아웃
자체는 변경할 수 없습니다.

**완성된 페이지는 라이브 모드에서 사용됩니다.**
[편집 및 캔버스 도구](./editing-tools)의 모든 내용은 여기에 도달하기 위한 것입니다.

**편집 모드** — 구성 모드입니다. 위젯에 이동/크기 조절/회전 핸들이 나타나고, 캔버스의 빈 곳을
마우스 오른쪽 버튼으로 클릭하면 **Add Widget** 메뉴가 열리며, 접을 수 있는 사이드바 두 개가 나타납니다. 왼쪽은
[Outliner](./attribute-editor-and-outliner), 오른쪽은
[속성 편집기](./attribute-editor-and-outliner)입니다.

## 첫 페이지 만들기 \{#build-your-first-page}

다리 하나짜리 최소 피커를 처음부터 끝까지 만들어 봅니다.

1. 캐릭터와 그 Control Rig가 포함된 Level Sequence를 연 다음 피커 페이지를 엽니다.
   헤더의 리그 드롭다운은 포커스된 시퀀스에서 자동으로 채워집니다. 리그를 선택하세요(리그가
   하나뿐이면 자동으로 선택됩니다).
2. **편집 모드**로 들어갑니다.
3. 뷰포트나 Anim Outliner에서 허벅지 컨트롤을 선택합니다. 캔버스를 마우스 오른쪽 버튼으로 클릭 →
   **Add Widget → 선택 버튼**을 선택합니다. 기본적으로 새 버튼은 현재 선택에서 대상 목록을
   가져오므로, 이 버튼은 이미 허벅지를 조작합니다.
4. 종아리와 발에 대해서도 반복합니다.
   [속성 편집기](./attribute-editor-and-outliner)의 라벨 필드로 각 버튼의 이름을 지정하고, 드래그해서
   다리 모양의 열로 배치합니다.
5. 세 개를 모두 선택하고 [정렬 도구](./editing-tools)로 열을 반듯하게 맞춰 보세요.
6. 편집 모드를 종료합니다. 버튼을 클릭하면 각각 해당 컨트롤이 선택됩니다. 이것이 기본 흐름이며, 나머지는 모두
   다듬는 작업입니다.
7. **파일 → 저장**은 페이지를 원하는 위치의 JSON 파일로 저장합니다.
   [저장, 불러오기 및 파일](./save-load-and-files)을 참조하세요.

## 실행 취소, 다시 실행 및 안전장치 \{#undo-redo-and-safety-nets}

편집 모드의 모든 변경 사항(이동, 크기 조절, 추가, 삭제, 붙여넣기, 색상 편집)은 페이지의
실행 취소 스택에 기록됩니다(기본 30단계, [에디터 설정](./editor-settings) 참조). Ctrl+Z /
Ctrl+Y 또는 헤더의 버튼을 사용합니다. 색상 선택기 안에서 드래그하면 움직임마다가 아니라 하나의 실행 취소 단계로
합쳐지므로, 색상 변경을 실행 취소하면 드래그 전체가 취소됩니다.

[북마크](./bookmarks)는 별도의 자체 실행 취소 스택을 가집니다. 레이아웃 실행 취소가 저장된 뷰를
건드리는 일은 없으며, 그 반대도 마찬가지입니다.

## 중단한 곳에서 다시 시작하기 \{#picking-up-where-you-left-off}

저장된 파일마다 플러그인은 캔버스의 팬/줌, 활성화되어 있던 Control Rig,
편집 모드와 라이브 모드 중 어느 쪽이었는지를 기억하며, 다음에 이 컴퓨터에서 해당 파일을 불러올 때
모두 자동으로 복원됩니다. 이 정보는 페이지 파일 외부에 저장되므로, 팀원과 페이지를 공유하면
보기 습관이 아니라 레이아웃이 공유됩니다.
[저장, 불러오기 및 파일](./save-load-and-files#session-state)을 참조하세요.
