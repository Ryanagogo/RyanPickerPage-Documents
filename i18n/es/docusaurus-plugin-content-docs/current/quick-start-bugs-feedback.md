# Errores y comentarios \{#bugs-and-feedback}

### El menú Ayuda \{#the-help-menu}

En la esquina superior izquierda de la Picker Page deberías ver el menú Ayuda junto al menú Archivo.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu.png')} alt="help-menu" style={{marginLeft: 0, zoom: '80%'}} />

Al hacer clic en el menú Ayuda, verás varias opciones útiles, entre ellas opciones para sugerir funciones, informar de errores o enviarme un mensaje.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu-items.png')} alt="help-menu-items" style={{marginLeft: 0, zoom: '80%'}} />

Al hacer clic en cualquiera de estas opciones, se abrirá un enlace en tu navegador web para que puedas rellenar un formulario.

Sugerir una función e Informar de un error añaden elementos directamente a mi sistema de seguimiento de tickets, y Contacto envía un mensaje a mi correo electrónico profesional.

También puedes usar estos enlaces para ir directamente a esos formularios:

- **[Informar de un error](https://tally.so/r/ODx6Np)**
- **[Sugerir una función](https://tally.so/r/D4RjLp)**
- **[Contacto](https://tally.so/r/RG9N6l)**
