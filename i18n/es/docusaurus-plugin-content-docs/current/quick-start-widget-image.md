# Widget de imagen \{#image-widget}

### Crear un widget de imagen nuevo \{#creating-a-new-image-widget}

Debes estar en el **modo de edición** para crear un widget de imagen nuevo

**Haz clic derecho en una zona vacía del lienzo del picker** para abrir el menú emergente y, a continuación, haz clic en la opción "Imagen"

### Desde el editor de atributos \{#from-the-attribute-editor}

Para ver los valores en el editor de atributos, debes seleccionar un único widget

**Color**

- Establece el color del botón

##### Imagen del widget de imagen \{#image-widget-image}

<img src={useBaseUrl('/img/quick-start/widget-image/image-widget-image.png')} alt="image-widget-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - Usa cualquier recurso de imagen de tu proyecto
- **Modo de ajuste**
  - Los distintos modos determinan cómo se estira la imagen para intentar ocupar todo el tamaño del widget
- **Escala**
  - Permite acercar o alejar la imagen
- **Desplazamiento**
  - Permite desplazar la imagen hacia arriba y hacia abajo, y de lado a lado
- **Alfa**
  - Permite establecer la transparencia de la imagen. Cuanto más transparente sea, más se verá el color del widget
