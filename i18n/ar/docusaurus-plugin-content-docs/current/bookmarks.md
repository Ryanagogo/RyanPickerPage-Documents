# الإشارات المرجعية \{#bookmarks}

*مواضع كاميرا مُسمّاة للوحة.*

في أداة انتقاء لكامل الجسم، تنتقل باستمرار بين المناطق — الوجه واليدين والقدمين. تجعل الإشارات المرجعية
كل انتقال بنقرة واحدة: تحفظ الإشارة المرجعية عرضًا للوحة (الإزاحة والتكبير)، والنقر على زرها في
صف الرأس ينقل اللوحة إليه فورًا.

## صف الإشارات المرجعية \{#the-bookmark-row}

- **افتراضي** موجود دائمًا ومرئي دائمًا، خارج الصف القابل للتمرير — اعتبره
  "الصفحة الرئيسية".
- **خانات المستخدم** — 4 افتراضيًا، وحتى 8 (راجع [إعدادات المحرر](./editor-settings)) — تقع في
  صف قابل للتمرير أفقيًا بجانبه، مرقّمة حسب موضعها ويمكن تسميتها.

## العمل مع الإشارات المرجعية \{#working-with-bookmarks}

| الإجراء | الطريقة |
|---|---|
| الانتقال إلى عرض | انقر على الزر |
| حفظ العرض الحالي | **Ctrl+Shift+نقرة** على الزر، أو نقرة يمنى ← تعيين / استبدال — يومض الزر بالأخضر للتأكيد |
| إعادة تسمية خانة | نقرة يمنى ← إعادة تسمية |
| إضافة خانة | نقرة يمنى ← إضافة إشارة مرجعية قبل / إضافة إشارة مرجعية بعد |
| إعادة الترتيب | نقرة يمنى ← نقل لليسار / نقل لليمين — يومض الزران المتبادلان بالبرتقالي |
| الإزالة / إعادة الضبط | نقرة يمنى ← حذف، أو Reset to Identity |

لتعديلات الإشارات المرجعية **مكدّس تراجع خاص بها من 30 خطوة**، مستقل تمامًا عن التراجع في التخطيط —
لن يبتلع Ctrl+Z على اللوحة أبدًا تغييرًا في إشارة مرجعية، ولن يمسّ التراجع في الإشارات المرجعية أبدًا
التخطيط.

تُحفظ الإشارات المرجعية في ملف الصفحة مع كل شيء آخر. يمكن ضبط عرض الأزرار والخط والحشو
ولونَي وميض التأكيد لكل صفحة في لوحة Class Defaults.
