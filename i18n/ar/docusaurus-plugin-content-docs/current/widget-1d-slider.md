# Slider أحادي البُعد \{#1d-slider}

*شريط تمرير مرتبط بقناة تحويل واحدة بالضبط.*

## في الوضع المباشر \{#in-live-mode}

يكتب سحب الشريط قيمته في **قناة واحدة** — الإزاحة أو الدوران أو القياس، على X أو Y
أو Z — لكل عنصر تحكم Control Rig وممثل هدف معيّن. لا يُمسّ أي شيء آخر:
يقرأ الشريط التحويل الحالي لكل هدف، ويستبدل القناة الوحيدة التي يملكها، ثم يعيد كتابة
التحويل. تمر تغييرات القيمة عبر مسار التطبيق نفسه الذي يستخدمه باقي الإضافة،
بما في ذلك المفتاح التلقائي (Auto-key) في Sequencer، لذا تُنشئ حركات الشريط مفاتيح كما تفعل عناصر التحكم المحرَّكة يدويًا.

لأن الـ Slider أحادي البُعد لا يستحوذ أبدًا على قنوات لا يملكها، يمكن لعدة أشرطة أن تتحكم في قنوات مختلفة
لعنصر التحكم *نفسه* جنبًا إلى جنب — فلن يتعارض "رفع" عبر إزاحة Y مع "دحرجة" عبر دوران Z على
عنصر تحكم القدم نفسه.

يتيح النقر بزر الفأرة الأيمن على الشريط الأمر **إعادة الضبط إلى القيمة الأولية**، الذي يعيده إلى القيمة
الافتراضية المحدّدة.

## نموذج القيم \{#value-model}

ثلاثة أرقام مهمة، ولا يتغير منها سوى اثنين:

- **القيمة الدنيا / القيمة القصوى** — النطاق الذي يُطابَق عليه السحب.
- **Current Value** — القيمة الحالية؛ يكتبها السحب، وهي ما يُطبَّق على الأهداف.
- **القيمة الأولية** — قيمة افتراضية يحددها المؤلف ولا يمسّها السحب *أبدًا*. لا تتغير إلا
  عمدًا في محرر الخصائص، مما يجعلها قيمة آمنة دائمًا يمكن للأمر
  "إعادة الضبط إلى القيمة الأولية" العودة إليها.

يؤدي **حجم الخطوة** الاختياري إلى التقاط السحب بزيادات محددة، ويعطّل **مقفل** السحب
تمامًا (لشريط مرجعي لا تريد أن يتحرك عن غير قصد في منتصف اللقطة).

## الإنشاء \{#authoring}

حقول محرر الخصائص: التسمية/الاسم، القيم الدنيا/القصوى/الحالية/الأولية، **نشط القناة** (القناة
الوحيدة التي يتحكم فيها هذا الشريط)، **الاتجاه** (أفقي/رأسي)، لون الشريط، لون المقبض،
سماكة الشريط، نمط المقبض الغائر، القفل، حجم الخطوة — إضافة إلى حقول تعيين الأهداف
المشتركة مع [زر التحديد](./widget-select-button) وكتلة
الموضع/الحجم/الدوران/نصف قطر الزاوية المشتركة.

## البرمجة \{#scripting}

`URyanPicker1DSliderFunctionLibrary` (الفئة `Ryan Picker Page|1DSlider`):

| الدالة | |
|---|---|
| `GetMinValue` / `SetMinValue` · `GetMaxValue` / `SetMaxValue` | النطاق |
| `GetCurrentValue` / `SetCurrentValue` | القيمة الحالية |
| `GetInitialValue` / `SetInitialValue` | نقطة إعادة الضبط المحدّدة |
| `GetActiveChannel` / `SetActiveChannel` | `EPickerSliderChannel`: Translate/Rotate/Scale × X/Y/Z |
| `GetOrientation` / `SetOrientation` | |
| `GetBarColor` / `SetBarColor` · `GetHandleColor` / `SetHandleColor` | |
| `GetBarThickness` / `SetBarThickness` · `GetHandleIndented` / `SetHandleIndented` | |
| `GetLocked` / `SetLocked` · `GetStepSize` / `SetStepSize` | |
| `GetControlNames` · `GetTargetActorGUIDs` / `GetTargetActorBindingGUIDs` | الأهداف |

يمكن للأصناف الفرعية من Blueprint تنفيذ `BI_RyanPicker1DSlider`: `OnSliderConstructed`،
`OnSliderValueChanged(float)`، `OnSliderDragBegin`، `OnSliderDragEnd(bool bValueChanged)`، إضافة إلى
[أحداث دورة الحياة المشتركة](./blueprint-api#event-hooks).
