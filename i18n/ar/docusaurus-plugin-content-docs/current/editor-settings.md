# إعدادات المحرر \{#editor-settings}

يفتح **ملف ← Settings…** مربع حوار الإعدادات العامة للإضافة. هذه تفضيلات **خاصة بكل جهاز**
تنطبق على كل صفحة تفتحها، على عكس Class Defaults الخاصة بكل صفحة (المحفوظة في
Blueprint الصفحة) والبيانات الخاصة بكل ملف (المحفوظة في ملف الصفحة).

## سلوك الأدوات الجديدة \{#new-widget-behavior}

| الإعداد | الافتراضي | |
|---|---|---|
| Seed New Widget Targets From Selection | مفعّل | تملأ الأزرار وأشرطة التمرير الجديدة أهدافها مسبقًا من التحديد الحالي — راجع [كيف تُعيَّن الأهداف](./control-rig-and-targets#how-targets-get-assigned) |
| Default Interactive Selection Mode | معطّل | تبدأ أزرار التحديد الجديدة في [وضع التحديد التفاعلي](./widget-select-button#interactive-selection-mode) |
| الحجم الافتراضي للأداة الجديدة | 200 × 100 | مع خانة اختيار **Override** — عند تعطيلها تكون الغلبة لقيمة Class Defaults الخاصة بالصفحة؛ وعند تفعيلها تحلّ قيمة هذا المربع محلها |
| نصف قطر الزاوية الافتراضي | 10 | الترتيب نفسه لخانة Override؛ وهي القيمة الاحتياطية العامة في [سلسلة التقريب](./attribute-editor-and-outliner#corner-radius) |

## فئات Sticky Defaults \{#sticky-defaults-categories}

سبع خانات اختيار — **اللون، الخط، نصف قطر الزاوية، الحجم، الدوران، النص، الصورة**، وجميعها مفعّلة
افتراضيًا — تتحكم في مجموعات الخصائص التي ينقلها فعليًا
[Copy to Sticky Defaults](./editing-tools#widget-defaults) إلى الأدوات الجديدة.
عطّل الحجم والدوران مثلًا لتصبح القيم الافتراضية الثابتة (sticky defaults) تجميلية بحتة.

## الصفحة والصيانة \{#page--housekeeping}

| الإعداد | الافتراضي | |
|---|---|---|
| العدد الافتراضي للإشارات المرجعية | 4 | خانات [الإشارات المرجعية](./bookmarks) للمستخدم في صفحة جديدة (8 كحد أقصى) |
| عمق مكدس التراجع | 30 | خطوات التراجع/الإعادة في الصفحة الرئيسية |
| الحد الأقصى لعمر حالة الجلسة | 90 يومًا | تُحذف إدخالات [حالة الجلسة](./save-load-and-files#session-state) الأقدم من ذلك؛ والقيمة 0 تعطّل الحذف |

## نمط التجاوز \{#the-override-pattern}

بالنسبة إلى القيم الموجودة أيضًا ضمن Class Defaults الخاصة بالصفحة (حجم الأداة، نصف قطر الزاوية)، يتنحّى هذا المربع
عمدًا: تكون Class Defaults الخاصة بـ Blueprint الصفحة هي المرجع إلى أن تحدّد هنا
خانة **Override** المقابلة. يحافظ ذلك افتراضيًا على ضبط Blueprint الصفحة المشترك،
مع السماح لجهاز بعينه بفرض قيمه الخاصة.
