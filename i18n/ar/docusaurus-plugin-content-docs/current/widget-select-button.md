# زر التحديد \{#select-button}

*الأداة الأساسية: زر يحدّد الأشياء.*

## في الوضع المباشر \{#in-live-mode}

يؤدي النقر على زر التحديد إلى تحديد عناصر تحكم Control Rig والممثلين المستهدفين المعيّنين له — في
نافذة العرض وفي الـ Rig وفي Sequencer حيث تكون مرتبطة — ثم يشغّل
[برنامج Python النصي](./python-scripting) الخاص به إن وُجد. يمكن للزر أن يحمل عنصر تحكم واحدًا أو مجموعة
كاملة ("تحديد كل الأصابع")، ويمكنه المزج بحرية بين عناصر تحكم الـ Rig والممثلين العاديين.

**Ctrl+نقرة** تبدّل بدلًا من الاستبدال: إذا لم تكن جميع أهداف الزر محددة بعد،
فإنها تُضاف إلى التحديد الحالي؛ وإذا كانت محددة بالفعل، فإنها تُزال منه — ويبقى باقي
تحديدك كما هو في الحالتين.

## سلوكا تحديد \{#two-selection-behaviors}

يعمل زر التحديد في أحد وضعين، يُبدَّل بينهما بخانة الاختيار **وضع التحديد التفاعلي**
في محرر الخصائص:

### وضع مجموعة التحديد (افتراضي) \{#selection-set-mode-default}

الزر مجموعة تحديد محفوظة. نقرة ← تصبح أهدافه هي التحديد. لا يتتبع الزر
ما تحدده في أماكن أخرى.

### وضع التحديد التفاعلي \{#interactive-selection-mode}

يصبح الزر انعكاسًا حيًا لتحديد المحرر، على غرار سلوك أدوات انتقاء التحريك
التقليدية:

- تستطلع الصفحة التحديد الحالي في نافذة العرض/الـ Rig عدة مرات في الثانية و**تُضيء
  الزر** كلما كانت جميع أهدافه ضمن التحديد الحالي — حدّد عنصر التحكم في
  نافذة العرض، وسيتوهّج زره على الصفحة من تلقاء نفسه.
- تحدّد النقرة **بالإضافة** — تنضم أهداف الزر إلى ما هو محدد بالفعل
  بدلًا من استبداله، لذا فإن النقر على عدة أزرار تفاعلية يبني تحديدًا تدريجيًا.
- تُزيل Ctrl+نقرة أهداف الزر من التحديد، كما سبق.

صُمّم هذا الوضع لـ**عنصر تحكم واحد (أو ممثل واحد) لكل زر**. تفعيله على زر
له عدة أهداف يعمل، لكنه يُظهر إشعار تحذير — فالزر متعدد الأهداف لا يمكنه
عكس تحديد جزئي دون التباس. لا يعمل الاستطلاع إلا عندما تكون علامة تبويب الصفحة في
المقدمة ويكون وضع التحرير متوقفًا، لذا لا تكلّف علامات التبويب في الخلفية شيئًا.

يمكن جعل الأزرار الجديدة تبدأ افتراضيًا في أي من الوضعين عبر [إعدادات المحرر](./editor-settings).

## الإنشاء \{#authoring}

مع تحديد الزر في وضع التحرير، يعرض محرر الخصائص:

- **التسمية** (وما إذا كانت تظهر)، واسم الأداة، وحجم الخط
- **لون الخلفية** و**لون الخط**
- **أسماء عناصر التحكم** — تُحلّ مقابل الـ Rig الحالي للصفحة؛ راجع
  [Control Rig والممثلون المستهدفون](./control-rig-and-targets)
- **الممثلون المستهدفون** — ملخص محلول وقابل للقراءة لكل ممثل معيّن
- خانة الاختيار **وضع التحديد التفاعلي**
- **برنامج Python النصي** — متعدد الأسطر؛ يعمل بعد التحديد في كل نقرة
- الموضع والحجم والدوران ونصف قطر الزاوية — مشتركة بين جميع الأدوات

تأخذ الأزرار الجديدة قائمة أهدافها مما هو محدد لحظة إنشائها (وهو
[إعداد](./editor-settings) مفعّل افتراضيًا) — وأسرع دورة إنشاء هي *التحديد في
نافذة العرض، ثم إضافة الزر، وانتهى الأمر*.

## البرمجة \{#scripting}

توجد دوال Blueprint في `URyanPickerSelectButtonFunctionLibrary`
(الفئة `Ryan Picker Page|SelectControl`)؛ أما دوال التحويل/المظهر المشتركة ففي
[مكتبة الأدوات المشتركة](./blueprint-api).

| الدالة | |
|---|---|
| `GetControlNames` | أسماء عناصر تحكم الـ Rig المعيّنة |
| `GetTargetActorGUIDs` / `GetTargetActorBindingGUIDs` | الممثلون المعيّنون، في كلا فضاءي الهوية — راجع [الكائنات القابلة للإنشاء في Sequencer](./control-rig-and-targets#sequencer-spawnables) |
| `GetBackgroundColor` / `SetBackgroundColor` | |
| `GetFontColor` / `SetFontColor` | |
| `GetFontSize` / `SetFontSize` | |
| `GetPythonScript` / `SetPythonScript` | |
| `GetInteractiveSelectionMode` / `SetInteractiveSelectionMode` | تُصدر دالة التعيين تحذيرًا (دون منع) للأزرار متعددة الأهداف |

يمكن للأصناف الفرعية من Blueprint تنفيذ أحداث الواجهة `BI_RyanPickerSelectButton`:
`OnSelectButtonConstructed`، `OnSelectButtonClicked`، `OnControlRigControlsSelected`،
`OnTargetActorsSelected`، إضافة إلى [أحداث دورة الحياة الثلاثة](./blueprint-api#event-hooks) التي يشترك فيها كل
نوع أداة. راجع [أدوات Blueprint المخصصة](./blueprint-api#custom-widget-blueprints) لمعرفة
كيف يظهر الصنف الفرعي في قائمة Add Widget.
