# البرمجة بلغة Python \{#python-scripting}

*اربط Python الخاص بالمحرر بنقرة — دون صنف فرعي من Blueprint ودون تصريف.*

تحمل [أزرار التحديد](./widget-select-button) برنامجًا نصيًا اختياريًا واحدًا بلغة Python؛
وتحمل [مفاتيح التبديل](./widget-toggle) برنامجًا **لكل حالة**. يعمل البرنامج النصي في بيئة Python الخاصة بالمحرر
(الوحدة القياسية `unreal` وكل ما يوفره Python Editor Script Plugin)
في كل مرة يُنقر فيها على الأداة في الوضع المباشر.

## ترتيب التنفيذ \{#execution-order}

يعمل البرنامج النصي **بعد** انتهاء عمل التحديد الناتج عن النقرة — أي بعد تحديد عناصر التحكم وتحديد
الممثلين وتبديل حالة مفتاح التبديل بالفعل. لذا يمكن لبرنامجك النصي أن يفترض أن أهداف الأداة
هي التحديد الحالي وأن يتصرّف بناءً عليها:

```python
import unreal

# يعمل بعد أن تكون أهداف الزر محدّدة بالفعل.
for actor in unreal.EditorLevelLibrary.get_selected_level_actors():
    unreal.log(f"picker clicked: {actor.get_actor_label()}")
```

في مفتاح التبديل، تُشغّل الحالة التي جرى التبديل *إليها* للتو برنامجها النصي — فيمكن لمفتاح تبديل IK/FK أن يشغّل
منطق المطابقة/الالتقاط عند كل انتقال، وفي كل اتجاه.

## الكتابة والتخزين \{#authoring-and-storage}

حرّر البرنامج النصي في حقل **برنامج Python النصي** في محرر الخصائص مع تحديد الأداة في
وضع التحرير، أو من Blueprint عبر `GetPythonScript` / `SetPythonScript` (زر التحديد) و
`GetPythonScriptForState` / `SetPythonScriptForState` (مفتاح التبديل).

في ملف الصفحة المحفوظ يُخزَّن البرنامج النصي بترميز Base64 — وهذا تفصيل خاص بالنقل، وليس إجراءً أمنيًا.
فهو نص عادي في واجهة المحرر وفي Blueprint وفي الذاكرة، ويعمل بكامل صلاحيات Python
في المحرر. **حمّل الصفحات من مصادر تثق بها فقط**، وهو المعيار نفسه الذي تطبّقه على أي
برنامج نصي للمحرر، وتعامل مع ملفات الصفحات المشتركة على أنها شيفرة برمجية عند مراجعتها.
