# تسمية \{#label}

*نص على اللوحة. تمر النقرات عبره مباشرة.*

التسميات للتعليقات التوضيحية: عناوين الأقسام ("الذراع اليسرى")، والملاحظات، والصور المرفقة بشرح. ليس لها
أي سلوك عند النقر في الوضع المباشر ولا أهداف معيّنة — وهذا يعني أيضًا أنها نوع الأداة الوحيد
(إلى جانب [الصورة](./widget-image)) الذي يمكنك وضعه في طبقات بحرية دون أن يسرق النقرات من
عناصر التحكم المحيطة به.

يمكن للتسمية أن تعرض **اسم Control Rig الحالي** مباشرةً بدلًا من نص ثابت — ضع واحدة في
زاوية الصفحة وستخبر المحرّك دائمًا بالـ Rig الذي تتحكم فيه علامة التبويب هذه.

## الإنشاء \{#authoring}

- **النص**، حجم الخط، لون الخط، **المحاذاة**، **الالتفاف التلقائي**
- **لون الخلفية**، واختياريًا **صورة** خلفية بوضع تمديد خاص بها و
  [قص مع إزاحة/تكبير](./widget-image#crop-panzoom)
- **ألفا الصورة** — عتامة صورة الخلفية تلك فوق لون الخلفية، من 0 إلى 1
- نصف قطر الزاوية: زوايا التسميات حادة افتراضيًا (نصف القطر 0)، لكنها تشارك في
  [سلسلة التقريب](./attribute-editor-and-outliner#corner-radius) نفسها مثل جميع الأنواع الأخرى
- كتلة الموضع/الحجم/الدوران المشتركة

تعرض التسميات خلفيتها باستخدام مادة الزوايا المستديرة نفسها التي تستخدمها
[الصورة](./widget-image#rendering)، لذا يتصرف التقريب وقص الصورة بشكل متطابق في كلتيهما.

## البرمجة \{#scripting}

`URyanPickerLabelFunctionLibrary` (الفئة `Ryan Picker Page|Label`):

| الدالة | |
|---|---|
| `GetText` / `SetText` | |
| `GetFontSize` / `SetFontSize` · `GetFontColor` / `SetFontColor` | |
| `GetTextJustification` / `SetTextJustification` · `GetAutoWrapText` / `SetAutoWrapText` | |
| `GetBackgroundColor` / `SetBackgroundColor` | |
| `GetImage` / `SetImage` · `GetStretchMode` / `SetStretchMode` | صورة الخلفية |
| `GetImageScale` / `SetImageScale` · `GetImageOffset` / `SetImageOffset` | القص مع الإزاحة/التكبير |
| `GetImageAlpha` / `SetImageAlpha` | مقيّدة بين 0 و1 |

ليس للتسميات واجهة لخطافات الأحداث — فلا يوجد ما يُنقر أو يُسحب — لكن جميع
[دوال الأدوات المشتركة](./blueprint-api) (الموضع، الحجم، الدوران، نصف قطر الزاوية، الاسم)
تنطبق عليها.
