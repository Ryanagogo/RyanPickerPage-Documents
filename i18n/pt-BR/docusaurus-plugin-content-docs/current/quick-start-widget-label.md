# Widget de rótulo \{#label-widget}

### Criar um novo widget de rótulo \{#creating-a-new-label-widget}

Você precisa estar no **modo de edição** para criar um novo widget de rótulo

**Clique com o botão direito em uma área vazia da tela do picker** para abrir o menu suspenso e, em seguida, clique no item "Rótulo"

### No Editor de atributos \{#from-the-attribute-editor}

Para ver os valores no Editor de atributos, você precisa selecionar um único widget

##### Aparência do rótulo \{#label-appearance}

<img src={useBaseUrl('/img/quick-start/widget-label/label-appearance.png')} alt="label-appearance" style={{marginLeft: 0, zoom: '80%'}} />

- **Cor**
  - Define a cor do botão
- **Fonte**
  - Define a cor e o tamanho da fonte

##### Texto do rótulo \{#label-text}

<img src={useBaseUrl('/img/quick-start/widget-label/label-text.png')} alt="label-text" style={{marginLeft: 0, zoom: '80%'}} />

- **Rótulo**

  - Define o texto do rótulo

- **Estilos de texto**

  - Para textos mais longos, você pode usar as opções a seguir para formatar o texto

    - Justification

    - Word Wrap

    - Margin

    - Clip

##### Imagem do rótulo \{#label-image}

<img src={useBaseUrl('/img/quick-start/widget-label/label-image.png')} alt="label-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - Use qualquer asset de imagem do seu projeto
- **Modo de Esticamento**
  - Os diferentes modos determinam como a imagem é esticada para tentar preencher o tamanho do widget
- **Escala**
  - Permite aumentar ou diminuir o zoom da imagem
- **Deslocamento**
  - Permite deslocar a imagem para cima, para baixo e para os lados
- **Alfa**
  - Permite definir a transparência da imagem. Quanto mais transparente, mais você vê a cor do widget
