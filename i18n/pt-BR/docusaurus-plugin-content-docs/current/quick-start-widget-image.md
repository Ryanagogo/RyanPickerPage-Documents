# Widget de imagem \{#image-widget}

### Criar um novo widget de imagem \{#creating-a-new-image-widget}

Você precisa estar no **modo de edição** para criar um novo widget de imagem

**Clique com o botão direito em uma área vazia da tela do picker** para abrir o menu suspenso e, em seguida, clique no item "Imagem"

### No Editor de atributos \{#from-the-attribute-editor}

Para ver os valores no Editor de atributos, você precisa selecionar um único widget

##### Imagem do widget de imagem \{#image-widget-image}

<img src={useBaseUrl('/img/quick-start/widget-image/image-widget-image.png')} alt="image-widget-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - Use qualquer asset de imagem do seu projeto
- **Modo de Esticamento**
  - Os diferentes modos determinam como a imagem é esticada para tentar preencher o tamanho do widget
- **Escala**
  - Permite aumentar ou diminuir o zoom da imagem
- **Deslocamento**
  - Permite deslocar a imagem para cima, para baixo e para os lados
- **Alfa**
  - Permite definir a transparência da imagem. Quanto mais transparente, mais você vê a cor do widget
