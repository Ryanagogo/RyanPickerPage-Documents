# Bugs e feedback \{#bugs-and-feedback}

### O menu Ajuda \{#the-help-menu}

No canto superior esquerdo da Picker Page, você deve ver o menu Ajuda ao lado do menu Arquivo.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu.png')} alt="help-menu" style={{marginLeft: 0, zoom: '80%'}} />

Ao clicar no menu Ajuda, você verá vários itens úteis, incluindo itens para sugerir recursos, relatar bugs ou me enviar uma mensagem.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu-items.png')} alt="help-menu-items" style={{marginLeft: 0, zoom: '80%'}} />

Ao clicar em qualquer um desses itens, um link será aberto no seu navegador para que você preencha um formulário.

Sugerir um recurso e Relatar um bug adicionam itens diretamente ao meu sistema de acompanhamento de tickets, e Fale comigo envia uma mensagem para o meu e-mail profissional.

Você também pode usar estes links para ir direto a cada formulário:

- **[Relatar um bug](https://tally.so/r/ODx6Np)**
- **[Sugerir um recurso](https://tally.so/r/D4RjLp)**
- **[Fale comigo](https://tally.so/r/RG9N6l)**
