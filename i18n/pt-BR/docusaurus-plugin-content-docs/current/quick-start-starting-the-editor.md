# Iniciar o editor do Picker Page \{#starting-the-picker-page-editor}

### O plugin \{#the-plugin}

Verifique se o plugin **RyanPickerPage** está ativado

Depois procure por **Ryan Tools -> Picker Page**

<img src={useBaseUrl('/img/quick-start/starting-the-picker-page-editor/find-ryan-tools-picker-page.png')} alt="find-ryan-tools-picker-page" style={{display: 'block', marginLeft: 0, marginRight: 'auto'}} />

Um Editor Utility Widget do Picker Page em branco deve ser aberto
