# Editor-Grundlagen \{#editor-basics}

<img src={useBaseUrl('/img/quick-start/editor-basics/editor-default-open.png')} alt="editor-default-open" style={{marginLeft: '0px', zoom: '75%'}} />

### Menü „Datei“ \{#file-menu}

<img src={useBaseUrl('/img/quick-start/editor-basics/file-menu.png')} alt="file-menu" style={{marginLeft: '0px', zoom: '75%'}} />

Über das Menü „Datei“ können Sie eine neue leere Picker Page erstellen, Seiten laden und speichern und die Editor-Einstellungen öffnen.

### Menü „Hilfe“ \{#help-menu}

<img src={useBaseUrl('/img/quick-start/editor-basics/help-menu.png')} alt="help-menu" style={{marginLeft: '0px', zoom: '75%'}} />

Im Menü „Hilfe“ finden Sie Links zu den YouTube-Videos, zur Dokumentation und zum Support sowie Links, über die Sie Fehler melden und Funktionen vorschlagen können.

### Neue Picker Page \{#new-picker}

<img src={useBaseUrl('/img/quick-start/editor-basics/new-picker.png')} alt="new-picker" style={{marginLeft: '0px', zoom: '75%'}} />

Der Button „Neue Picker Page“ öffnet einen weiteren Picker-Page-Editor, sodass Sie mehrere Picker Pages gleichzeitig öffnen können.

### Seitentitel \{#page-title}

<img src={useBaseUrl('/img/quick-start/editor-basics/page-title.png')} alt="page-title" style={{marginLeft: '0px', zoom: '75%'}} />

Der Seitentitel zeigt den Titel der geladenen Picker Page an.

### Aktuelles Rig \{#current-rig}

<img src={useBaseUrl('/img/quick-start/editor-basics/current-rig.png')} alt="current-rig" style={{marginLeft: '0px', zoom: '75%'}} />

Im Dropdown-Menü können Sie aus allen Rigs in Ihrem Level das aktuelle Rig auswählen, mit dem Ihre Picker Page arbeiten soll. Der Name des aktuellen Rigs wird außerdem unter dem Seitentitel angezeigt.

### Lesezeichen \{#bookmarks}

<img src={useBaseUrl('/img/quick-start/editor-basics/book-marks.png')} alt="book-marks" style={{marginLeft: '0px', zoom: '75%'}} />

Da Sie die Picker-Arbeitsfläche verschieben und hinein- oder herauszoomen können, ermöglichen Lesezeichen es, die aktuelle Position und den Zoom der Arbeitsfläche zu speichern, um später dorthin zurückzukehren.

### Bearbeitungsmodus-Umschalter \{#edit-mode-toggle}

<img src={useBaseUrl('/img/quick-start/editor-basics/edit-mode-toggle-button.png')} alt="edit-mode-toggle-button" style={{marginLeft: '0px', zoom: '75%'}} />

Mit einem Klick auf den Umschalt-Button „Bearbeitungsmodus“ betreten und verlassen Sie den Bearbeitungsmodus. Im Bearbeitungsmodus können Sie Picker-Page-Widgets bearbeiten, hinzufügen und entfernen.

### Arbeitsfläche \{#canvas-area}

<img src={useBaseUrl('/img/quick-start/editor-basics/canvas-area.png')} alt="canvas-area" style={{marginLeft: '0px', zoom: '75%'}} />

Auf der Arbeitsfläche befinden sich alle Picker-Page-Widgets

# Bearbeitungsmodus \{#edit-mode}

<img src={useBaseUrl('/img/quick-start/editor-basics/editor-edit-mode.png')} alt="editor-edit-mode" style={{marginLeft: '0px', zoom: '75%'}} />

Im Bearbeitungsmodus können Sie Picker-Page-Widgets bearbeiten, hinzufügen und entfernen.

### Bearbeitbarer Seitentitel \{#editable-page-title}

<img src={useBaseUrl('/img/quick-start/editor-basics/editable-page-title.png')} alt="editable-page-title" style={{marginLeft: '0px', zoom: '75%'}} />

Hier können Sie den Seitentitel ändern

### Werkzeugleisten-Werkzeuge \{#toolbar-tools}

<img src={useBaseUrl('/img/quick-start/editor-basics/toolbar-tools.png')} alt="toolbar-tools" style={{marginLeft: '0px', zoom: '75%'}} />

Die Werkzeugleiste enthält verschiedene Werkzeuge, mit denen Sie bestimmte gängige Widget-Attribute bearbeiten und das Widget-Layout gestalten können.

### Umschalter für den Widget-Attribut-Editor \{#widget-attribute-editor-toggle}

<img src={useBaseUrl('/img/quick-start/editor-basics/attribute-editor-toggle.png')} alt="attribute-editor-toggle" style={{marginLeft: '0px', zoom: '75%'}} />

Im Attribut-Editor können Sie verschiedene Attribute eines ausgewählten Widgets bearbeiten oder Informationen dazu einsehen.

### Umschalter für den Widget-Outliner \{#widget-outliner-toggle}

<img src={useBaseUrl('/img/quick-start/editor-basics/outliner-toggle.png')} alt="outliner-toggle" style={{marginLeft: '0px', zoom: '75%'}} />

Der Outliner bietet verschiedene Ansichten der Widgets auf der Arbeitsfläche, gruppiert nach Ebene oder Typ.

### Bearbeitungsbereich der Arbeitsfläche \{#canvas-edit-area}

<img src={useBaseUrl('/img/quick-start/editor-basics/canvas-edit-area.png')} alt="canvas-edit-area" style={{marginLeft: '0px', zoom: '75%'}} />

Sie erkennen, dass Sie sich im Bearbeitungsmodus befinden, wenn die Arbeitsfläche einen roten Rahmen hat. Ein Rechtsklick in diesem Bereich öffnet Kontextmenüs, mit denen Sie Picker-Page-Widgets erstellen oder bearbeiten können.
