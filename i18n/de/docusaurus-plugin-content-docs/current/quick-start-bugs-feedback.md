# Fehler und Feedback \{#bugs-and-feedback}

### Das Hilfe-Menü \{#the-help-menu}

In der oberen linken Ecke der Picker Page sehen Sie das Menü „Hilfe“ neben dem Menü „Datei“.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu.png')} alt="help-menu" style={{marginLeft: 0, zoom: '80%'}} />

Wenn Sie auf das Menü „Hilfe“ klicken, sehen Sie eine Reihe nützlicher Menüeinträge, darunter Einträge, um Funktionen vorzuschlagen, Fehler zu melden oder mir eine Nachricht zu senden.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu-items.png')} alt="help-menu-items" style={{marginLeft: 0, zoom: '80%'}} />

Jeder dieser Einträge öffnet beim Anklicken einen Link in Ihrem Webbrowser, damit Sie ein Formular ausfüllen können.

„Funktion vorschlagen“ und „Fehler melden“ legen Einträge direkt in meinem Ticket-System an, und „Kontakt“ sendet eine Nachricht an meine geschäftliche E-Mail-Adresse.

Sie können auch diese Links verwenden, um direkt zu den jeweiligen Formularen zu gelangen:

- **[Fehler melden](https://tally.so/r/ODx6Np)**
- **[Funktion vorschlagen](https://tally.so/r/D4RjLp)**
- **[Kontakt](https://tally.so/r/RG9N6l)**
