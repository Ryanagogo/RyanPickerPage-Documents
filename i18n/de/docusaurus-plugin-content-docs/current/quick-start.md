# Schnellstart \{#quick-start}

#### Ein Mannequin-Control-Rig laden \{#load-in-a-mannequin-control-rig}

<img src={useBaseUrl('/img/quick-start/quick-start/load-mannequin.png')} alt="load-mannequin" style={{marginLeft: 0, zoom: '67%'}} />

**Die Picker Page öffnen: Tools -> Ryan Tools -> Picker Page**

<img src={useBaseUrl('/img/quick-start/quick-start/start-picker-page.png')} alt="start-picker-page" style={{marginLeft: '0px', zoom: '80%'}} />

Öffnen Sie die vordefinierte Picker Page für das Epic-Mannequin

**Picker Page: Datei -> Vordefiniert laden -> Epic Mannequin**

<img src={useBaseUrl('/img/quick-start/quick-start/open-epic-mannequin-picker.png')} alt="open-epic-mannequin-picker" style={{marginLeft: 0, zoom: '80%'}} />

Klicken Sie auf einen der Buttons der Picker Page

<img src={useBaseUrl('/img/quick-start/quick-start/pick-mannequin-picker-button.png')} alt="pick-mannequin-picker-button" style={{marginLeft: 0, zoom: '50%'}} />

Ziehen Sie einen Rahmen um mehrere Buttons, um viele Controls auf einmal auszuwählen

<img src={useBaseUrl('/img/quick-start/quick-start/multi-select-mannequin-buttons.png')} alt="multi-select-mannequin-buttons" style={{marginLeft: 0, zoom: '67%'}} /><img src={useBaseUrl('/img/quick-start/quick-start/multi-select-mannequin-controls.png')} alt="multi-select-mannequin-controls" style={{zoom: '67%'}} />

Erstellen wir nun einen eigenen Picker-Button.

Beginnen wir zunächst mit einer leeren Picker-Page-Arbeitsfläche

**Picker Page: Datei -> Neue Picker Page**

<img src={useBaseUrl('/img/quick-start/quick-start/new-blank-picker-page.png')} alt="new-blank-picker-page" style={{marginLeft: 0, zoom: '67%'}} />

Wenn ein Popup „Ungespeicherte Änderungen“ erscheint, klicken Sie einfach auf „Ja“

<img src={useBaseUrl('/img/quick-start/quick-start/unsaved-changes-popup.png')} alt="unsaved-changes-popup" style={{marginLeft: 0, zoom: '80%'}} />

#### Wechseln Sie jetzt in den Bearbeitungsmodus. Klicken Sie einfach auf den Umschalt-Button „Bearbeitungsmodus“. \{#now-go-into-edit-mode--just-click-the-edit-mode-toggle-button}

Der Button wird blau, und die Arbeitsfläche der Picker Page erhält einen roten Rahmen.

<img src={useBaseUrl('/img/quick-start/quick-start/go-into-edit-mode.png')} alt="go-into-edit-mode" style={{marginLeft: 0, zoom: '50%'}} />

Gehen Sie in den Viewport und wählen Sie eines der Controls am Mannequin aus

<img src={useBaseUrl('/img/quick-start/quick-start/select-control-on-mannequin.png')} alt="select-control-on-mannequin" style={{marginLeft: 0, zoom: '67%'}} />

Gehen Sie zurück zur Picker Page und rechtsklicken Sie auf eine leere Stelle der Arbeitsfläche.

Dadurch öffnet sich ein Kontextmenü, über das Sie ein Picker-Widget hinzufügen können.

Klicken Sie auf den ersten Eintrag „Auswahl-Button“

<img src={useBaseUrl('/img/quick-start/quick-start/create-selection-button.png')} alt="create-selection-button" style={{marginLeft: 0, zoom: '67%'}} /><img src={useBaseUrl('/img/quick-start/quick-start/new-selection-button.png')} alt="new-selection-button" style={{marginLeft: 0, zoom: '100%'}} />

Welches Control-Rig-Control Sie auch ausgewählt haben, es wird beim Erstellen dem Auswahl-Button-Widget hinzugefügt.

#### Klicken Sie auf den Umschalt-Button „Bearbeitungsmodus“, um den Bearbeitungsmodus zu verlassen. \{#click-on-the-edit-mode-toggle-button-to-get-out-of-edit-mode}

Wenn Sie mit der linken Maustaste auf eine leere Stelle der Arbeitsfläche klicken, wird die Auswahl des Buttons aufgehoben. Dadurch wird auch die Auswahl des Control-Rig-Controls aufgehoben.

<img src={useBaseUrl('/img/quick-start/quick-start/deselect-button.png')} alt="deselect-button" style={{marginLeft: 0, zoom: ''}} />

Wenn Sie auf den Button klicken oder einen Rahmen um ihn ziehen, wird der Button wieder ausgewählt. Dadurch wird auch das Control-Rig-Control wieder ausgewählt. (Im Bearbeitungsmodus wird dabei nur das Widget ausgewählt; das Control Rig bleibt unberührt.)

<img src={useBaseUrl('/img/quick-start/quick-start/box-select-button.png')} alt="box-select-button" style={{marginLeft: 0, zoom: ''}} />

<img src={useBaseUrl('/img/quick-start/quick-start/test-select-selection-button.png')} alt="test-select-selection-button" style={{marginLeft: 0, zoom: '80%'}} />

**Hinweis:** Wenn Sie zuerst das Control-Rig-Control auswählen, wird das Widget ausgewählt.

#### Wechseln Sie jetzt wieder in den Bearbeitungsmodus. \{#now-go-back-into-edit-mode}

Wenn Sie die Maus über eine Kante oder Ecke bewegen, sehen Sie den Mauszeiger zum Skalieren.

Wenn Sie die Maus über die Mitte des Widgets bewegen, sehen Sie den Mauszeiger zum Verschieben.

Wenn Sie mit dem Skalier- oder Verschiebe-Mauszeiger klicken und ziehen, können Sie das Widget skalieren oder verschieben.

<img src={useBaseUrl('/img/quick-start/quick-start/resize-widget-mouse-pointer.png')} alt="resize-widget-mouse-pointer" style={{marginLeft: 0, zoom: ''}} /><img src={useBaseUrl('/img/quick-start/quick-start/translate-widget-mouse-pointer.png')} alt="translate-widget-mouse-pointer" />

**Öffnen wir bei ausgewähltem Widget den Attribut-Editor.**

Das kleine „+“ in der oberen rechten Ecke der Arbeitsfläche

<img src={useBaseUrl('/img/quick-start/quick-start/open-attribute-editor.png')} alt="open-attribute-editor" style={{marginLeft: 0, zoom: '67%'}} />

In der Gruppe „Erscheinungsbild“ können Sie die Farben des Widgets ändern

<img src={useBaseUrl('/img/quick-start/quick-start/change-widget-color.png')} alt="change-widget-color" style={{marginLeft: 0, zoom: '80%'}} />

In der Gruppe „Text“ können Sie den Text der Button-Beschriftung ändern

<img src={useBaseUrl('/img/quick-start/quick-start/change-widget-text.png')} alt="change-widget-text" style={{marginLeft: 0, zoom: ''}} />

Wenn Sie mit dem Bearbeiten der Button-Attribute fertig sind, können Sie den Attribut-Editor schließen und weitere Widgets erstellen.

#### Danke, dass Sie den Schnellstart durchgearbeitet haben! \{#thanks-for-reading-through-the-quick-start}
