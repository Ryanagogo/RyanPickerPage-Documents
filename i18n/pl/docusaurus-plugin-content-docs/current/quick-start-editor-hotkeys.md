# Skróty klawiszowe \{#hotkeys}

Wszystkie skróty klawiszowe i gesty myszy, na które reaguje edytor pickera.

### Zasady fokusu i trybów \{#focus-and-mode-rules}

- **Skróty klawiszowe działają tylko wtedy, gdy płótno ma fokus.** Płótno otrzymuje fokus, gdy tylko je klikniesz. Jeśli fokus ma pole w panelu bocznym albo lista w Outlinerze, naciśnięcia klawiszy trafiają tam.
- W trybie Live działa tylko skrót **F**. Wszystkie pozostałe skróty klawiszowe działają wyłącznie w trybie edycji.
- Przesuwanie przeciąganiem prawym przyciskiem i powiększanie kółkiem myszy działają zarówno w trybie edycji, jak i Live.

### Klawiatura \{#keyboard}

| Klawisz | Czynność | Tryb |
|---|---|---|
| **Delete** | Usuń zaznaczone widgety | Tylko edycja |
| **F** | Wyśrodkuj widok płótna na bieżącym zaznaczeniu (powiększenie się nie zmienia) | Edycja + Live |
| **Alt + kliknięcie przycisku** | Wyśrodkuj viewport na obiektach zaznaczonych kliknięciem przycisku |Tylko Live|
| **Alt + zaznaczanie przycisków prostokątem** | Wyśrodkuj viewport na obiektach zaznaczonych przeciągnięciem prostokąta po przyciskach |Tylko Live|
| **Klawisze strzałek** | Przesuń zaznaczenie (domyślnie 2 px) | Tylko edycja |
| **Shift + klawisze strzałek** | Przesuń zaznaczenie o większy krok (domyślnie 10 px) | Tylko edycja |
| **Ctrl + X** | Wytnij zaznaczone widgety | Tylko edycja |
| **Ctrl + C** | Kopiuj zaznaczone widgety | Tylko edycja |
| **Ctrl + V** | Wklej w miejscu kursora myszy | Tylko edycja |
| **Ctrl + Z** | Cofnij | Tylko edycja |
| **Ctrl + Shift + Z** lub **Ctrl + Y** | Ponów | Tylko edycja |

Obie odległości przesuwania klawiaturą ustawia się w panelu Class Defaults strony. Są niezależne od narzędzia **Przesunięcie** na pasku narzędzi, które ma własne pole odległości.

Kopiowanie / wycinanie / wklejanie działa między otwartymi kartami stron.

**Nieprzypisane:** nie ma Ctrl+A (zaznacz wszystko), Ctrl+S (zapisz), Ctrl+D (duplikuj) ani Esc (odznacz). Duplikowanie, wyrównywanie, rozkładanie i odbicie lustrzane są dostępne tylko w menu pod prawym przyciskiem lub na pasku narzędzi.

### Mysz – zaznaczanie widgetów \{#mouse---selecting-widgets}

Tylko Ctrl i Shift zmieniają sposób zaznaczania.

| Gest | Czynność |
|---|---|
| Kliknięcie widgetu | Zaznacz tylko ten widget |
| Ctrl + kliknięcie widgetu | Dodaj ten widget do zaznaczenia lub go z niego usuń |
| Shift + kliknięcie widgetu | Dodaj ten widget do zaznaczenia |
| Kliknięcie pustego płótna | Wyczyść zaznaczenie |
| Przeciągnięcie po pustym płótnie | Narysuj prostokąt zaznaczenia |
| Ctrl lub Shift + przeciągnięcie prostokąta zaznaczenia | Dodaj objęte widgety do bieżącego zaznaczenia zamiast je zastępować |
| Kliknięcie wiersza w Outlinerze | Zaznacza ten widget — działa nawet dla zablokowanych widgetów |
| Dwukrotne kliknięcie wiersza w Outlinerze | Zmień jego nazwę |

### Mysz – przesuwanie, skalowanie, obracanie (tryb edycji) \{#mouse---moving-resizing-rotating-edit-mode}

Osiem uchwytów skalowania i uchwyt przesuwania pojawiają się tylko w trybie edycji.

| Gest | Czynność |
|---|---|
| Przeciągnięcie uchwytu przesuwania | Przesuń zaznaczone widgety |
| **Alt** + przeciągnięcie uchwytu przesuwania | Obracaj zamiast przesuwać |
| **Alt + Shift** + przeciągnięcie uchwytu przesuwania | Obracaj z przyciąganiem co 15 stopni |
| Przeciągnięcie uchwytu krawędzi lub narożnika | Zmień rozmiar (działa poprawnie także dla obróconych widgetów) |

Przytrzymaj Alt, zanim naciśniesz uchwyt przesuwania, aby zacząć obracać. Trzymaj Shift podczas przeciągania, aby przyciągać.

### Mysz – nawigacja po płótnie \{#mouse---navigating-the-canvas}

| Gest | Czynność | Tryb |
|---|---|---|
| Kółko myszy | Powiększaj w stronę kursora | Edycja + Live |
| Przeciąganie prawym przyciskiem | Przesuwaj płótno | Edycja + Live |
| Kliknięcie prawym przyciskiem (bez przeciągania) | Otwórz menu kontekstowe | Tylko edycja |
| Przeciągnięcie separatora panelu bocznego | Zmień rozmiar panelu Outlinera lub Edytora atrybutów | Tylko edycja |

### Zakładki \{#bookmarks}

| Gest | Czynność |
|---|---|
| Kliknięcie zakładki | Zastosuj zapisany widok |
| **Ctrl + Shift + kliknięcie** zakładki | Zapisz bieżący widok w tej zakładce (nadpisując ją) |
| Kliknięcie zakładki prawym przyciskiem | Zmień jej nazwę lub ją wyczyść |
