# Widget obrazu \{#image-widget}

### Tworzenie nowego widgetu obrazu \{#creating-a-new-image-widget}

Aby utworzyć nowy widget obrazu, musisz być w **trybie edycji**

**Kliknij prawym przyciskiem puste miejsce na płótnie pickera**, aby otworzyć menu kontekstowe, a następnie kliknij pozycję „Obraz”

### W Edytorze atrybutów \{#from-the-attribute-editor}

Aby zobaczyć wartości w Edytorze atrybutów, musisz zaznaczyć jeden widget

##### Wygląd widgetu obrazu \{#image-widget-appearance}

<img src={useBaseUrl('/img/quick-start/widget-image/image-widget-appearance.png')} alt="image-widget-appearance" style={{marginLeft: 0, zoom: '80%'}} />

**Kolor**

- Ustawia kolor przycisku

##### Obraz widgetu obrazu \{#image-widget-image}

<img src={useBaseUrl('/img/quick-start/widget-image/image-widget-image.png')} alt="image-widget-image" style={{marginLeft: 0, zoom: '80%'}} />

- **Image Asset**
  - Użyj dowolnego zasobu obrazu z projektu
- **Tryb Rozciągania**
  - Poszczególne tryby określają, jak obraz jest rozciągany, aby wypełnić rozmiar widgetu
- **Skala**
  - Pozwala przybliżyć lub oddalić obraz
- **Przesunięcie**
  - Pozwala przesuwać obraz w górę, w dół i na boki
- **Alfa**
  - Pozwala ustawić przezroczystość obrazu. Im bardziej przezroczysty obraz, tym bardziej widać kolor widgetu
