# Błędy i opinie \{#bugs-and-feedback}

### Menu Pomoc \{#the-help-menu}

W lewym górnym rogu Picker Page powinno być widoczne menu Pomoc obok menu Plik.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu.png')} alt="help-menu" style={{marginLeft: 0, zoom: '80%'}} />

Po kliknięciu menu Pomoc zobaczysz kilka przydatnych pozycji, w tym pozycje do proponowania funkcji, zgłaszania błędów lub wysłania mi wiadomości.

<img src={useBaseUrl('/img/quick-start/help-menu/help-menu-items.png')} alt="help-menu-items" style={{marginLeft: 0, zoom: '80%'}} />

Każda z tych pozycji po kliknięciu otwiera link w przeglądarce internetowej, abyś mógł wypełnić formularz.

Zaproponuj funkcję i Zgłoś błąd dodają wpisy bezpośrednio do mojego systemu zgłoszeń, a Kontakt wysyła wiadomość na mój służbowy adres e-mail.

Możesz też użyć tych linków, aby przejść bezpośrednio do odpowiednich formularzy:

- **[Zgłoś błąd](https://tally.so/r/ODx6Np)**
- **[Zaproponuj funkcję](https://tally.so/r/D4RjLp)**
- **[Kontakt](https://tally.so/r/RG9N6l)**
